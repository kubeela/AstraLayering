# eye_right 眼部色盘与颜色层次

本轮仅为锁定队列中的 `eye_right`（画面左侧）准备原图色样，供后续分部件着色。原图 `references/base-subject.png` 为 **941 × 1672**，SHA-256 为 `7448a2575ec8619e43cd8ee9565ab35035272dd4702cd4b2ae58db4d748d34c3`。开工时以 `--expected-sha256 459f82982d648c44f4b54468c9d4a8c391f68ea16be896fb7ae9126717e87569` 运行 `validate_plan.py`，返回 `valid=true`、`eyes_symmetric=true`、`queue=["eye_right"]`。已审线稿用于定位结构；所有色值均由同目录 `提取色盘.py` 从原彩图的指定单像素读取，`radius=0`，无手改 RGB/hex。样本的 `part_id` 全部为 `eye_right`。

原图眼睛仅数十像素宽，单像素样本用于证明颜色确实存在、明确空间位置，不能当作整块区域的精确边界。最终范围和过渡须对照原彩图及已审线稿判断。`palette.json` 保留每个样本的原图坐标、实际像素、用途和来源哈希；`palette.png` 提供标注局部与色样。
