## 3. 第二步：连体服去除与身体构型/肤色平滑补全方式

遵循提示词要求（“不需要补全人体的细节，主要参考已有的皮肤上下文，平滑地补全缺失处的皮肤即可。其中 `body/torso`，根据先验你甚至可以简化这个部分，可以去除胸部相关的特征，而是补出身体本身的轮廓”），在 Krita 工程中借助 Python 脚本完成了建立在统一皮肤场与外轮廓场上的平滑补全：

1. **构建统一的躯干—骨盆—大腿根部皮肤与外轮廓场**：
   - 参考人物已有的上胸及大腿主肤色上下文（亮部中心肤色 `#FEE4D7` / `(254, 228, 215)` 至 `#FDE3D6` / `(253, 227, 214)`，外缘侧影过渡色 `#F0CBBD` / `(240, 203, 189)`，外轮廓深棕描边色 `#563A34` / `(86, 58, 52)`），基于 `013 | body`、`009 | pelvis` 与 `007/008 | leg` 的联合外轮廓距离场构建连续平滑的肤色与外沿立体过渡，确保跨层交界处在同坐标像素上拥有完全一致的色彩与明暗。

2. **`013 | body`（躯干层）处理细节**：
   - **清理肩带顶端凸起并连通锁骨/肩线**：裁除原双肩带顶端（`x=553..581` 与 `x=674..702, y=342..348`）高出自然斜方肌/锁骨线的 4–5px 黑色肩带凸角，按两侧肩头至锁骨线的自然弧度平滑收边并补齐柔和深棕肩颈轮廓线。
   - **去除连体服与胸部特征、简化还原身体轮廓**：完整保留 `y <= 363` 的原生锁骨线与颈窝柔光过渡以及两侧肩头端帽皮肤；将其余全部白色面料、双肩带、U 型领口黑边、袖窿线、纵向省道线以及胸部阴影褶皱彻底去除，平滑填充为干净、简化的躯干皮肤表面，并在两侧肋部至腰部外轮廓（`y=410..582`）绘制与手臂、腿部一致的柔和深棕身体外轮廓线。
   - **底边内侧无痕羽化**：在 `y=575..592` 压在 `009 | pelvis` 内部的重叠区域（保留外侧 4px 腰部外轮廓不减淡），对底边做 4.5px 柔和羽化，使躯干与骨盆层合看完全无缝。

3. **`009 | pelvis`（骨盆层）处理细节**：
   - **去除连体服下半身并补全骨盆/下腹皮肤**：将整层白色连体服、省道线及高叉滚边全部替换为与 `013 | body` 及 `007/008 | leg` 完全连续的柔和皮肤，并在裆部底端（`x=605..650, y=692..720`）加入符合原图画风的轻微暖色体块过渡。
   - **外髋与裆底轮廓保留、大腿内侧重叠边无痕化**：在骨盆层构成人体真实外轮廓的两侧外髋段（`y=570..624`）和两腿之间的裆底桥接段（`x=610..646, y=706..720`）保留柔和深棕外轮廓线；而在压在 `007/008 | leg` 大腿皮肤之上的斜向腹股沟交界边（`y=624..714`）彻底去除原泳衣高叉黑线，并在内部重叠区做 4px 柔和羽化，消除分界线。

4. **`007 | legs/leg_right/leg` 与 `008 | legs/leg_left/leg`（左右腿层）处理细节**：
   - **消除连体服高叉投射阴影**：将大腿根部（`y=612..770`）原本由高叉连体服裤边投射的深紫褐色斜向阴影带平滑替换为正常大腿亮部肤色与柔和外侧过渡，同时完整保留大腿外侧（`y >= 620`）与大腿内侧（`y >= 712`）的深棕腿部外轮廓线，使单独显示腿部或与骨盆层叠放时均干净自然。
