## 真实绘画与修正过程

使用 Krita 原生 `Node.paintPath`，共86条实际画笔记录。`b) Basic-5 Size` 在逐处建立的衣料选择内清掉旧衣色与线；随后用 `b) Airbrush Soft` 沿本处体积逐笔叠暖暗面和柔亮面。肩带、上胸、下胸、腰侧、腹部、髋前和腿根分别选择路径、色彩、笔径和力度。`k) Blender Blur`、`k) Blender Smear` 只用于已定位的短接头和原新交界；小尺寸实笔用于真实外轮廓与锁骨短端。

Python 辅助定位、取色、选择、切层、笔触调度、保存及导出。QImage/QPainter 仅用于选择范围和检查图组合；没有通过公式色场、渐变图、肤色传播或插值生成最终补绘像素，没有导入程序生成的皮肤补丁。检查图的灰底、拼版和整数放大只服务检查，没有写入交付工程或 PNG。

实际修正并非一次补色即验收：

1. 躯干第一遍清掉衣料后，肩带端出现偏平浅块；改用本侧肩根暖色接入，并局部融合旧肩带两侧，接续锁骨短外端。主体锁骨和腋窝未重画。
2. 胸部第一遍放大时发现领口上支残线，且一次局部清色形成横向浅块。重新按本层实际 y373 上端和领口内缘定位，重画衣料范围的皮肤，再分别重建左右体积，消除残线与横块。
3. 合看发现胸部下弧与 torso 明度断层。将暖暗体积续接到 torso 的新皮肤，并按两侧实际色差局部修正承底，去掉浅接边；没有把图层下弧画成轮廓。
4. 骨盆初次过渡显出斜向色面、右腿根窄暗痕；跨原裤口局部接色，延长柔暖转折并收淡原裤口邻近残影。腰腹两层的下沿色差也在新补绘内接顺。
5. 完整独显时发现骨盆 y535–579 的隐藏上端仍有衣料，先前局部对照漏掉这一段。已实际补清该处、补接上端层次，将最终对照扩大到 y525 起，重新保存查看，未接受有残衣的阶段工程。

每次上述绘画批次后保存同一 KRA，再从实际文档导出检查；中间状态保留在 inspection 的各阶段目录。最终验收仅引用 `inspection/final/`，不把早期候选图当成最终效果。
