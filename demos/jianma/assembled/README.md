# Jianma 穿戴合成

[打开交互对照](index.html) · [Krita 工程](jianma-assembled.kra) · [合成图](preview.png) · [原图对照](comparison.png)

将已完成的人物素体 90 层与衣装 69 层装配到同一张 1024 × 1536 画布。人物使用 `demos/jianma/raster-layering/step03/character-skin-base.kra`；衣装使用 `clothing-raster-layering` 的 `live-clothing-20261018/step02/clothing-soft-edges.kra` 最终修复稿。对照图为这次衣装输入中的 `simplified-character.png`。源工程的文件哈希见 [verification.json](verification.json)。

后发、后领、后袖、人体、前袖和衣襟分别穿插；手保留在后袖口之前、前袖片之后。腰带、链条、胸饰沿用衣装内部的既有层序。

另加 12 个可关闭的原生透明度遮罩：收束两束后发在裙摆外多出的发尾；遮住四个手臂部件与衣袖不贴合处；约束躯干、胸部、骨盆和双腿在衣下的多余外露；恢复内裙下摆透出腿部的效果。所有 159 个原始绘画层的像素保留，未粘贴参考图像素、合并部件或覆盖输入工程。人物与衣装使用不同图层标签色，遮罩随对应部件保存。

网页支持并排、滑动对照、逐层显隐、独显、搜索与遮罩开关。关闭全部衣装时自动恢复完整素体的显示；在 Krita 中查看完整素体时，也需要关闭人物部件下的穿戴遮罩。网页中的图层 PNG 是从保存重开的 KRA 导出的显示副本，工程是继续编辑的入口。

已核对原生保存重开、159 层像素一致性、合成效果及网页图层交互。此次交付是静态穿戴装配；源分块中已有的袖口折线、胸饰、裙边笔触及人物手足比例差异仍然存在，尚未做动画绑定。
