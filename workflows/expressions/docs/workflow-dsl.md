# 本目录使用的现行 DSL

本页随技能包提供本流程所需的完整调度约定，与项目的统一 DSL 使用相同语义，无需读取其他技能目录。编号决定顺序，YAML 声明调度与数据交接，提示词规定具体工作，`.model` 指定执行能力。

任务资料根是 `SKILL.md` 所在目录；工具、预览器及 schema 统一放在仓库根 agent-tools，节点和规则留在本技能。`run` 与 `asset` 相对声明它们的 YAML 解析，工具引用可进入 agent-tools，但不能引用另一技能的工具；产物路径相对用户输出目录，命令当前目录无需等于技能目录。

| 位置 | 含义 |
| --- | --- |
| 编号目录 | 从 1 开始按数字逐段排序，容器仅组织子任务；一个实际任务直接放提示词、配置与模型，不套空壳步骤 |
| 根 `流程.yaml` | 用户输入的 type、required 和 description；工作根目录由用户调用时指定 |
| 节点 `id` | 全流程唯一的结果身份，后续以 `nodes.id.output` 引用 |
| `run: .` | 显式执行当前目录任务；其他相对路径定位任务资料，不能填写 shell 命令 |
| 分支内 `run` | 只执行选中分支的任务；条件节点顶层不写 `run`，避免复用分支误派发 |
| `foreach.run: .` | 每项执行本目录任务一次，不重新解析自身循环；其他路径进入模板 |
| 无 `run` | 根输入定义、纯容器或仅发布已有输出的分支；生成新产物的叶任务缺失 `run` 是配置错误 |
| 节点 `worker` | 会话身份；同名串行续做，不同名独立派发 |
| `inputs.name: inputs.xxx` | 绑定根输入；循环内部则读取当前循环输入 |
| `from / required: false` | 可选输入；未提供与路径错误分别处理 |
| `asset` | 相对当前 YAML 的工具或素材；不是运行产物路径 |
| 普通 `outputs` 路径 | 相对用户指定工作根目录 |
| 输出为 `inputs.* / nodes.*` | 发布已有文件路径，不重新复制或派发 |
| `if / then / else` | 从已绑定输入或 options 读取明确条件，分支继承节点输入 |
| `imagegen.prompt / inputs` | 提示词相对执行目录；仅传列出的图片与自然语言文本 |
| `review.run` | 定位明确声明的独立审查任务 |
| 集中审查节点 | 输出报告，`status: pass` 才发布候选别名；revise 定向返修再复验 |

本流程的共同 SVG 修改按固定节点串行传递，无需为每个眼角、符号或表情枚举派发 foreach；需要读取已确认规格时只读取节点绑定的规格产物。

规格决策在负责该规格的节点内完成，已有用户选择直接记录，常规可选项按节点默认规则采用并注明依据；仅必要输入缺失、明确要求冲突或用户要求先确认的实际未决项才等待，不发明 `approval`、`goto` 或自定义调度字段。生图分支可直接复用已有风格图，两分支均发布同名 `image`。

集中审查的返修发生在当前最新 SVG 与关键形数据上；审查节点发布经修正且通过的实际路径，运行记录同步更新。后续绑定发现缺形时定点交回绘制者，随后原绑定 worker 接收新路径继续，不重跑整个阶段。
目录型输出也按同一规则传递，透传路径不要求复制目录。静态目标、配套 command 与后续累计 SVG 分别按节点声明交接；审查只发布通过的别名，后序读取实际通过版本，不能用早期目标的完整 SVG 覆盖下游新素材。
