# 表情工作流调度规则

任务顺序由编号目录决定，输入输出由各级 `流程.yaml` 声明，实际制作要求由节点提示词承担；本文件只规定通用调度与交接。

## 输入与任务边界

读取[根配置](流程.yaml)，绑定用户素材、需求与绝对输出目录；仅询问缺失的必要输入或无法按已有要求解决的冲突，可选输入未提供时按节点默认规则执行，不自行搜旧任务补隐含输入。用户选定本工作流即确定其职责范围，不能把笼统措辞扩展成新的范围确认门槛；用户只要求设计或修改工作流时不启动角色制作。

素材与工作流源文件只读，产物、预览和临时文件写入工作根目录。用户已经明确的选择直接交接；常规款式由节点依据角色风格选择并记录默认依据，不把提案批准设为每轮开工前置条件。只有用户明确要求先确认某项，或必要输入缺失/明确要求冲突且无法自行解决时才集中询问；只暂停确实依赖该答复的任务，不重问已经回答的事项。

本文件所在目录是任务资料根目录，节点与 DSL 规则随包携带；工具、schema、样例和离线预览器统一来自仓库根的 [agent-tools](../../agent-tools/readme.md)，不从其他技能读取工具。`run` 与 `asset` 仍相对声明 YAML 解析，工具以绝对路径调用，工作目录仍是用户指定的产物目录；迁移时随项目携带公共工具目录。

## 节点与绑定

- 按编号逐段数字排序；容器只展开子节点，不额外执行父任务。实际节点读取 YAML、提示词及 `.model`。
- 实际任务显式声明 `run`，当前目录写 `run: .`，相对路径定位其他执行目录；条件任务只在执行分支写 `run`，单任务循环写 `foreach.run: .` 且不重新进入自身循环。无 `run` 的纯容器只展开编号子步骤，输出别名分支只发布路径；不能按目录中的模型文件隐式派发。
- `inputs.*` 读取根输入，`nodes.<id>.<name>` 读取已成功节点结果；`asset` 相对当前 YAML，普通输出相对工作根目录，输出引用已有输入时只发布路径。
- `if / then / else` 按已绑定数据选择分支，缺失或错误类型交原负责 worker 修正；不能猜测条件或偷偷省略已确认能力。
- 遇到循环按 `foreach` 的来源、当前项和 `carry` 传递最新成功版本；循环局部进度独立记录，未通过声明 review 的候选不向后发布。
- 派发只包含节点声明的输入、工具和本轮用户补充要求；教程原文与总规划不追加给 worker，通用语法按[DSL 规则](docs/workflow-dsl.md)解释。

大型 SVG 和累计 JSON 先用程序定位实际 id、引用和本任务相关数据，再读取需要编辑的区域与图像；保留完整文件其余内容，不把整份长 SVG 文本反复塞入上下文。schema 按当前用到的定义读取，通用工具优先直接调用。

## worker 与交接

语言模型和强度由 `.model` 文件名最右侧分隔符解析；新 worker 使用 `spawn_agent`，显式指定配置模型、强度与 `fork_turns: "none"`，相同 `worker` 的串行节点通过 `followup_task` 继续原会话，不同身份独立建立会话。

共同修改完整 SVG 的任务串行执行；每次交接都显式给最新 SVG 和数据文件，经过其他 worker 或返修后也不能退回会话里的旧稿。只有已声明且相互独立的并行节点才可并行，各分支输出隔离。

```text
工作根目录：<绝对目录>
提示词：<实际节点提示词绝对路径>
输入：<绑定名＝实际路径或未提供>
输出：<声明的产物路径>
当前用户要求：<与本任务有关的选择和限制>
读取提示词并执行；命令工作目录设为工作根目录。
```

`imagegen.model` 由总控直接调用生图工具，只传 `imagegen.inputs` 声明的图片与自然语言文本；不把结构 JSON、路径、参数名或 SVG 发给生图模型。生成一次后保存结果并确认可读，只有工具失败、具体不可用问题或用户要求才重试。

## 审查与返修

只执行配置声明的独立 review 或集中审查节点，reviewer 与绘制者使用不同会话；`pass` 才发布该节点输出，`revise` 把具体问题交回原负责人在最新完整稿修复，再交同一 reviewer 复验改动区域，`blocked` 报告真实缺项。

节点内自查和联调由该 worker 完成；总控复用现有证据，核对声明交付和结论，不追加逐项复看、哈希链、全套再组装或收尾 review。没有具体缺陷不反复派发“继续优化”，必要返修优先局部完成。

## 记录与续跑

在输出目录 `运行记录.md` 简记输入、已确认选择、分支、节点状态、实际 agent ID、产物与问题归属；待用户回答不等于已完成，工具校验不等于视觉验收。

续跑核对实际产物和最新配置，按成功交付恢复；输入变化只处理受影响范围。最终报告实际完成能力和未解决项，不把素材完成、协议校验与角色动态通过混为同一状态。
