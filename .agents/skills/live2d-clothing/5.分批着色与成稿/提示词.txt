继续 clothing_drawing，在最新 svg 中完成当前 color batch；approved_line_art 仅作几何基准，不可覆盖其它批次已经完成的颜色。读取本批 task/part_ids/effects 与色盘，按以下顺序完成本批，不把全部衣层混涂，也不为每条褶皱另派任务。

一、完整材料底色与空间层次
先给本批完整实体和隐藏侧/背/内面、连接处填底色，再依原图依次制作整体体积、褶皱与折面、纹样/包边、自然边线和反光。整体胸腰或裙摆的宽面渐变、沿布料走向的明暗、折转接触、局部冷暖与亮带分别描述实际位置并绘制；多方向、多尺度的色层不能缩减为一种基色加一条全局渐变。
保留已审外轮廓、开口、松量、长度、附件身份及前后层位；衣物纹样随实际布面走向，不像贴纸跨过所有折面。柔软布料、硬领/金属和宝石按材料组织边缘与反光，不能一律塑料亮边；隐藏补色与新推断写在实体 desc。
关闭 data-role="construction-guide"；正式线条融入所属部件，以原图线色、粗细、软硬和局部消隐处理。连接截口不留封口描边，真正领角/硬饰边缘保留，不用全局模糊抹掉全部结构。颜色修饰不能暗中改变已通过的几何；确有局部缺陷才修并同步固定点、依赖与影形。

二、透明布料与多层穿搭
透明底布、不透明绣纹/包边、叠褶和材质反光分别着色控制；不要对整衣层统一降 alpha，让刺绣也变淡。用色盘区分可见合成像素和推断的布料本色，以实际身体/内搭为底校准穿戴结果，不把混入肤色的像素再透明一次。
真实双层布料重叠允许更深/更不透明，人为拆分接口不得出现重复 alpha 深带；使用较平的接口及受控覆盖，若用渐变蒙版，要检查实际合成覆盖率，不能假定两边线性 alpha 相加就等于一次遮盖。可用互补覆盖或合适的分区，但保留各部件完整可编辑底形，避免硬缝或为了消缝把两件永久合并。
透明区域下面的素体和内搭始终完整，布料固有层次与外来投影分开。无法从单图唯一还原透明参数时按原图合成效果保守校准并注明推断，不反复搜索所谓唯一正确值。

三、本批承影与指定跨件效果
完成本批部件自身明暗后，落实 batch.effects 及线稿阶段已修正的相关旧影；按承影面分工，source 可来自其它衣层、附件、身体或头发。衣服投皮肤、外衣投内搭、饰品投布面以及身体/头发投衣物均按真实关系处理，无依据不凑影。
先查询现有关系，持续的效果保留 id 并修正，不为同一源/目标重叠添加第二层；完整源形缓存、影形、目标轮廓和坐标保持当前版本。投影保留完整可编辑几何，再按承影面裁切，形状、偏移、接触与柔边依原图，不能只复制黑色源轮廓或画当前露出碎片。
外来影独立于材质体积，使用 data-effect="cast-shadow"、data-source-part/data-target-part 与实际内部 data-source-id/data-target-id；data-kind 随承影面，即使承影为 body/arms/lower_body 也一样。本套衣装新增或专属的效果另加 data-outfit-id 和相关 data-wear-layer，source/target 共同决定其依赖，不按 kind 粗暴开关。
独立材质高光标 data-effect="highlight" 并指向真实承载 id，固定亮面不强拆；跨表面效果分别裁切。clipPath 仅含实际 path/基本形状或 use 直接指向形状，保留变换、孔洞、显式 clip-rule，外层 clip、内层 blur；避免 g/use 链导致越界，避免多片 alpha/multiply 重叠变脏。
阴影保留与裙摆/袖子/饰物实际投影范围相称的完整源形，再按衣料或素体表面裁切。根据承影材质选正片叠底、深色半透明或普通受影色面：前两种在拆片接口/同源跨衣层处会重复压暗，需要分配有效覆盖；普通受影色面须匹配局部渐变与图案，不能把衣料纹理抹平。真实多件投影的重叠按原图处理，与人工重复覆盖区别开。
金属扣、光泽布等独立反光若不应照亮外轮廓，放在底色与正式线条之间并裁到本体；透明底布和不透明绣纹按各自承影/反光范围处理，不把整个衣组一起提亮。当前SVG按原图匹配混合后的颜色；后续绑定更换混合实现时，半透明添加/变亮效果可能需再调，不假定不同渲染器数值等价。
素体已有仍成立的非衣装效果保留；若新穿搭需要改变其可见区域，采用衣装可撤销的遮挡/显示关系或记录可恢复的依赖，不破坏原干净效果/身体底形。关闭衣层时，同时处理以其或其附属件为来源、目标的影及衣装专属遮罩；其余关系保持，不能只藏衣物留下皮肤上的衣影。
这里完成默认姿态的画面与可追踪关系，metadata 不会自动产生显隐或动画跟随，后续绑定仍需实现；不为未来未发生的姿态预画投影。

四、批次保存与最后直接交稿
非末批只交完整 SVG，作画中按需要定点比较；不出额外整套预览或长报告。每批保持稳定 id、viewBox、素体本体与其它已完成区域，仅修改职责内实体及受影响关系。
is_last=true 时，当前稿即最终穿戴稿，完成以下一次收尾，不另拼装或请总控复查：
1. 将同一完整 SVG 保存到本批 svg 和 final_svg，保证内容一致；直接从其衣装实体导出 clothing_svg，包含本套所有衣层、附属件、独立效果及所需资源，保留画布坐标与独立组，不能栅格化或拼成最上层单片。为裁切引用的素体形状保留必要非显示资源，不把素体可见实体带入衣装集合；展开必要祖先变换/样式使导出几何位置一致，重写引用时同步 id。
2. 写 index 为简洁 JSON：outfit_id、viewBox、layers（id/name/实际实体 ids）、parts（实际 id、layer_id、素体复用来源或本轮新绘、attach_to/固定点、相对素体/其它衣件的绘制位置）、effects（id/source_id/target_id、所依赖衣层）、必要的 visibility_dependencies 与推断备注。说明 clothing_svg 是分层素材集合，重穿必须依索引穿插，不能整张置顶；索引使用实际输出 id，不照抄已失效计划。
3. 对被衣装临时抑制的既有素体效果/显示关系，在 visibility_dependencies 记实际 id、原状态与启用条件；不能只有“待关联”一句话。若源/目标分属不同衣层，记录两边依赖，任一方关闭时该关系失效；已有非衣装部件仍由素体保有身份。
4. 用 preview_tool 输出默认 preview 和一张成稿对照，组合原图并排/可对齐区域混合、一个代表性衣层或衣附饰品开关，以及实际存在的透明接口/投影局部；同版视图复用。临时开关须按 index 同时处理该层实体及依赖影/遮罩，单独 --toggle 一个组不能代表全部衣装依赖已切换；可在 tmp 构建临时视图，最终稿保持默认穿戴。没有透明或投影项不制造测试。
5. 集中看一次轮廓还原、材料层次、自然线质、接口及衣层隐藏后身体/内搭完整无衣影；发现具体问题只修相应实体并更新交付，不枚举所有穿搭组合、不做动作预览、独立成稿 review、哈希审计或无限局部放大。
