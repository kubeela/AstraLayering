# Live2D 衣装技能

`$live2d-clothing` 根据穿衣参考，在已有分层素体上还原或制作可替换衣装；[SKILL.md](SKILL.md) 只规定通用调度规则，实际任务由编号目录与各级 `流程.yaml` 定义。

## 调用

```text
使用 $live2d-clothing，按照参考完成衣装。
素体 SVG：/绝对路径/base.svg
穿衣参考图：/绝对路径/outfit.png
输出目录：/绝对路径/本轮衣装输出
```

用户只需这两份素材和输出目录；素体保持只读，不要求提供旧任务、归档或额外交接文件，也不自动搜索这些资料。已有且可用的素体配饰复用，缺失或不可用的衣装部件依据参考补画。

## 节点安排

| 节点 | 职责 |
| --- | --- |
| [1.结构与穿戴分析](1.衣装结构与穿戴分析/流程.yaml) | 列齐实际衣层与附件、复用身份、前后穿插及必要侧/背/内面，安排少量实际绘制批次 |
| [2.按需补全参考](2.按需补全参考/流程.yaml) | 结构仍不明确时生成一次补全参考，否则沿用穿衣参考 |
| [3.1.分批线稿](3.衣装线稿/3.1.分批完整线稿/流程.yaml) | 按衣件或穿搭层完成完整几何、接口与穿插，全部几何完成后才进入上色 |
| [3.2.集中结构审查](3.衣装线稿/3.2.集中结构审查/流程.yaml) | 一次独立结构审查，具体问题交原绘制者修正 |
| [4.衣装色盘](4.衣装色盘/流程.yaml) | 按实际材料提取颜色与空间层次，透明材质注明本色和透明度的推断 |
| [5.分批着色与成稿](5.分批着色与成稿/流程.yaml) | 完成各批底色、体积与褶皱、纹样、柔和边缘及关联投影，末批直接导出 |

模型及推理强度以各节点 `.model` 为准；部件与着色方法写在对应 worker 提示词，不追加教程原文作为运行输入。

## 交付与边界

最终目录 `final/` 包含完整穿戴稿 `character.svg`、独立衣装集合 `clothing.svg`、穿插与效果索引 `clothing-index.json`、默认预览和成稿对照；衣装集合须按索引放到素体各层之间，不能整张置顶。

当前产物是静态分层素材，保留必要补形及效果关系；转向、物理摆动、透明接口和投影的动态跟随需要后续绑定验证。仓库首页另有 Jianma 实跑案例展示，案例不属于技能运行依赖。

## 工具依赖

`SKILL.md` 所在目录是任务资料根，DSL 说明在 [docs/](docs/workflow-dsl.md)，通用工具放在本技能的 [tools](tools/readme.md)，衣装色盘入口放在具体步骤的 `tools/`；迁移时直接携带本技能目录。Python 3.8+、Pillow 9.1+、Node.js 与 sharp 用于工具执行。
