# 工作流 DSL

本页随技能提供所需的完整调度约定，与人物分层和表情包采用相同语义；无需读取其他技能。编号目录决定顺序，YAML 声明调度和数据交接，提示词规定具体工作，`.model` 指定执行能力。

## 包根与路径

`SKILL.md` 所在目录是任务资料根，`run`、`asset` 相对声明它们的 YAML 解析；任务与规则留在本技能，工具引用统一指向仓库根 agent-tools，不能指向另一技能。提示词相对执行目录，脚本相对自身位置寻找配套资源；输入绑定为绝对路径，输出相对用户工作根目录。

## 执行入口

| 声明 | 含义 |
| --- | --- |
| 根 `流程.yaml` | 外部输入的类型、必需性与说明，无执行任务 |
| 编号目录 | 按数字逐段排序；纯容器只展开子节点，不额外派发父任务 |
| `id` | 节点结果身份，后续用 `nodes.<id>.<输出名>` 引用 |
| `run: .` | 显式执行本目录提示词与模型，不再次解析自身 YAML；run 是目录，不是命令 |
| `run: 相对目录/` | 进入被引用任务或编号子流程 |
| `worker` | 相同身份串行续用会话；未声明时使用 id，新会话按模型文件配置 |
| `if / then / else` | 先读取已绑定数据选择分支；run 写在实际执行分支，顶层不隐式继承 run |
| 无 run 的别名分支 | 仅发布 `inputs.*` 或 `nodes.*`，不复制、不派发；目录内有模型也不改变这个含义 |
| 无 run 的纯容器 | 无本地提示词与模型，只展开编号子任务 |

生成新文件或写选项的叶任务缺少 `run` 是配置错误；不能通过提示词、模型或输出文件是否存在猜测是否执行。条件字段缺失或类型错误交给负责产生该字段的 worker 修正；未选择的分支不执行。

## 输入与产物

- `inputs.*` 在顶层节点绑定根输入，在循环内绑定当前循环输入；`nodes.*` 读取已成功交付的结果。
- `{asset: ...}` 声明本技能资料或 agent-tools 公共工具；`{from: ..., required: false}` 允许输入缺省，缺省与文件损坏不是同一情况。
- 分支继承节点输入并加入自身输入；普通输出路径相对工作目录，输出引用已有输入/节点时发布实际路径。
- `self.*` 仅在当前节点的 review 内指向候选产物；发布前先完成声明的 review。

## 循环

`foreach.from` 指向清单输入，`items` 指定其中数组，`as` 绑定当前项，`mode: serial` 按顺序执行；先读取来源和初始 carry，再用当前项解析占位符，并传入序号、总数及 `is_last`。

单任务循环使用 `foreach.run: .`，每项直接执行本目录任务一次，不重新进入自身 foreach；指向其他目录时执行该模板，无 run 的循环仅限无本地任务的纯子步骤容器。循环入口与顶层 run 不能并存。

`carry` 从节点初始输入开始，每项使用上一成功项最新输出；无同名输出时保留原值，失败或待返修候选不向后发布。当前项 `nodes.*` 独立记录，整个循环完成才发布循环最终结果，`when: last_item` 输出只交给末项，不追加未声明的组装任务。

## 生图与审查

生图分支同时写 `run`、`imagegen` 并提供 `imagegen.model`；总控按 `imagegen.prompt` 读取自然语言，仅传 `imagegen.inputs` 列出的图片和文本，不派语言 worker。生图失败记录失败，不偷偷改为复用分支。

`review.run` 定位明确声明的独立审查；联合审查也可作为带 run 的编号任务。`pass` 才发布，`revise` 定点交回原 worker 修复，再交同一 reviewer 复验改动，`blocked` 说明缺项；总控不追加审查、截图或哈希链。

所有交接显式携带最新输入路径；模型与提示词通过本包路径读取，续跑按实际成功产物恢复会话和状态，不把早期整图覆盖到后续成果上。
