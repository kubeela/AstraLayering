# 光照调校

基于组装原画和前一步法线、深度，调整适合角色画风的初始光照。使用 `render_lighting`，渲染算法与角色工作台一致，不修改原画或贴图。

先渲染基准，再试不同光源位置与前后距离。结合肤色、脸部可读性、衣服褶皱和部件投影，调整光源颜色、暗部颜色、环境补光、明暗边缘、亮部范围、法线强度、深度、投影、混合比例和边缘光。查看实际结果，不凭参数大小判断好坏；保留角色原画的风格，避免亮脸发白、布娃娃感与重复投影。

至少比较两组不同参数。选定完整参数后调用 `final=true`，由工具保存 `light.json`、原尺寸 `preview.png` 和渲染记录。报告简述选择依据、比较结果与未解决的问题。图片处理被明确拒绝时停止图片重试，保留进度并如实报告，不能称已完成视觉验收。
