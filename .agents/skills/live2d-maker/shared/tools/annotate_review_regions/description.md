将你已经看图确认的问题框选在当前 KRA 导出的图片上，供绘制者定位返修。你自行判断问题、填写框坐标、对应图层及说明；工具不检测差异，不计算相似度，也不决定是否通过。

image 是当前 KRA 导出的 PNG，reference 可选，为同画布的实际参考 PNG。路径相对本管线工作目录，也可使用本任务内的绝对路径。regions 中每项提供与报告一致的 id（如 R1）、原画布坐标 bounds=[x,y,width,height]、相关 layers 和 description。框覆盖需要修复的区域；不同位置的问题可分别标记，即使它们属于同一部件。不要为标记问题修改、移动或缩放参考。

输出 marked.png（整图编号框选）、regions.json（原坐标、图层及问题说明），以及每个编号的当前局部图；提供 reference 时还输出同坐标参考局部和左参考/右当前对照图。padding 仅增加局部图周围的观察上下文，默认 16 像素，不改变 bounds。返回证据路径，在 review 报告中引用，并说明修复方向及需要保留的内容。工具保留输入和 KRA，只写本步 review-evidence/ 下的新证据目录。
