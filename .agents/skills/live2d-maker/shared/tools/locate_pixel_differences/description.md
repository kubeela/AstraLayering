定位同一画布上的可见像素差异，供 step01 绘制、返修和独立 review 使用。先从实际 KRA 导出当前 PNG，reference 为该步骤实际采用的参考 PNG。路径相对当前管线工作目录，也可传本任务内的绝对路径。工具只写诊断图与 JSON，不修改输入、KRA、图层或上游资料。

输出 missing（参考内容缺失）、extra（当前多出内容）、color（明显颜色差异）的候选坐标 [x,y,width,height]、像素数、编号标记图、热图及左参考/右当前的原尺寸对照图。返回文件路径，用已有看图能力检查。完整区域清单在 differences.json，max_regions 只限制返回及标记数量。

整图合成可直接对比；对单层时，应提供独立的 visible_mask：白色为该部件在参考中实际可见、需要比较的区域，黑色/透明不比较。不要把遮挡补全区按遮挡物的参考像素判错，也不要用当前层 alpha 与参考交集制作可见范围，否则会漏掉当前缺口。可选 crop 聚焦某个区域，坐标始终保留原画布位置。尺寸不同会报错，不能通过缩放或移动参考掩盖错位。

color_threshold、alpha_threshold、min_region_pixels 是可调的诊断筛选值，默认分别为 80、96、64，优先定位明显差异，不是验收标准。可在 schema.json 修改默认值，或本次调用显式覆盖。候选清单包含正常边界和纹理差异，不能逐条自动转成返修要求；需要定位细小明确缺口时再降低筛选值。空清单不代表通过，也不能检测不可见的补绘是否合理；必须结合 KRA 单层、隐藏上层和整图观察，检查轮廓、画风及补绘衔接。确认明显问题后由绘制者修画，细微抗锯齿留给 step02。
