提交覆盖全部终止 part 的深度提案；每个 ID 恰好一次。单深度使用 level，多深度使用 levels，两者互斥。levels 每项提供 level 与非空 region：描述该区域、与相邻物的前后关系及连续分界，不要求像素线条。所有深度属于同一从后到前的数轴，数值越大越靠前，不得重复；允许小数以便在既有层之间插入。数组位置不代表深度。
必须先用 preview_svg 查看现有 preview.svg 的 blend。工具生成候选 SVG；每个完整 part 只放一次，多深度 part 暂按最靠后深度放置，绝不把这份整件预览当成已完成切片的证据。实际切片由 raster step01 完成。每次重新提交都会清空逐件检查和旧候选观察，之后必须查看新候选并重新检查全部 part。
