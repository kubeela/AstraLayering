在 Krita 中去除连体服，并把原衣料覆盖的区域画成与已有皮肤自然连续的身体底层，供后续叠加衣服。交付必须同时满足两件事：原有合格绘画得到保留，新补绘的颜色、明暗、笔触和部件衔接达到同等质量。

## 输入与工作位置

- 以下步骤路径相对本管线目录，实际绝对路径见文末运行信息。
- 输入 KRA：step02/character-soft-edges.kra，只读使用，不覆盖。先阅读 step01/report.md 和 step02/report.md，沿用已确认的参考依据、部件说明和修画成果。以输入 KRA 的原有皮肤和第一步实际采用的皮肤参考判断画风，不用穿衣参考中的衣料明暗代替皮肤。
- 本步目录：step03/。首次处理先另存为 step03/character-dressup-base.kra；中断后继续已有工程，保留合格修改。局部修坏时从输入工程恢复对应区域，不能重置整份工程丢掉其他合格修改。

## 辨认范围，保留已有绘画

逐层独显并查看合成，辨认衣料、肩带、滚边、衣缝及其抗锯齿残色，和原本裸露的皮肤分开记录。标记到某个 part 不代表可以重画整个 part。

去掉实际衣料内容，在该范围内补画皮肤；接色所需的过渡带按本处形体、原笔触和实际接缝确定，不硬套固定像素宽度。允许在紧邻衣缘的必要范围内逐步接色，但不能扩大为整层铺色、整体模糊或改画未受影响的皮肤。原有肩头、锁骨、颈根、腋窝、髋部及肩臂连接等处合格的描线、明暗和体积应保留。误覆盖时恢复原绘画，再局部修接。

无需新增被衣料遮挡的人体细节；仍须画出与周围一致的自然体积和肤色层次。“身体底层”不降低绘画质量，不等于平涂肤色，也不能保留衣褶和裤口形状、只把衣料染成肤色。

## 在 Krita 中逐处补画

用 Krita 原生笔刷、涂抹等绘画操作，沿身体形体逐处补色、接续明暗和修整线条。可以通过 computer use 操作，也可以用 Python 驱动 Krita 原生画笔；每处都要看实际画面决定颜色、笔触方向、笔刷尺寸、力度及后续修正。不能用统一参数对所有区域批量处理。

Python 可以辅助定位、取色、建立选择范围、切换图层、导出对照及检查文件。不能在 NumPy、Pillow、QPainter 等中用公式色场、高斯渐变、最近邻肤色传播、阈值填色或插值生成最终补绘像素，再通过 setPixelData 导入来代替上述绘画。脚本在 Krita 进程中执行、像素已写入 KRA、调用过几次画笔，都不能单独证明完成了修画；最终笔触必须实际解决画面问题。

每处理一处，先观察周围已有皮肤的色相、明度、亮暗走向和笔触，再在当前部件中延续这些关系。旧衣料边界只决定从哪里开始去衣，不应成为新皮肤上的斜带、亮边、暗沟或描线。尤其检查原领口、肩带、腰腹和裤口：清除滚边与残色后，跨越原衣缘观察明暗是否连续，不能仅将边界模糊成另一条宽色带。

部件交叠处同时查看相关层。皮肤内部的分层边界不能被当成外轮廓补描；真实外轮廓则保留与原画相符的线条。接色有问题时修正当前补绘及必要过渡，不磨平相邻合格部件来迁就新色块。

## 先验收画面，再核对文件

每完成一处实际修改就保存 KRA，从该工程查看或导出画面。检查图必须对应最新保存的实际工程，不能只看补色脚本生成的候选 PNG。对每个修改部件完成以下检查：

1. **独显修改层。** 衣料、滚边、衣缝及残色清除干净；补绘有与原画一致的柔和层次，没有平涂块、涂抹脏斑、突兀亮斑或沿旧衣缘留下的线和色带。
2. **显示相邻皮肤层、隐藏遮挡层。** 核对颈肩、肩臂、胸躯干、腰腹及腿根中实际受影响的连接；跨边界的肤色、明度变化和描线连续，没有硬接头、浅色接带或体积断层。相邻层像素未改，不能证明连接正确。
3. **查看完整合成。** 在原尺寸判断正常观感，再放大到 200–400% 检查过渡、残线、锯齿和笔触；不能只看缩略图或靠缩小隐藏接缝。切换修改前后，确认原有合格绘画保留，新增部分没有降低整体画风和质感。

保存同坐标、同倍率的局部对照，覆盖每处衣料移除区及其与原皮肤的完整交界，不只截取没有变化的保护区。说明看到的具体问题、实际修画方式和修后结果。生成检查图后必须实际打开查看；发现或怀疑仍有接带、残色和不自然过渡时继续修画，再保存、查看和复验，不能只改报告中的结论。

视觉验收通过后，保存、关闭并重新打开最终 KRA，再核对图层、导出 PNG 与合成一致。像素散列、保护区零差异、图层数和保存重开校验只证明保留范围与文件一致性，不能代替绘画验收。不能以“低细节底层”“之后会被衣服挡住”或文件检查通过为由接受可见缺陷。未修好的地方继续处理并保留进度，不能返回 completed；必要输入或工具确实不可用时按运行规则说明障碍与恢复尝试。
