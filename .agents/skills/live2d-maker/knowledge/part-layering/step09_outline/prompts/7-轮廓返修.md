【返修要求】
按上述意见修改当前草稿，保留可靠的可见边缘，清理噪音；微小缺口按参考和形体关系补成连续的局部形状，不用孤点或碎片代替形体。

先重新核对反馈涉及区域的真实归属和主要形体。归属、整体形状或位置比例错误时，可以重画当前组草稿，不限于微调控制点；修正后先复查整体，再检查局部边缘。反馈也须以原参考为依据，不能沿用错误的部件识别继续扩画。被遮住的完整形状仍交给后续补全。

先核对反馈所称的组件缺失是否确有未覆盖区域。group 此步是联合覆盖色块；完全位于本组另一实体色块内部的饰件不要求另画内部边界或单独 path。若反馈仅依据没有内边或 path 数量判断漏画，说明现有覆盖依据，保留正确的联合色块，内部结构留到直属拆分；仍须修正真实未覆盖的外露部分，不挖空底形来制造饰件分界。

有父组时，按 group.allowOutsideParent 处理范围：为 true 时，依据 note 的完整实体职责修正形体，允许伸出父轮廓，并继续核对原图定位、画布坐标和归属；省略或为 false 时，在父范围内修正可修漏画，只有扩大父稿才能恢复的部分单列上游限制，写清位置与依据。父 SVG 始终保持原样；受父范围约束时保留该检查，如实说明尚未补齐的父外缺漏。

同组相邻连续形体优先合并覆盖，远处分离区域保留；允许跨组合理重叠，不为避开饰件刻意挖缺口，例如耳朵沿清晰耳缘连续描绘，不绕开耳坠。已有合理补形且附近无走向相符的参考边界时保留。

逐项核对反馈是否已修正，放大改动处及相邻区域，以原图叠加和边缘图确认边缘、接缝和形体连续性；再看整图确认未引入位置、比例或其他区域的变形。发现问题在本次返修内修正并复查，不把已发现的问题留到下次审查。

若反馈要求恢复配色、纹样、明暗、材质或半透明表现，逐项说明它们属于后续栅格绘制；保留正确色块，仍须修正真实轮廓、开口、覆盖和归属问题。发现本组说明有误时可使用 update_group_note 修正说明；仅有说明问题时保留正确轮廓，不改父组、其他组或分组树。
