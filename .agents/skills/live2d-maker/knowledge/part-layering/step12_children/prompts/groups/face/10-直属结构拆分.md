拆分当前 face 的直属结构，默认候选为 face_base（part，干净脸底，包含额头、脸颊、下颌和下巴）、eye_left 与 eye_right（group，各自完整眼睛）、eyebrow_left 与 eyebrow_right（part，每侧整眉）、ear_left 与 ear_right（按耳部结构判断）、nose（按下述条件）、mouth（group）。普通脸底在当前轮廓阶段作为一个 part，线色处理在后续绘制中落实，不仅为绘画步骤另建组。

鼻点或简单鼻线统一变化时 nose 为 part；鼻点、鼻影、鼻梁线转头时需不同位移时 nose 为 group，并在 note 列明后续需分出的结构；鼻梁高光、柔和鼻影只是浓淡不同而随鼻统一变化时不另拆。耳部按深度层次判断：猫耳、兽耳等外耳壳与耳内面在转动时前后错开、夹在中间的耳内面会露出更多或更少，每侧为 group，在 note 指明后续需拆出的外耳壳、耳内面及实际存在的翻折边、耳毛等结构和遮挡关系；本轮不提前提交其子树。普通人耳转动时整体变形即可，每侧为 part；不按耳廓线、肤色、普通明暗或落在外耳轮廓内的耳内片拆分。眉毛独立、不带周围肤色。明显不同于脸部肤色、用于表情且需独立显隐的腮红（如害羞红晕）列 blush_left、blush_right（part）；普通脸颊微红当作肤色画在脸底，不单独列出。

脸底在五官下保持完整，不挖眼洞、口洞，不将耳朵、颈部或头发并入脸底。耳饰已有上层归属时不重复。五官被头发遮挡仍按确实存在的结构规划。当前只登记每只眼和整个嘴，不提前登记眼内、口内更深层。脸型不扩大成头顶或后脑。

没有明确的猫耳、兽耳等替代耳部结构时，左右普通耳朵默认存在，即使当前完全遮挡也登记 ear_left 与 ear_right，在 note 中写明遮挡和补全依据，不因看不见而省略。已有替代耳型时按实际结构及上层归属处理，不重复增加一对普通耳朵。
