从当前父组完成稿中框选一个直属子节点的独立形状，直接作为该子节点的轮廓。name 填将要在 submit_children 中提交的子节点名称，region 为原画布坐标中的整数选框 {x,y,width,height}。

选框边线须全部落在父组完成稿的空白处：框内形状整体复制，框外形状整体排除；边线切过形状、框内外形状相连、框内没有形状或包含父组全部形状时报错。同名再次调用会替换上次选框，不同子节点的选框不能复制同一形状。返回复制结果的 SVG 路径，用 preview_svg 查看确认范围。

提交同名子节点后，程序从父组完成稿按同一选框重建其轮廓，跳过描边与轮廓 review，父范围与结构校验照常执行；去重与补全照常进行。该子节点不能同时标记 hiddenInReference。
