# Layering 调度流程约定

2026-10-15 更新。参考准备、首次分组、轮廓绘制与自检、独立 review、整层去重、正面遮挡补全和直属结构拆分已接入真实 agent。补全结构检查及最终 preview.svg 合并由程序执行。

轮廓绘制/返修可用 `write_outline_svg` 写入指定草稿，工具不接受文件路径，并执行已有 SVG 与父范围校验；随后仍须 `preview_svg` 自检，最后由调度器发布。绘制和 review 均可用 `view_bitmap` 查看参考局部，不依赖终端或额外裁图运行时。group 所属独立组件的覆盖属于轮廓审查范围，不能以“不审内部纹理”跳过整个组件。

绘制、review、去重和补全可用 `read_svg` 只读本轮明确指定的源图、父图或草稿，以复用共边曲线。路径按本轮绑定清单与运行目录校验，拒绝目录逃逸。长源码按字符偏移分页，返回文件哈希、总长度与下一页位置，不把部分页面当成完整 SVG；单页默认 16000 字符、最多 65536 字符，单文件上限 8 MiB。读取不计为视觉观察，原有预览、发布和原形保留检查照常执行。

group 轮廓表示所属结构的联合覆盖。完全位于本组底形内部的饰件已被该色块覆盖，内部边界留到下一层，不以缺少独立 path 或 edge 内边判为漏画。位于联合色块外的独立眼褶线、饰件外露部分等仍须纳入范围，真实孔洞仍须保留。

## 初始化与范围

启动先读取当前运行的 groups.json 和事实产物。null 输入且实际没有组才执行首次分组；已有组时恢复，不重新识别或重置。显式 groups 仅按 ID 选择已有组及其后代，不导入外部描述、进度或新组，拒绝空选择、未知组及错误父子关系。

第一层人体组为 face、hair、head_accessories、neck、body、arms、pelvis、legs，按实际角色取舍。face 的先验范围是脸型与耳朵，不补头顶或后脑。hair 包含头发与发髻，head_accessories 包含头饰及其长飘带；分类名作为制作范围，允许实际发束留在头饰组，不为类别纯粹而重新制作。临时连体服只用于辨认身体，不另分组。

首次识别用 view_image / view_bitmap 观察程序指定的素体参考，通过 write_groups 原子保存主体和一层分组；不解析最终回复，不修改制作产物。组 ID 沿用可读路径，如 face/eye，直属子组 ID 位于父 ID 下。

## 严格按层推进

层级直接从组树计算，同一层包括整棵树同深度的全部组。固定本层名单，按以下顺序执行：

1. 层内并行执行每组的轮廓绘制与分块自检，以及原有 review／返修流程。
2. 等待本层所有组的轮廓流程结束，再统一处理整层重复对象。
3. 层内并行执行每组的直接遮挡补形、补形自检、子组分析和登记。
4. 当前层全部结束后，收集新子组作为下一层，重复这一流程。

某父组先完成也不提前启动其子组。review blocked、pending 或待接入步骤会阻止本层进入后续阶段，已启动任务可收尾。执行异常立即输出具体组、步骤和原因，停止新派发，等待已启动组结束后汇总错误。maxDepth: 1 只处理深度 0，不触发后代或提前合并。

workflow.ts 仍是通用并发执行器，不引入工作流领域规则；layering.ts 用两个批次复用它，中间执行一次层去重。同层依赖满足的组全部进入队列，不设组任务数量上限；实际 agent 总并发默认 3（--jobs / -j），共享 agent-runtime.ts 的队列、临时服务重试和退避；层间等待不占 agent 执行位置。

显式选择也遵守层级屏障：所选组的祖先和前面各层均须完成。已有整层去重结果时可只继续所选分支；去重批次尚未完成时，必须完整运行本层，不偷偷启动或修改未选分支。某些分支未完成时，下一层继续等待。

## 组轮廓与 review

依据当前组、素体参考和父组完成 SVG 绘制独立纯矢量色块，沿用画布和 viewBox，以唯一容器和 data-group-path 绑定当前组。先整图 blend 定位，再 crop / scale 放大，用 blend 和 edge 分块核对全部可见区域、可靠边缘、接缝、孔洞、开口和尖端，发现问题先修正再复查。连续形体不刻意挖缝，结构明确的分离区域保留。大片直接遮挡补全留给后续阶段。

子组的职责受父完成范围约束。父内可修缺漏仍须返修；候选已贴父边界、只有扩大父范围才能恢复的参考区域，在 feedback 中明确记录为上游限制，不再要求子组越界。仅有已确认的上游限制、父内检查均通过时可通过当前轮；这不代表上游参考偏差已修复，也不改变程序的父范围校验。

同组绘制与返修保留一个 thread，每次 review 使用新的只读会话。每组最多两次正式 review：绘制自检 → review 1 → 返修自检 → review 2 → 返修自检 → 下一阶段。任一轮 pass 可提前结束；第二轮 revise 落实后不做第三轮。原 verdict 保留，事实推导结果区分 pass 与 repaired，不把 repaired 称为独立审查通过。轮数来自报告 reviews，跨启动累计；服务重试不额外消费轮数。

review 通过 submit_review 保存候选哈希、结论、反馈和实际观察图。返修后的哈希写入 repairedCandidateHash，只有它匹配当前正式 SVG 才证明返修落实。groups/<id>/step01/outline.repairs/<序号>/ 保存反馈和实际提示词，过程目录存在或数量增加都不能证明返修成功。反馈和失败草稿保留；结束、pending 或异常时关闭绘制会话，跨启动只恢复产物和事实记录。

通用正文来自 prompts/5-组轮廓.md 和 6-轮廓review.md；prompts/groups/<完整ID>/outline.md、review.md 分别完整替换对应正文，不继承父组特化。返修附加 prompts/7-轮廓返修.md。绘制、返修与 review 只核对原参考的可见轮廓，不提供生图；辅助生图由遮挡补全使用。先确认归属和主要形体，再检查局部边缘；大错误可重画当前草稿。已登记但完全遮挡的节点可交付空轮廓，经 review 确认没有可见遗漏后进入补全。preview_svg 提供独显、blend、edge 和裁剪放大；父范围沿用四倍采样与 alpha 覆盖差校验，允许贴边和共边，不扩张父范围。

## 整层去重

本层轮廓和 review 全部结束后，去重 agent 查看带组色的合成预览、原参考和各组 SVG，识别被多个组重复制作的同一个可见对象，选一个已有归属保留，只清理其他副本。合理遮挡补形或身体接缝重叠不直接扣除。保留可见覆盖、可靠边缘、孔洞和分离区域，不强制纠正分组类别。

实体身份和分层职责优先于连续性。先确认同一实体、同一控制层的重复领取，才用连续性选择保留归属；独立遮挡、隐藏根部或运动职责不同的层允许投影重合。明确独立的侧发不能因刘海或后发更连续而清空。整组清空须说明其职责由同层同实体的完整副本承担；证据不足或与分层说明冲突时保留各组并记录疑点。

工作正文为 prompts/8-同层轮廓去重.md。preview_svg 提供整体和局部观察；write_reduction_svg 只接受本层 groupId 与 SVG 文本，绑定该组草稿并验证，写后须重新预览。submit_reduction 只接受实际修改组的指定 .draft.svg；未修改组由程序按字节原样复制。本层只有一个组时无需跨组模型处理，直接复制。

全部组的输出保存为 layers/depthNN/<完整组ID>.svg，原轮廓不覆盖。验证完整输出后再发布，最后完成本层步骤，逐件记录输出哈希。部分输出和草稿不放行补形；某件输出缺失或被改动只影响该件。原本非空、去重后删空的重复组仍保留含组容器的空 SVG，由程序完成空产物和空子组结果，不调用补形／分析模型。原本完全遮挡而为空的节点仍进入补全；子组分析是否跳过取决于补全后的实际形体。

## 补形与子组

补形读取去重后的 SVG，按对应部位提示词和参考图补直接遮挡，不扩展至侧面、背面等不可见结构。补形自检的 before 同样采用去重版本，确认保留其既有形状，新增结构合理。具体部位需要专门先验，例如脸部只补完整脸型，不补完整头型。

通用正文是 prompts/9-正面遮挡补全.md；prompts/groups/<完整ID>/completion.md 独立特化，不继承父组。face 已配置脸型与完整双耳指导；只露耳缘或耳垂、耳部主体被遮住时生成并查看露出双耳的结构参考，再按当前角色比例补全。辅助图不替换原稿；源稿误认归属需报告，不能靠新增连接将其合理化。各完整 ID 的 completion.references.json 可显式列出 path/description 参考数组；相对路径从清单目录解析，无配置只用当前素体参考。没有特化正文时仍可以单独配置参考，实际图片、用途和提示词保存在 agent 请求中。

固定操作约定来自 prompts/9-补全操作约定.md，按“通用或特化正文 → 本次输入 → 操作约定”拼接，每次补全调用读取并记录正文和来源。文件缺失或为空时停止调用；改约定不必改代码，也不会自动重做已完成补全。原形保留仍由程序校验。

补全 agent 为只读会话，用 set_completion_paths 设置完整新增闭合路径列表，程序合成指定 .draft.svg。原 SVG 的正文、属性与顺序完整保留，新增路径在其下方绘制；修改新增列表后清空旧观察，须重新预览独显与 blend，再由 submit_completion 提交。发布和恢复事实时均核对保留原形，防止变换、重画、删改或属性注入；适配器不能绕过。checkCompletion 执行程序结构与父范围检查，视觉合理性在补全回合内自检，不新增独立审查循环。

自检通过后才分析组内轮廓，返回直属 group/part 并登记到树。part 同样经过绘制、review、整层去重、补形和检查，随后终止，无独立子组分析文件；kind 来自父分析结果。没有 kind 的历史节点按待分析 group 兼容。group 分析产生空列表时，事实明确其本身是最终单元，保留既有 ID 和 SVG，不造唯一同范围 part；初始层仍只识别 group。nodeKind 从明确类型或有效终止分析推导当前角色，不从尚待分析的空树猜测。

拆分使用 children-agent.ts 的只读会话，实际观察父完成稿的 svg/blend 后调用 submit_children。name 使用 snake_case，程序构造父路径下的直属 ID；拒绝重复、嵌套树、进度字段、非法类型及单 part 包装。提交前后检查父 SVG 未被改写，然后将子节点和可选 note 写入 groups/<id>/step03/children.json，它是该组子树的唯一来源。补全稿变化时拆分步骤按依赖重跑，旧拆分不能放行下一层。

正文来自 prompts/10-直属结构拆分.md，prompts/groups/<完整ID>/children.md 完整替换，10-拆分操作约定.md 始终附加。特化和通用均按独立变形、硬软、摆动、透视、绘制顺序、显隐及剪贴判断，固定纹理不机械拆；同名节点可依实际需求为 group 或 part。breast 左右一件；手臂先分左右，再分 upper_arm/forearm/hand，手分手掌和五根完整手指；腿先分左右，每侧分 leg/foot，不拆膝和脚趾。头发按完整发面、合理发根和独立控制需要规划；前发、侧发、后发是常见组织方式，不固定节点数量或树深。侧发不等同于鬓角细丝，完整统一控制的发面直接为 part；头盖可独立，也可由合理的后发单元承担，不强制巨大 base。教程作为开发先验落实在提示词，运行时不追加整套教程。

拆分参考由当前完整 ID 的 children.references.json 显式列出图片 path/description，不继承祖先清单。模型按当前疑问用 view_bitmap 查看指定图片，不预先附加所有图片；外部读取仅开放清单内的文件。hair/children.md 说明 Milly、莉尔和樱桃蛋糕天使三套参考的不同用途；第三方图片按本地资产约定准备，见 prompts/groups/hair/references/README.md。已配置但缺失的图片明确报错，不静默跳过。

hair/completion.md 补充正面被脸和身体遮住的完整后发联合范围，给子组提供足够父范围；不制作侧视、后视或九轴关键形。子层去重明确区分底形与其上五官、虹膜、breast 等合法覆盖。子节点仍受父组完成范围约束，当前层全部结束才进入下一层。CLI --max-depth 控制处理层数，1 完成根层并登记下一层，2 制作到第二层并登记第三层，不改变拆分语义。

## 步骤目录与草稿发布

所有 SVG 制作接口，包括绘制、返修、去重、补形和合并，统一先写指定的 .draft.svg。验证与回合成功后才发布正式 SVG。每个步骤是带 .running／.completed 标记的目录（shared/part/part-steps.ts，规则见 shared/step-chain.ts）：

| 步骤 | 目录与产物 |
| --- | --- |
| 首次分组 | initial/step01/groups.json |
| 轮廓与复核 | groups/<id>/step01/：outline.svg、review.json、outline.repairs/、session.json |
| 同层去重 | layers/depthNN/<id>.svg |
| 补全与检查 | groups/<id>/step02/：check.json、session.json，产物 parts/<id>.svg |
| 直属子组拆分 | groups/<id>/step03/children.json |
| 整树预览合并 | merge/，产物 preview.svg |
| 遮挡层级表及逐件检查 | occlusion/（含 candidate.svg），产物 occlusion.json |

子组目录嵌套为 groups/<父>/children/<名>。依赖写成「步骤#产物」，只读该产物的最新哈希；重新生成相同字节时下游保留，产物变化只重跑真实使用者。删除 .completed 或产物即重跑该步骤及下游；已完成步骤记录的产物被手改时拒绝直接续跑。重跑先删除整个步骤目录，其中的复核记录和会话随之重置。补全读取的同级去重稿写成依赖；图片参考和提示词编辑仍需显式重跑。

groups.json 是组树视图，只保留可编辑的名称、note 和元数据；结构、kind 与顺序来自首次分组和各拆分记录。SVG 哈希兼容 LF/CRLF 差异。新运行不创建或读取 progress.json；旧 stages/ 布局的运行不迁移，续跑报错。不删除原始参考、调用日志和返修诊断，也不清其他 raster 工作目录。

全部节点及后代完成后进入程序合并，默认实现为 mergePartSvgs，不调用模型。parts 仅包含终止叶节点，完整树另传；按树顺序保留逻辑容器并嵌入各 part，父组引导底形不重复绘制，各 SVG 的资源 ID 隔离。写 preview.draft.svg，验证后发布 preview.svg，与 groups.json 同目录；SVG 记录对应树的节点 ID、父子关系与 kind，供 part-preview 核对。merge 步骤输入未变时预览继续复用，未完成树不会发布。事实读取和调度测试使用本地模拟 agent，不证明真实模型的拆分、去重或视觉审查质量。

## 最后一步：整件深度规划

preview.svg 生成后调用 planOcclusion，为每个终止 part 设置一个整体固定深度，统一从后到前排序。组树只表示包含关系，原结构预览的叠放顺序不证明实际前后。agent 依据原图、完整 SVG 与必要的去重轮廓，以 propose_occlusion 提交全表；查看候选叠放预览，逐件对照完整部件的原图叠加，用 check_occlusion_part 确认整件深度。修订清空检查结论，原输入的观察可复用；全部检查完成后 submit_occlusion。几何连接余量或形状出入记录为待修说明，本步保持部件树和源 SVG。

程序原子保存独立的 occlusion.json，不向 groups.json 混入层级状态。version 为 2，direction 为 back-to-front；layers 覆盖每个叶节点一次，每行仅含 id、连续递增的固定 level、深度依据 note、通过的 check。数值越大越靠前，每个 part 全部区域共用该深度。候选预览直接按固定深度叠放完整部件。

sourceHash 绑定树语义、完整与去重 SVG、参考图、preview 和规划提示词。恢复时旧版本、缺失、损坏、漏项、漏检、深度非法或指纹变化，仅重做此步；已有 preview 与上游事实保留。整体 completed 要求预览与当前深度表均完成。

本步的结果仅供后续 raster 流程读取；RGB 控制图在 raster 第一步即时生成。
