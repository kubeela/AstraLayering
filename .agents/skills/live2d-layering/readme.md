# Live2D 人物分层技能

本目录基于 Live2D 实际皮套制作方法，重构角色 SVG 分层流程。目标是在保持角色设计与人物辨识度的基础上，按需整理参考画法，准备适合表情变化、转头、身体运动和物理摆动的部件，让后续皮套动画更加生动、衔接自然。

本目录是正式技能 `$live2d-layering`，通过 [SKILL.md](SKILL.md) 的通用规则调度节点；具体制作方法由各节点提示词规定。旧实现移至 `archive/svg-layering/`，仅供历史追溯。

**接口迁移中：**[第 2 步](2.皮套结构识别/流程.yaml)输出嵌套 `group` 树 `structure/groups.json`，[第 3 步](3.大层分层稿/流程.yaml)按叶 group 绘制并审查分组色稿。第 4 步及后续仍有旧 `kind/part` 编排，待下一轮简化；下文的旧版后续节点说明暂作改造参考。

当前按暂定顺序逐步建立节点；[根目录流程文件](流程.yaml)声明外部输入与选项。已建立角色参考准备、皮套结构识别、[大层分层稿](3.大层分层稿)和[专项细化](4.专项细化)。专项细化先生成整图线稿参考，再由总控按 kind 展开对应模板。当前依次执行 [face 模板](templates/部件专项/face)、[eyes 模板](templates/部件专项/eyes)、[mouth 模板](templates/部件专项/mouth)、[hair 模板](templates/部件专项/hair)、[body 模板](templates/部件专项/body)、[lower_body 模板](templates/部件专项/lower_body)与 [arms 模板](templates/部件专项/arms)。face 先取色并逐步细化；eyes 按计划逐眼细化和镜像组装；mouth 为线稿、取色、统一着色三步；hair 生成参考后分区完成线稿、取色、层次与关联投影；body 完成身体构型与连接面、独立取色、颈肩/胸腹腰着色及身体承影；lower_body取色后先完成骨盆，再一次完成双腿和足部；arms取色并完成双臂后，生成手部补全参考，由专门会话连续完成双手线稿和着色。常规绘制共用refinement_drawing（Astra-xhigh），双手另用hands_drawing（Astra-xhigh）。

新流程采用 [Workflow 文档 DSL](docs/workflow-dsl.md)：从 `1` 统一编号，通过 `1.1` 等子编号展开步骤，同编号的 `parallel` 节点表示并行批次；节点内的 `流程.yaml` 说明输入来源、可选分支、输出与 review。提示词继续作为各 worker 的独立任务资料。

运行选项由负责判断的 agent 核对根流程声明后，使用 Python 标准库实现的[选项工具](tools/readme.md) `options.py`，写入本轮工作根目录的平级 `options.json`；总控读取并核对类型后调度。1.1 同时决定 `simplify` 和 `wear_cloth`。1.2 先按 `simplify` 选择原图或简化图；1.3 在 `wear_cloth: true` 时替换衣物，否则透传前一步选出的图。

穿着待替换衣物的主体在 1.3 使用内置简化连体服。1.1 由 `reference_prep` worker 判断选项；1.2 与 1.3 若需生图，由总控直接调用 imagegen。第 2 步由 `group_planning` worker 建立嵌套分组树，输出 `structure/groups.json`；临时连体服仅供判断身体姿态，分组排除衣服并建立被其遮住的身体组。旧版[拆分规划](docs/拆分规划.md)仅供后续改造参考。

当前第 2—3 步按嵌套 group 树组织主体，叶组是色稿绘制单位；衣装的独立拆分交给 `live2d-clothing`。第 4 步以下的旧 `kind/part` 专项说明仍留作迁移参考。

原图已有的眼眶积泪、泪滴和泪流归对应eyes内部组件，由线稿、取色、4.3装饰着色及第5步效果接续完成；汗珠和脸部附着符号归face内部，在第5步完成底形与自身颜色、第6步处理必要效果。泪液经过脸颊仍由eyes负责，两组不重复绘制；只保留输入已有素材，新增表情和动画控制留后续专题，不另设表情组。
眼本体采用镜像时，原图两侧实际泪液仍在现有任务内按所属侧制作，标data-mirror="exclude"并在最终组装保留；不把单侧泪复制到另一眼，也不因此重画双眼本体或增加节点。基础分类共11类，arms后的专项按physics_details → special_parts → clothing → generic推进，服装作为换装重点放在人物专项最后，generic按实际独立对象收尾；physics_details、special_parts、generic模板已建立，clothing已接入一次Sol-xhigh素体整理，独立衣装制作已有[live2d-clothing 技能](../live2d-clothing/SKILL.md)，按用户要求另行启动。

## 使用技能

在本仓库的新任务中调用技能，提供角色原图和绝对输出目录，例如：

```text
使用 $live2d-layering，完成角色分层与素体制作。
原图：<图片的绝对路径，也可以附图>
输出目录：/绝对路径/本轮输出
```

参考图判断、按需改绘、连体服替换、分组树生成和分组色稿已更新；第 4 步及以后正在迁移。用户只需提供原图和绝对输出路径；`simplify` 与 `wear_cloth` 由 `reference_prep` 判断，用户也可明确指定。运行进度保存在工作根目录的 `运行记录.md`。

技能目录为 `.agents/skills/live2d-layering/`；模型和推理强度读取各节点的 `.model` 标记，技能入口不另行维护具体步骤清单。

## 重构方向

- **先完整分出独立部件，再按组展开内部拆分与线稿精修。** 前期落实每个部件的外形、隐藏底形和遮挡；kind 组织专项工作，内部细分依据教程、画风和实际需求决定。
- **补全服务于预期动作。** 除当前姿态的隐藏底形，还要考虑运动会露出的区域、环绕部件的前后面和关节搭接。
- **分别处理部件归属、绘制顺序和运动关系。** 同一物件可以有多个前后绘制片段；投影需要同时关联投影来源与承影部件。
- **保留必要的体积与材质信息。** 自身明暗、外来投影、需要独立变化的高光和半透明材质，按用途组织。裁切控制显示范围，动画绑定负责运动时的跟随关系。
- **在后续动画表情专题检查动作。** 关注眨眼、张嘴、适度转头、关节连接和发束摆动，并区分素材问题与绑定问题；当前眼口专项以默认状态、完整底形、裁切和静态独显验收。

普通用户以提供一张角色图为起点，流程采用可解释的基础动作规格；具体幅度和细分颗粒度逐步验证。大幅改变手势或姿势所需的新素材，作为后续扩展。

主流程的目标确定为可复用人物素体：简化连体服只作中间参考，clothing使用独立Sol-xhigh会话一次移出临时衣物、清理相关效果并修补新露出局部；原服装还原或新衣装叠加另建工作流，详见[素体与衣装流程规划](docs/素体与衣装流程规划.md)。原始衣装参考与可复用附件随交付保留，身体自身明暗及仍成立的投影关系继续保留；素体整理与独立衣装制作均已有 Jianma 静态案例，见[案例快照](../../../demos/jianma-current-case/readme.md)。衣装另由 [live2d-clothing](../live2d-clothing/SKILL.md) 启动。

## 主流程的职责与终点

以下是已确定的职责顺序，clothing的素体整理任务已接入；各组完成后以最新完整SVG直接交付，不重新串行执行整图线稿、配色和材质制作。

| 顺序 | 工作 | 主要结果 |
| --- | --- | --- |
| 1. 角色参考准备 | 同时判断画法与是否穿着待替换衣物；按需改绘，再决定换连体服或直接传递所选参考图 | `base_subject.image`，供分组与色稿使用 |
| 2. 皮套结构识别 | 按语义与空间结构建立可嵌套的 group 树；眼睛停在整眼层，头发可先分基本几何结构；排除临时连体服并识别其下身体 | `structure/groups.json` |
| 3. 大层分层稿 | 按 `groups.json` 的每个叶组建立可独显的色块底形与遮挡，逐组对比轮廓并独立审查 | 叶组齐全、轮廓与参考图吻合的色块 SVG 与预览 |
| 4. 按组专项制作与素体收尾 | 逐组完成内部拆分、轮廓、着色与效果；clothing移出临时衣物及其依赖并局部修补，generic继续完成实际独立对象 | 可复用人物素体SVG、预览与后续衣装交接 |

服装还原与叠加另走衣装工作流，动作试装与绑定另走后续动画专题。

参考判断与部件识别使用 GPT-6 Sol-xhigh；参考图生成由总控直接调用 imagegen，一次生成后作为下游参考使用；色块分层绘制及其独立审查使用 GPT-6 Astra-xhigh。各组色盘由各自独立的GPT-6 Sol-medium会话提取，常规绘制共用refinement_drawing（GPT-6 Astra-xhigh），双手线稿与着色另用hands_drawing（同模型和强度）；模型标记和worker名保存在各模板任务中。

## 大层分层稿

| 节点 | 输入 | 输出 |
| --- | --- | --- |
| [3 大层分层稿](3.大层分层稿/流程.yaml) | 角色彩图、`structure/groups.json` | `block-layers/character.svg`、`block-layers/preview.png` |
| 3 review | 角色彩图、`structure/groups.json`、候选 SVG | `reviews/group_layers/审查.md` 及轮廓对照图 |

第 3 步根据[本节点提示词](3.大层分层稿/提示词.txt)递归读取 group 树，最底层的每个叶组是绘制和独显的单位；父组只组织归属。前景主体除临时连体服外都应落在叶组；衣服遮住的身体由色稿补出。同一叶组如有前后穿插，可以拆成多个绘制段，但共享完整 `data-group-path`，不用旧 `data-part`、`data-kind`。整图线稿参考在后续标准节点 [4.1](4.专项细化/4.1.整图线稿参考/流程.yaml)生成。

当前完成叶组层：整眼与完整嘴部保留外形，眼白眼黑和牙舌等内部层后续展开。各组以可辨标记色建立底形，必须把参考图可见的外缘、接界描线、孔洞和穿插轮廓描准；不处理正式色彩与明暗。隐藏部分补全到各组底形中，不覆盖已校准的可见轮廓。

绘制者和[独立审查](3.大层分层稿/review/提示词.txt)都使用本节点绑定的预览与轮廓对照工具，核对整图、各大类 group 合并叶组后的外形，再逐个叶组独显，对照轮廓叠加图与混合图。明显偏移、漏组或错叠按 DSL 交原 worker 返修并复验。

叶组以从根到叶的路径标识，例如 `face/eyes/left_eye`；同一叶跨层的绘制段共享路径，各段 `id` 不同。独显时合看这些段，也检查与相邻叶组的实际组合边界。内部细拆可以后置，叶组、真实孔洞和隐藏补全必须在当前落实。

## 专项细化

[4.专项细化](4.专项细化)是分组目录，按顺序执行两个标准节点：

| 节点 | 执行方式 | 产物 |
| --- | --- | --- |
| [4.1 整图线稿参考](4.专项细化/4.1.整图线稿参考/流程.yaml) | 总控直接调用 imagegen 一次 | `references/line-art.png` |
| [4.2 按组细化](4.专项细化/4.2.按组细化/流程.yaml) | 总控执行 foreach，各组复用同一个 Astra-xhigh worker | `refinement/groups/<group.id>/` 下的整图 SVG、预览和说明 |

[4.2 流程 YAML](4.专项细化/4.2.按组细化/流程.yaml)只供总控读取，声明分组、优先级、模板路径与 SVG 传递。枚举项按 kind 汇集相关部件，generic 按独立对象分别成组；完整优先顺序为face → eyes → mouth → hair → body → lower_body → arms → physics_details → special_parts → clothing → generic。模板路径直接为 `templates/部件专项/<kind>/`，已建立的模板进入执行队列，未建立的类别记为未接入。

后续四组的作画准备见[角度X与分层规划](docs/拆分规划.md#后续四组的顺序与角度x素材准备)：physics_details、special_parts、generic共用前置结构分析、按需补全参考、完整线稿与结构审查、独立色盘、分批着色成稿的方法，clothing采用一次素体整理任务；按派发组分析一次，具体操作分别写入各自实际任务。线稿定稿时按改变的来源和承影面修正已有投影的几何、引用与裁切，后续着色完成光影匹配，不增加全局光影重审或逐件多视图验收。

总控逐组展开模板的编号任务，读取各任务的流程 YAML 和模型标记，将具体提示词路径、当前分组及实际输入输出交给 worker。4.2 没有额外提示词或 worker；常规绘制通过 `worker: refinement_drawing` 复用Astra会话，arms双手的两次绘制使用专门的 `worker: hands_drawing`。会话切换时仍传最新完整SVG，具体规则见 [DSL 动态派发](docs/workflow-dsl.md#8-按产物动态派发)。

取色不新增全局光影判断；大小臂承影在第2步收尾，手部承影在第5步收尾，body/hair等已有影继续沿用原归属，仅在本轮源形改变时维护受影响的原引用/效果。未来新姿态产生的影留后续关联；部件自身起伏和普通柔亮随着色完成。

所有任务直接放配置、提示词和模型，不按左右手/每指额外派发；色盘和生图保持SVG carry，线稿review通过后再着色，第5步直接发布carry，无最终review、组装或总控重复检查。后续绘制会话须读取第5步成稿，不能用其早先的第2步稿覆盖双手；模板已接入，本次未启动arms绘制。

## 第一步：角色参考与按需改绘

旧前置同时要求精简高清渲染、生成平涂版本和改成平视角；旧换装步骤继续要求平涂风格与少量明暗。它有助于降低重绘难度，也可能丢掉后续体积、投影和材质还原的依据。

需要区分两个用途：

- **准备便于后续重绘的角色参考**：根据原图决定是否整理光影、简化渲染，或转为结构清晰的插画表现。
- **在 SVG 绘制中先建立基础色，再绘制明暗**：属于分层制作方法，可以继续保留；这不要求参考图本身没有阴影。

`simplify` 以内置风格参考为目标：眼部可见时优先比较眼睛、眼周和脸部；不可见或不存在时，比较头发、皮肤、衣物或物件表面的画法。清晰线条与色块定形，辅以局部渐变、高光，已属于适合的二维插画，设为 `false`；主要靠连续晕染、厚涂或真实光照塑形，且与参考画法明显不同时设为 `true`。没有眼睛、局部画面、线条粗细不同或物件不是人物都不单独触发改绘；轮廓和衣物分区清楚也不能代替画风判断。改绘依据原图的人物设计和基本配色，可适当调整头身比并整合细碎部分。

`wear_cloth: true` 时原有服装随后会替换为简化连体服，因此旧衣料、服饰纹样及服装层次的复杂度不单独触发参考改绘。原图继续作为人物特征依据，参考改绘本身也不能保证后续重建完全一致。

| 输入情况 | 待验证的处理方向 |
| --- | --- |
| 角色完整、轮廓与结构清楚，现有插画表现适合重绘 | 直接使用，省去参考改绘 |
| 插画结构清楚，包含半透明衣料、自然渐变或复杂的待替换服装 | 直接使用；保留材质表达，随后完成换装 |
| 强环境光、背景效果或模糊遮蔽了部件边界 | 针对妨碍识别的部分整理参考，同时保留原图的必要结构与材质依据 |
| 偏 3D 或写实渲染，主要靠渐变、反光和材质表现形体 | 按需转为轮廓清楚、色区稳定、明暗简洁的插画立绘 |
| 厚涂、复杂纹理或明显艺术化处理 | 判断笔触与细节是否妨碍结构还原，按需整理画法并保留角色特征 |
| 视角或姿势影响目标动作 | 单独讨论姿态适配，与色彩、明暗简化分别处理 |

Live2D 的素材制作允许部件包含线条、填色、滤镜效果，也允许把阴影独立成层；纯平涂并非其素材前提，见[官方素材说明](https://docs.live2d.com/en/cubism-editor-manual/precautions-for-psd-data/)。艺术化图片的困难，需要结合结构可辨认程度、目标动作和制作成本判断。对本项目而言，复杂画风还会增加自动补全与可编辑 SVG 重建的难度，这需要案例验证。

后续可以用同一张图比较直接重建与先改绘参考的结果，观察人物还原、必要明暗和材质保留、下游分层表现，验证参考适配的适用条件。生成图仍按一次生成的参考使用，效果通过后续制作判断。

## physics_details、special_parts、generic：共用方法，分别执行

入口：[物理饰品](templates/部件专项/physics_details)、[特殊部件](templates/部件专项/special_parts)、[独立对象](templates/部件专项/generic)；三个目录各有五个直接任务，工序和产物一致，任务提示词分别落实各类对象的实际拆分、材料与连接要求。

| 步骤 | 模型 | 交付与职责 |
| --- | --- | --- |
| 1 结构分析 | 独立Sol-medium | 结构安排.md、补全要求.txt；逐对象判断现有结构、完整内部件、前后/侧面、固定点、软硬、左右转向显露、绘制批次及受影响旧投影 |
| 2 按需补全参考 | imagegen，最多一次 | 需要时生成组合线稿和完整部件参考，不需要时沿用既有线稿；仅传原图与自然语言补全要求 |
| 3 完整线稿与关联投影 | Astra-xhigh，独立Astra-xhigh结构review | 完整SVG、一张结构对照、短衔接记录；对原图校形、完整补面，并修正改形影响的旧影形/缓存/引用/裁切 |
| 4 部件色盘 | 独立Sol-medium | palette.png/JSON；模型按实际材料选择采样方法与层次，工具仅提供可覆盖展示和通用取色 |
| 5 着色与效果成稿 | 继续绘制Astra-xhigh | 完整底色、各面体积和纹理、自然线质、独立反光及投影颜色/柔度，直接交最终SVG/预览/一张对照 |

physics_details重点是固定座、柔性连接、硬坠和包围前后片，衣上饰品继续指向真实衣物；special_parts重点是兽耳前/内/后、必要侧面、完整根部及手持穿插；generic按每个实际独立对象判断。三组都按结构和运动需要补侧面、背面、内面或环绕后段，这些需求可以同时存在；例如脚链补完整后段接回两侧，需要厚度时再一并补侧面。补全不限定于clothing，也不默认每件都补全背面或一面一层；简单对象合批、复杂对象按结构先后制作，表内批次在对应绘制任务中执行，不逐小件增加调度。

生图分支读取当前组结构安排的reference_needed，缺值回原分析worker补正；true时imagegen.inputs只选原图和补全要求，结构表与路径不交给生图模型，false时不生成假占位图。三个组均保持最新SVG carry，特别是从arms双手会话切回绘制会话时；generic的结构/参考/色盘按当前group.id隔离。几何改动的跨kind旧投影仍归实际承影组，线稿改几何、着色调观感，最后绘制者一次自查，无额外拼装、成稿review或总控视觉审查。
