# 组、独立部件与内部拆分

本文供流程编辑时核对教程与职责。worker 直接执行各自节点内的提示词，无需读取本文。

第 2 步读取本轮 `base_subject.image`，输出独立部件清单；第 3 步逐件建立完整底形、补全与遮挡；后续按组进入部件内部拆分和线稿精修。人物以简化连体服参考为准，非人物先按实际语义对象识别。

## 三个层次

| 层次 | 含义 | 例子与制作时机 |
| --- | --- | --- |
| 1. 部件内部拆分 | 在一个完整部件内，为具体动作、画法或材质控制进一步拆分 | 左眼内的眼睑、眼白、眼黑；后续眼部专项展开 |
| 2. 独立部件 | 当前需要分别保存完整形体和遮挡关系的语义对象或基础结构 | 左眼、右眼、头脸、躯干、连体服、整副眼镜；前期识别并逐件分层 |
| 3. 组 | 组织相关独立部件的制作工作，使用 `kind` 标记 | 眼部组包含左右眼，头发组包含前后发与主要发束；后续按组精修 |

这些名称区分制作粒度。进入专项后，眼白、眼黑也会成为独立图层，并保留所属眼部的关联。前期先把第 2 层做完整，第 3 层组织后续工作，第 1 层按专项展开。

SVG 的绘制组是另一项实现安排：一个独立部件发生前后穿插时可以有多个绘制组，共享 `data-part`。同一 `kind` 的部件也可能分布在不同绘制顺序中，按类别收集不要求它们在画面上粘连或连续排列。

## 边界依据

- [旧版部件规划](../../../../archive/svg-layering/workflows/1.确定基础角色与补全范围/生成提示词.txt)按实际对象、替换、显隐与前后关系识别主要部件。[旧版绘制](../../../../archive/svg-layering/workflows/2.建立完整部件与遮挡/生成提示词.txt)已验证逐件底形、衣下身体、跨层分段和独显检查的做法，继续沿用。
- [教程的通用拆分](../../../../live2d-tutorial-text/2.部件拆分总原则.txt)先完成头脸、身体、肢体和整眼等部件，再进入各部位细节；[眼睛专题](../../../../live2d-tutorial-text/3.眼睛拆分和制作指南.txt)从整眼继续拆眼睑、眼白和眼内部件。
- [拆分与否](../../../../live2d-tutorial-text/13.判断拆分与否.txt)结合运动、绘制顺序、显隐、剪贴与项目规格判断精度。本流程将这些判断先应用于独立部件层，细致的内部控制在专项中继续判断。

边界主要看两点：是否需要把不同语义对象或主要身体结构分别保留下来；还是在同一个已识别部件内，为更细致的控制继续划分。衣服与身体、发饰与头发、手持物与手属于前者；眼白与眼黑、手指与指节、配件材质分片通常属于后者。用户明确指定了细粒度目标时，以本轮要求调整。

隐藏补全、真实孔洞和跨部件穿插始终属于当前独立部件的完整性。它们不能因内部细拆后置而省略。部件的可见轮廓精度也不随拆分粒度降低。

## 默认粒度与通用物件

检查范围覆盖上述全部部件专题，但只输出实际存在、被遮挡且基础动作需要补全、或确有疑义的对象。列表是观察范围，不要求为每张图补造全部项目，也不额外设计表情或替换姿势。

| 对象 | 当前独立部件层 | 后续部件内部拆分 |
| --- | --- | --- |
| 眼部 | 左眼、右眼，外形和被头发遮住的延续准确；已有泪液在所属眼的说明中记录 | 上下眼睑、眼白、眼黑、睫毛、高光，以及实际积泪/泪滴/泪流等内部组件 |
| 嘴部 | 当前姿态下的完整嘴部，闭嘴也保留 | 嘴上、嘴下、口内、牙舌及口型所需补画 |
| 头脸 | 头脸底形、左右眉毛、鼻子、左右普通耳朵等；已有汗珠/附着符号在脸底说明中记录 | 转头所需的内部结构，实际汗珠和脸部附着素材的独立底形与画法细分 |
| 头发 | 前发、侧发、后发、马尾等，必要的主要发束分别保留 | 更细的发束、发丝及精细物理控制 |
| 身体与服装 | 脖子、躯干、骨盆与整件连体服，身体和衣服分别完整 | 具体形变所需的内部结构与服装细片 |
| 四肢 | 左右大臂、小臂、手、大腿、小腿、脚，关节处有搭接 | 手指、指节及更细的形变结构 |
| 配件 | 整副眼镜、整件耳坠、发饰、手持物等，与承载对象分开 | 镜片与镜框、链条与坠体、材质分片等 |
| 通用物件 | 桌子、路灯、杯子等语义对象分别保留 | 物件内部的具体活动结构、材质与装饰细分 |

通用对象先按语义与独立性保留整件，例如桌子、杯子、路灯各有自己的 part。`generic` 表示采用通用制作方法，各对象的内部拆分与分组在后续专项中确定。

半透明物件先以整件对象独立保存，其内部透明与不透明区域留到材质专项。透过它看到的后方对象仍是后方部件。色块稿的标记色仅用于结构检查，真实透明度在后续恢复。

一个配件或发束穿过其他部件前后时，当前就应分绘制段并补全；各段仍归属同一个 part。真实的环孔、指间空隙和主发束之间的开口也在当前保留。内部拆分后置不要求把这些结构压成整块。

## 清单、分层和后续组的衔接

输出为 `parts.yaml`：`subject` 和 `parts`。每个部件有稳定的 `id`、`name`、`kind`、`visibility` 和 `separate_for`；连接、包围、穿插或隐藏补全需求写入简短原因。

`parts` 列表只记录当前独立部件层，不把组作为部件条目，也不递归展开内部层。先确定 part，再标记 `kind`；身体与服装分别归入 `body`、`clothing`。输出字段沿用现有格式，三层概念不增加额外清单或分类步骤。

色块绘制以 `data-part` 对应清单 id，以 `data-kind` 记录制作组；每个 part 有真实底形，跨层分段共享 part 归属。review 核对独立部件是否齐全、形状是否贴合、底形是否完整和组合遮挡是否成立。无需为了当前验收提前画出眼白眼黑等内部功能层，也不能以后续会精修为由省略独立部件。

后续线稿按组处理相关 part，在组内展开必要的内部拆分、补画和笔触精修。通用物件可按语义对象组织专项。细看后发现分类、部件边界或遮挡错误时可以调整，并记录实际变化，复核受影响的相邻部件与整图；未改变的 part 保留原 id。后续节点的具体派发与输出随节点建立，本文件仅定义制作职责与粒度。

当前 face 先[提取脸部色盘](../templates/部件专项/face/1.脸部色盘/提示词.txt)，再由[脸型校准与绘制](../templates/部件专项/face/2.脸型校准与绘制/提示词.txt)集中处理脸型、脸底肤色和轮廓线；周围头发、眼眉等作为定位与遮挡依据，存在明确偏差时联动校准。脸底色与轮廓线分别保存，便于后续独立控制；粗稿经校形后再精修线宽和轮廓色，使线条与肤色协调。

随后用[关联部件校准](../templates/部件专项/face/3.关联部件校准/提示词.txt)检查头脸的组合关系：保留已完成脸底，对照彩图调整关联 part 的位置、外形和显露范围。关联关系可以跨越 kind，参与校准的眼、嘴、头发、颈部或配件仍留在原组；本次几何调整不代表这些专项已完成，也不重新拆分或改写清单。

[肤色与局部层次](../templates/部件专项/face/4.肤色与局部层次/提示词.txt)只处理脸底自身的肤色及连续冷暖变化。色盘辅助取色，原彩图决定分布；妆容、五官明暗和外来投影分别保留归属。

[脸部部件绘制](../templates/部件专项/face/5.脸部部件绘制/提示词.txt)结合教程的枚举方法完成眉、鼻、耳、红晕。左右眉与红晕分别独立；眉周透明，鼻标记与自身明暗可分开调整，耳根补全且隐藏封口不描线。按画法选择色面、必要结构线和柔边，避免统一粗黑描边，红晕通常以扩散色面表达。
原图已有汗珠和脸部附着符号也在face第5步完成校形、完整底形及自身颜色，作为脸底所属的独立内部组件；第6步整理它们确有的独立高光与投影。泪液属于来源眼，即使位于脸颊也由eyes制作，face只保留其下完整肤色；不另设表情制作组，不新增哭泣/流汗素材或动画任务。

[投影与高光效果](../templates/部件专项/face/6.投影与高光效果/提示词.txt)在部件绘制后统一整理独立效果。投影保留来源与承影对象，高光保留承载对象；静态 SVG 先裁切到目标完整表面，效果路径仍可编辑，后续据此建立动画跟随和剪切关系。每项说明实际效果或无可见依据，已有合格光影继续沿用。眼口内部、头发及配件本体由对应专项继续。

## eyes 内部部件与效果归属

[眼睛教程](../../../../live2d-tutorial-text/3.眼睛拆分和制作指南.txt)的三类部件和内部层序是拆分依据：

| 类别 | 部件 | 制作职责 |
| --- | --- | --- |
| 轮廓 | 上眼睑、下眼睑、眼白 | 4.1着色，完整眼白延伸到眼睑下并补满眼黑背后 |
| 眼内 | 眼黑、高光 | 4.2单独制作眼黑颜色层次；高光在第5步独立制作，仍归眼内 |
| 装饰 | 上睫毛、下睫毛、眼皮及实际附加装饰 | 4.3处理正式颜色与线感；复杂眼周肤色/妆色在4.4单独完成 |

原图已有泪液作为对应眼内部组件，在第2步完成积泪/泪滴或条状泪流的完整形状和独立控制，第3步取色，4.3完成本体颜色与透明感，第5步制作实际独立反光及必要投影；眼周皮肤步骤保留泪液下的完整肤色。泪液不随虹膜移动，不套眼裂clip，必要的显示范围mask独立于完整滴体，动态循环与情绪开关后续绑定。

眼白裁切眼内，上下眼睑在眼内部件前方；眼皮通常在眼白后，下睫毛在眼白前。任务制作顺序不改这些关系，也不为流程编造不存在的部件。

第2步先校准输入色块眼位、眼型及比例，再按三类部件制作线稿。[独立线稿审查](../templates/部件专项/eyes/2.逐眼线稿/review/提示词.txt)通过后固定主要几何，允许后续添加必要颜色层和眼周皮肤色形。辅助显示标记 construction-guide，着色时关闭，正式眼线按原图保留。

第3步由 Sol-medium [独立提取色盘](../templates/部件专项/eyes/3.眼部色盘/提示词.txt)，给实际像素色值、位置、用途与空间层次说明。第4步循环当前眼的四个真实子任务，由同一 Astra-xhigh 顺序绘制并传递最新整图；各自的工作和验收写在对应提示词中。

[眼黑颜色与层次](../templates/部件专项/eyes/4.逐眼着色/4.2.眼黑颜色与层次/提示词.txt)检查基础色、纵向深浅、边缘/中心、局部反射色和瞳孔过渡。原图层次丰富时不能只用单一 fill 或一条渐变，各层需有原图位置依据；无对应纹样/变化时不强加。自身颜色跟随眼黑，外来投影不烙入其中，独立高光单独控制。

[眼周皮肤明暗](../templates/部件专项/eyes/4.逐眼着色/4.4.眼周皮肤明暗/提示词.txt)逐项处理眼窝、上下眼皮、内外眼角和下眼缘周围。肤色体积与真实妆色归当前眼独立成组，按皮肤表面裁切，保护眼裂与正式眼线，不用眼白 clip 裁掉眼周颜色，不进眼珠视线组、不烙进 face。去重已有 face 层次不等于省略眼周明暗。

[第5步投影与高光](../templates/部件专项/eyes/5.逐眼投影与高光/提示词.txt)按来源×目标保留独立效果与完整路径，记录 data-source-part/data-target-part 和内部 id；虹膜效果受虹膜表面与眼裂共同限制，软边也不越界。关闭效果应回到包含4.1–4.4的干净着色稿，眼黑自身层次及眼周明暗不能被一起删除。检查全开、关闭、独显和来源关闭无残影，静态关系不等于完成动画绑定。

### 镜像、头发与审查

计划用 Sol-medium 在开始前锁定并记录 SHA-256，后续不得自行改变对称策略。true只画主眼本体，所有着色/效果完成后第6步镜像本体，包含虹膜各层和眼周皮肤；原图两侧实际泪液在第2/4.3/5步各任务内按侧别制作，泪液及其相关效果标data-mirror="exclude"，第6步保留不克隆，单侧泪不触发两眼本体重画。false按计划分别制作当前眼及其泪液。每只眼与前发保持统一层序；透发来自头发材质，禁止发上睫毛碎片、同源前景实例或局部露出窗口。

[最终审查](../templates/部件专项/eyes/6.镜像组装与成稿审查/review/提示词.txt)同时核对几何/可见比例、眼黑丰富度、眼周皮肤和独立效果。原图与候选对照包含眼周皮肤，不能只看眼裂。返修定位到对应子任务，复用同版证据；不以省交接或审查次数为由省去明确制作职责，也不重复无变化项目的全套量测。

## mouth 内部部件与静态验收

### 角度X需要哪些画面信息

[第1讲](../../../../live2d-tutorial-text/1.立体感的来源与制作.txt)的角度X指水平方向的左右转向，靠面的变形、相对错位与遮挡表现深度；它不是画布内绕一个点转动，那属于角度Z。官方也把ParamAngleX定义为左右转头；参数取值本身不证明素材已能正确表现相应视觉转角。[官方标准参数](https://docs.live2d.com/en/cubism-editor-manual/standard-parameter-list/)

作画时要能回答：左转/右转会露出哪块原先隐藏的形状，哪个面会收窄或展开，哪些部分会隔着头/手/身体处在不同前后位置，哪个硬件应保形、哪段软连接应弯曲。不能只把正面整件横向压缩，或因为绘制细节很多就认为已经具有转向条件。

尚未确定具体转向幅度，先以常规左右转头和对应部件跟随为准备范围；按结构连续、包围穿插、隐藏连接和预期运动确定补全范围，通常无需每件完整背面或整套360度素材，有实际需要则补完整。侧面、背面、内面与环绕后段可以同时需要，适用于所有组：例如脚链应补全脚踝后方链段并接回两侧，有厚度需求再同时补相应侧面，不能用一条窄侧边替代后方结构。补全背面也不等于必须生成背视图或单独加一个控制层，参考视图与图层颗粒度各按实际需要决定；大转角才显露的新面仍需明确动作范围后补形。

### 从教程落实到作画的六项要求

| 需求 | 作画阶段的处理 | 拆分停止条件 |
| --- | --- | --- |
| 包围与前后穿插 | 环、领口、腕带等拆前片/后片，夹住实际承载对象；把遮挡后会露出的连接补完整，保持洞口与厚薄 | 不包围、无换序、各处运动一致的对象可完整一件，不机械要求每件前后两面 |
| 可见侧面和厚度 | 硬质弧件、镜腿、弯角等按实际转向需要保留侧面/内外面，接合处连续且无隐藏封口墨线 | 正面小幅运动用一件足够时沿用；同一面上不独立变化的纹样留在所属面 |
| 软硬与固定点 | 固定座、可弯链条/布带、硬质宝石/坠体按不同运动分离，完整补根部和插接段 | 链条可用完整曲线形体供后续蒙皮，不逐环或每个装饰纹样增加控制层 |
| 图层和运动关系 | 同一实体可分多个绘制片段共享part身份，明确附着对象、固定点与默认遮挡；运动父级和绘制顺序分开表达 | 不为让整个物体一起移动，就把前后片强塞进同一不可穿插层位 |
| 自身色、反光与投影 | 自身材质随表面；需要随角度改变的金属/宝石/镜片反光独立并受本体裁切；外来投影保留来源、目标和完整影形 | 不把每个浅色面都拆成高光，不把换装后应消失的衣影烙进身体 |
| 隐藏补全和参考 | 可见处以原图为准，隐藏连接按结构推断；只有影响轮廓/穿插且无法辨明的复杂局部才需要补全/侧向参考 | 不为每件生成正侧背多视图，也不把生图臆造的侧面当原设定 |

前后片解决“可以分别显示与变形”，并不代表必须在某个固定角度突然交换层序；是否换序、何时换序由实际遮挡决定，绑定阶段再设置参数。Cubism支持将绘制顺序绑定到参数；程序化SVG则需要运行时同步管理绘制次序、几何和裁切。[官方绘制顺序说明](https://docs.live2d.com/en/cubism-editor-manual/draworder/)

### 各组重点

**physics_details先处理固定、软硬和包围关系。** [第9讲](../../../../live2d-tutorial-text/9.物理饰品与衣服细节.txt)把“跟随父对象转向”和“自身物理摆动”分成两个需求：耳钉随耳朵定位，链条弯曲，吊坠可整体转动且保持自身造型，不能一起作橡皮式拉伸；硬物转向仍允许合理透视压缩，保形不等于画面宽度永远不变。发饰即使固定也应与软头发独立，蝴蝶结可按结、翼、尾的不同摆动需求拆，环饰按前后包围拆；重复小花纹不自动成为物理单元。

当前角色可据此检查头环与枝形头饰的前后段/必要厚度、额饰的固定宝石与悬垂小坠、耳饰的连接与硬坠、飘带的带头与柔性带身、足链围踝的前后关系；这是案例映射，其他角色按实际构造决定，不固定成同一套零件清单。细枝不是发丝，宝石也不应跟着软带扭曲。

**special_parts按对象的立体结构制作。** [第10讲](../../../../live2d-tutorial-text/10.常见其他部件拆分.txt)给出帽顶/帽檐/必要里外层、兽耳前/内/后、弯角内外面、眼镜框/镜腿/可独立镜片反光等典型方案；直角、普通细尾和仅需简单扇动的翅膀不必过拆。手持物补出手后完整本体，通过原arms手指/掌的前后绘制片段夹持，道具和手仍各归原组，真实握持需调整时只局部协调接触区域，不能把手画进道具或默认重画整条手臂。

**clothing改为一次素体整理，服装制作独立成流程。** 简化连体服只作中间产物，本节点移出临时衣物及其依赖效果，修补新露出的身体缺口/衣缘色痕并保留自身明暗；原服装还原和新衣装制作按[素体与衣装流程规划](素体与衣装流程规划.md)另行落地。依据[第1讲](../../../../live2d-tutorial-text/1.立体感的来源与制作.txt)、[第9讲](../../../../live2d-tutorial-text/9.物理饰品与衣服细节.txt)与[手臂教程](../../../../live2d-tutorial-text/12.手臂细节拆分.txt)，衣装流程再处理领口/袖口/裙片/披肩的前后、侧面/背面和必要内侧，以及领子、衣襟的不同透视；完整素体不烙入衣边或服装专属投影。

随具体衣物佩戴的饰品由衣装一起管理，制作类别仍可为physics_details，固定点在SVG desc中指向真实衣物part及位置；已完成素材保留复用来源，在素体成稿中移出，后续衣装流程校准固定点、遮挡与投影，不重复画同一件饰品。后续新运行应前置识别衣物依附附件并交衣装流程制作，身体/头发直接附着的部件继续按既定范围独立保留；这些调度调整随新流程实现，动态显隐留后续绑定。

**generic用同一判断方法逐对象处理。** 输入可能是桌子、路灯、杯子或独立符号；按实际前后包围、硬软、透视与运动差异拆，不硬套人体关节。人物手持物仍优先归special_parts，不能因其“是物品”再重复归generic。

### 三组共用的制作方法

physics_details、special_parts、generic共享以下顺序；具体操作分别写进各自实际任务的提示词，clothing另用已建立的单任务素体整理模板。按当前派发组做一次前置分析，generic仍按独立对象派发，不为每个细小零件重复建立分析任务。

| 环节 | 本环节要完成的工作 |
| --- | --- |
| 结构分析 | 对照原图和现有SVG，列出可沿用的控制分组、需要重画的轮廓和缺失结构；逐对象明确附着对象/固定点、软硬、前后穿插、左右转向时显露或收窄的面、隐藏补全范围、拆分理由及绘制批次。现有分组可沿用不代表现有色块轮廓可直接描摹；简单、软硬、包围等特征可以同时存在 |
| 按需补全参考 | 仅对分析中无法辨明且影响结构的局部生成必要参考，明确需要补出的连接、内侧或侧面；可见部分仍以原图为准，不逐件生成全套多视图 |
| 完整线稿与结构审查 | 按绘制批次落实完整底形、连接余量、前后层次及自然轮廓，集中做一次独立结构审查；定稿时登记本轮改变的来源部件、承影面和关联投影，并同步修正其几何与引用 |
| 独立色盘 | 根据原图实际材质提取自身色、体积渐变、局部层次、反光和投影对照色，保留位置依据；复杂材质的层次由模型判断 |
| 分批着色、效果与成稿 | 按结构分析确定的批次完成材质、明暗、独立反光和受影响投影的颜色/柔度；简单相关对象可合批，复杂对象按结构分工，各绘制任务持续接续最新整图SVG，最后绘制者直接交成稿 |

必要的固定点、邻件id、隐藏补全说明保存在实际SVG中；结构分析使用简短制作表表达决定，不新增复杂计划JSON，后续worker直接获得与自己任务有关的具体决定。

### 线稿定稿后的关联投影修正

**线稿几何定稿就是已有投影重新对齐的触发点。** 轮廓、位置、内部拆分、前后层序或承影面发生变化时，由绘制者按本轮改变的来源id和目标id定位受影响的已有投影，包括归属face、body、hair等其他组的效果；这属于本次改形的必要收尾，不能只画新部件而留下旧影形。

- **来源改变：** 更新投影依赖的完整来源形状及其缓存，按新轮廓与原图光影关系校准影形和偏移；不能只换引用而保留旧形，也不能把来源轮廓机械涂黑充当投影。
- **承影面改变：** 更新目标轮廓、clip/mask及坐标变换；拆成多个面或改变前后穿插时，按新的实际承影关系调整裁切和层序，避免漏影、越界和重复叠影。
- **关系延续或消失：** 同一关系保留已有effect id及承影组归属；来源/目标改成内部部件时更新真实引用，只有原关系确实消失才移除对应效果，避免新增一份叠在旧影上或留下失效引用。
- **影形仍保持完整可编辑：** 被遮挡的影形不能剪成当前露出的碎片，投影保持独立于承影面的自身明暗，延续外层裁切、内层柔化的现有规则。

线稿交接前完成受影响投影的几何、引用和裁切修正，原绘制者在后续着色/效果任务中完成其颜色、透明度和柔度匹配；交接只需注明受影响的effect id及尚待着色的事项，不增加一轮全局光影判断或全身返修。最终已有对照中查看改动区域，必要时开关这些投影定位问题，无需再派总控重复拼装与审查；未来新姿态导致的新投影及动态跟随，仍留给后续绑定处理。

### 制作和后续验证的边界

本轮素材完成以默认形态高保真、需要的面真实存在、隐藏连接完整和归属明确为准；绑定时对每种实际结构选代表对象，查看中立、左转、右转以及必要的摆动组合，验证断口、纸片感、穿插、硬件保形和投影/裁切更新，发现问题才回对应局部补形。不能用静态截图或统一压缩的伪旋转证明角度X已通过，也不在每个绘制步骤反复做动态验收。

## 清单的图像依据

- **归属明确。** 图中显眼的结构与装饰应能找到所属条目；整件合并记录时说明包含范围，相邻或相似部件用位置区分。仍使用 `name` 与 `separate_for` 表达，保持现有输出结构。
- **拆分用途有依据。** 饰品可以固定，也可以摆动；按图中可见关系记录，活动方式不清楚的留给专项确认。新增替换手势或表情素材由用户本轮需求确定。
- **交付前对图核对一次。** worker 按需放大局部，补漏并澄清范围；已归属大件的内部细节继续留给专项制作。此核对在原识别任务内完成。
