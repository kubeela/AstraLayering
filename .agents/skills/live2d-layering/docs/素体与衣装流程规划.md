# 人物素体与衣装制作的流程边界

本次确定主流程以可复用人物素体收尾，原服装还原或新衣装制作另建独立工作流；[clothing素体整理模板](../templates/部件专项/clothing/流程.yaml)已实现，使用Sol-xhigh，独立衣装工作流已建立[live2d-clothing 技能](../../live2d-clothing/SKILL.md)，已有 Jianma 静态交付。

## 一、当前主流程：完成素体

参考准备阶段仍可用简化连体服帮助识别和制作身体，连体服作为中间素材保留在历史阶段；body、lower_body、arms等按既有步骤完成衣下完整底形、自身着色与衔接。

专项顺序保持face → eyes → mouth → hair → body → lower_body → arms → physics_details → special_parts → clothing → generic，其中clothing改为下面的一次素体整理任务，后续generic只完成其实际对象，保持素体及衣物移出状态。

### clothing：一次素体整理任务

由独立clothing_cleanup（Sol-xhigh）接续最新完整SVG，以下是同一次任务内的操作顺序，不拆成重复派发的检查节点；模板根目录直接放配置、提示词和模型。

| 顺序 | 工作 | 处理范围 |
| --- | --- | --- |
| 1 | 定位临时衣物及依赖 | 从当前clothing部件、实际SVG和附着说明确认临时连体服、包边/装饰、服装依附附件，以及以它们为来源或目标的投影、遮罩和裁切 |
| 2 | 移出临时衣装 | 在新的素体成稿中移出临时连体服及其附属实体，清理只为它们存在的效果和资源；历史阶段SVG继续保留，避免把隐藏旧衣层当成干净素体交付 |
| 3 | 修补暴露出的局部 | 只修本次脱离遮挡后发现的断口、硬边、衣缘色痕、重复阴影与肤色衔接；沿用身体已完成的底色和体积，确需隐藏补色注明推断，缺失较大时明确定位回原负责部件，不默认重画全身 |
| 4 | 一次局部自查并交付 | 用svg_preview.py查看新露出区域及默认预览，确认衣物残影已清、身体自身明暗和其它有效效果保留；直接交完整素体SVG、预览及简短交接，无独立review或额外拼装 |

效果清理按真实source/target与附着关系决定，不能只按data-kind="clothing"删除：衣服投到身体上的影仍归body，头发投到衣服上的影也依赖这件承影衣物，二者都需随临时衣物移出；下巴投颈、头发投身体等仍成立的关系保留。衣物专用的遮罩/裁切解除后，身体底形应自然完整，不能误删身体自身或保留其阴影伪影；共享defs只移除已无有效引用的资源。

本任务不再调用生图，不重新提取整套皮肤色盘，也不增加一次全局光影判断；这些职责已在身体各专项完成。没有临时衣物且没有相关依赖时原样保存输入到声明输出，不制造重绘。输出character.svg、preview.png、交接.md、原样保留完整资源的衣装来源.svg和衣装参考目录，实际交付见[案例快照](../../../../demos/jianma-current-case/readme.md)。

### 附件的交接

- 身体或头发直接附着的已有配饰，以及角色自身特殊部件，按既定范围保留独立身份与控制层。
- 依附具体服装的附件由衣装一起管理，制作kind仍可保留physics_details，服装归属和制作类别分别表达；原来的独立id、附着点及前后关系随交接保留。
- 已画好的衣物附件保存可复用来源，不丢弃已有成果；只从素体成稿中移出其实体及相关效果，归档可供人工追溯；当前衣装技能只接收素体和穿衣参考，不自动恢复档案。
- 独立衣装流程接入时，再将新运行的衣物依附附件在前置结构分析中交衣装流程制作，避免先精修后移出；当前先保存已画成果。归属不能只凭饰品名称或临时连体服的位置猜测，应结合原始衣装参考及真实附着关系。
- generic仍按独立对象完成，其部件与人物保持独立；不重建已移出的临时衣物，不把手持物或环境物烙进身体。

### 素体交付

以最后实际绘制节点的完整SVG作为素体成稿，沿用稳定id、画布/viewBox、身体接口与有效投影关系；最终默认画面中没有临时连体服，也没有它遗留的边线、投影或裁切。

随交付保留原始角色/衣装图、实际使用的画风适配参考及各自用途，不能只留下换连体服后的base-subject图；原始衣物的款式、花纹和穿戴关系由这些参考恢复。

简短交接记录素体SVG位置、移出的衣物/附件id及可复用来源、必要的身体接口与推断范围，既有parts清单作为历史识别结果；后续衣装任务以当前SVG中的实际实体为准，不能将历史clothing条目当作素体里仍存在的服装。

## 二、独立工作流：服装还原与叠加

调用只需当前素体 SVG、原始衣装或用户指定的新衣装参考，以及输出目录；原始衣装还原和新换装使用同一套制作方法。清理归档仅供历史追溯，不是运行输入，执行者不自动搜索旧任务。

### 衣物附件、多层穿插与透明材质

**先对原衣图建立完整衣装清单。** 衣件、衣上绳带/蝴蝶结/链坠/硬饰等一起辨认，再对照当前素体的实际实体：可用的独立件沿用（reuse），缺失或无法可靠适配的重新绘制（draw），不能根据素体当前 id 列表反推原图衣装范围。附属件记录所属实际衣件、固定点、前后层位、软硬与摆动需要；结/固定座、软连接、硬坠按不同运动分开，身体和头发直接附着的配饰保留原身份，避免重复。

**按穿搭层、结构面和局部件组织衣装。** 内搭、外衣、披肩、不同层裙摆等各有身份，按需要独立显示或替换；每一衣层再判断其前后片、侧面、背面/内侧、活动下摆与附件，不能把整套衣服仅拆成一张“前”和一张“后”。需要被外层遮住的内层、被身体挡住的后段及连接应真实补全，隐藏纹样或造型推断注明依据，不能只复制当前露出的边条。

各穿搭层并非简单顺序叠在人物最上方：同件外衣的后片可能在身体后，袖片分别在手臂前后，衣襟在内搭前，附件又可能穿入其它衣片。结构安排需写实际夹住谁、谁在谁前后、附着何处及可独立开关的单位；统一衣装归属与实际绘制位置分别保存，视觉花纹不自动成为动画控制件。

**透明是独立的材质判断。** 区分透明底布、不透明刺绣/包边、局部叠褶和反光，按原图决定各区域的颜色与透明度，不能用整组统一降alpha让所有细节一起变淡。半透明图像里的像素已混入皮肤、内搭或背景颜色，不能直接取这个合成色当作布料本色，再次透明叠加；本色/透明度的分离有不确定性时注明推断，并以实际穿戴合成结果校准。

透明层下的身体和内搭保持完整；真实多层布料交叠应保留原图中的浓淡变化，人为拆分接口则避免重复alpha导致深带。按[透明衔接教程](../../../../live2d-tutorial-text/14.透明，阴影，高光的拆分方式.txt)处理拼接形状与渐变，不能机械套用不透明肢体的大面积圆形重叠；褶皱自身明暗、反光和独立投影分别归属。

**光影关系覆盖衣层与附件。** 既要有衣服投身体，也要处理外衣投内搭、附件投布面、身体/头发投衣件等实际关系；来源与目标按真实内部件指向，颜色/柔度按实际材质和原图匹配。独立关闭某衣层时，只处理与该层及其依附附件有关的效果，保留其余有效关系；换掉承影内搭或调整衣片形状时，同步更新对应裁切与影形，不能把某套穿搭的合成阴影烙到素体。

这些判断分别进入已有结构分析、线稿、色盘和着色任务；线稿review集中看部件完整与穿插，最后绘制者在同一次自查中选代表性的衣层/附件开关和透明衔接查看，不枚举全部穿搭组合，也不新增审查轮次。

| 阶段 | 执行与职责 | 交付 |
| --- | --- | --- |
| 1 衣装结构与穿戴分析 | Sol-medium：对原衣图列齐穿搭各层及物理附件，区分复用/补画，明确前后穿插、固定点、软硬、透明材料、遮挡补全及转向需要；适配素体姿势/体型并确定绘制批次 | 短结构安排与必要补全要求 |
| 2 按需补全参考 | imagegen仅在结构无法辨明时生成一次必要参考，展示组合与完整拆件；侧面、背面、内侧或环绕后段按实际需求同时补全 | 衣装制作参考；不需要时沿用已有参考 |
| 3 完整衣装线稿 | Astra-xhigh按实际衣件/层次分批绘制，完成内外层隐藏底形、附件、连接及与身体的真实前后穿插；所有线稿完成后集中一次独立结构review | 穿在素体上的线稿SVG与结构对照 |
| 4 独立衣装色盘 | Sol-medium：根据各层布料、金属、透明底布/刺绣及附件提取颜色与空间层次，区分合成像素与推断材质本色，保留隐藏补色依据 | 色盘PNG/JSON |
| 5 衣装着色与效果成稿 | Astra-xhigh按主体、复杂材料或衣层分批完成底色、褶皱、纹理、自然线质、透明/反光及跨衣层/附件投影；最后绘制者一次自查独立开关与代表性透明衔接后直接交稿 | 可独立替换的衣装部件集合、穿戴后的完整SVG与预览 |

批次按实际工作量安排：简单相邻小件合批，复杂主体或材料拆开，不逐褶皱派任务，也不要求复杂整套衣装在一次调用内全部画完；最后完成效果的绘制者直接交穿戴结果，无单独重复组装或最终独立review。

衣装部件需要能在身体、手、头发等对象前后穿插，独立衣装集合可以包含分布在不同绘制位置的部件，不能简单合成一张始终盖在素体上方的图；素体的完整底形与自身颜色始终保留，遮挡通过独立衣物及其专用显示关系实现。

服装投到身体的影仍标实际承影kind，并保留来源/目标及衣装归属，服装关闭时移除其依赖效果；角色投到衣服上的影同样随承影衣件管理。既有配饰若复用，保留身份并更新固定点、几何、裁切与受影响影形，不重复绘制，不把服装专属颜色或投影烙进皮肤。

本工作流交正确默认穿戴素材、完整补形和替换关系；X/Y转向、物理、动态遮挡与投影联动仍在后续绑定专题验证。
