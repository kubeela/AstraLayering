按功能部件观察：轮廓是上眼睑、下眼睑、眼白；眼内是眼黑与独立高光；装饰是上睫毛、下睫毛、眼皮及实际特殊装饰。结合已审线稿定位，实际颜色从原彩图读取，标记色和生成线稿不参与取色。

一、覆盖真实颜色分布
- 轮廓：眼白的明部、暖冷变化、上下眼睑和内外端线色；区分眼白自身颜色与眼睑投影。
- 眼黑：辨认并分别采样原图存在的上/中/下深浅、外缘与中心、瞳孔核心与外围过渡、局部亮弧或反射色带。不能只取一个代表蓝色，也不能只取最深和最浅两点就忽略中间色相/饱和度变化。按实际复杂度选取色样，不凑固定数量，不为纯色眼睛编造层次。
- 装饰：上/下睫毛、眼皮褶线及实际眼影/泪痣的颜色与轻重，记录向端部变淡或变色的区域。
- 原图泪液：按两侧实际积泪、泪滴或条状泪流区分边缘色、内部色、透明/不透明画法和独立高光参照，role用comparison并以region/usage说明；透出的肤色属于背景混色，不能直接当成不透明水滴底色，也不把泪液当眼周皮肤暗部。样本part_id用实际所属眼，即使该侧本体采用镜像也保留侧别。
- 眼周皮肤：眼窝与上眼皮、内外眼角、下眼缘周围的底色、暗部和柔和亮部，注明与已有 face 肤色的衔接。不能只有一份肤色而无原图可见的明暗对照。
- 效果对照：原图确有的外来投影、独立高光及其周围色。明确它们是观察色，不把投影最深处或白色反光误当成眼黑/皮肤底色。

二、取样与色盘
写取样 JSON 数组，每项含 name、part_id、x、y、radius、role；role 使用 sclera、iris、contour、skin、comparison。瞳孔归 iris，眼皮和睫毛线色归 contour，皮肤体积层次归 skin，独立妆色/投影/高光对照归 comparison。
可增加 region（该眼内的空间位置）、usage（底色/自身层次/妆色/投影/独立高光）与 basis（用途判断、可能混色）。脚本保留这些附加字段。坐标以原图为准，小部件可用 radius=0；不要让采样窗口跨过皮肤、发丝或眼线，混在一起平均。
运行同目录 提取色盘.py：python3 <脚本> <原彩图> <取样JSON> <输出palette.png>。需要 Python 3 和 Pillow；工具会同时保存真实像素色值、坐标、参考 SHA-256 的 palette.json。观察输出的标注局部，误取样时修正。不能手改 hex 或 rgb 冒充原图实测值。

三、给绘制者的层次说明
按每只眼给一张简短表：部件/区域、样本 id、颜色分布方向与范围、过渡软硬、后续用途。对复杂虹膜明确哪些变化是纵向的，哪些发生在边缘/中心或局部区域，以及瞳孔与其周边如何过渡；指出“一条纵向渐变仍无法表达”的实际差异。纯色区域也记录判断依据。
低清图无法确定妆色还是皮肤体积时，记录可见色区与不确定性，交眼周步骤还原外观；没有来源证据的暗色不要一概推迟到投影步骤。明确外来投影交第5步，属于眼内的独立高光也在第5步单独制作。
