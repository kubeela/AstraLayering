# 摆动物理预览

先在角色工作台验证绑定、活动范围与回弹，再固化自动制作管线。本阶段验证飘带和裙摆，不包含果冻、身体碰撞或 Cubism 导出。

## 操作

1. 加载 KRA / PSD，等原生图层就绪。光照、贴图投影与物理使用同一画布、同一工程；三个页签只选择编辑面板，不重新加载底图或取消已有运动。
2. 在左侧开启「摆动物理」，首次自动准备部件；也可在物理面板点击「准备物理部件」。Jianma 的左右长飘带与裙子前／后片使用保守初始绑定；其他层默认关闭，可在部件列表或左侧图层栏定位并手动启用。
3. 选择固定侧、固定范围和过渡范围。固定范围内的网格点位移严格为零；过渡边插入网格行，不让大三角形跨越固定边。
4. 调整「最大约束」：摆角、末端位移和拉伸。末端位移以自由段长度的百分比保存，同时显示对应像素值；过渡区的允许位移更小。剪切限制为 18°，三角形面积至少保留静止面积的 45%，并禁止翻折。
5. 选择「扰动」后悬停划过即可施力；移动工具、光照和投影页签不接受扰动力。范围可选当前部件或全部摆动物体。切工具停止新力，已有运动继续衰减。
6. 使用单次扰动、暂停、单帧和复位比较。网格绿色为固定区，虚线显示自由端活动边界；受力圆圈表示鼠标作用半径，不是碰撞体。

左侧「实时光照」与「摆动物理」是独立效果开关，允许只开光照、只开物理、同时开启或全部关闭。关闭物理回到静止姿态，保留绑定配置与已准备的部件；再次开启不下载贴图。暂停保留当前形变，切页不重置光源、形变或缩放。画布的效果／原画／法线／深度对照在各编辑页签均可查看；只有相应编辑页签显示移动光源或扰动工具。

原尺寸颜色、法线、深度在同一网格、同一源 UV 中移动。法线方向按二维形变的逆转置修正；深度沿用原表面值。成立条件仍是部件自身纵深没有大幅变化。动态投影使用同一合成深度；表面归属与补全方法沿用[正式教程 08](../formal/08-part-surface-completion.md)。

静止与复位时直接复用原始纹理和原始深度投影网格。准备物理不会改变中性渲染，也不额外逐帧合成；运动超过亚像素阈值后再切换到动态合成。

## 独立物理测试

点击侧栏「物理测试」，或使用 `studio?physicsCase=ribbon`、`skirt`、`flag`。三个案例分别展示上端固定的长条、腰口固定的宽布片与左侧固定的横向挂布；全部使用本工作台的同一 XPBD 与 GPU 贴图形变，不另建演示动画。案例由确定性棋盘格位图和解析法线／深度组成，1024×1024，不读取人物或冒充制作管线产物。

默认关闭光照并开启循环演示。黄色标记与 alpha 轮廓直接证明原色贴图在移动；点「扰动」可用鼠标施力，关掉循环后用单次扰动、暂停和单帧比较。光照可随后独立开启，验证同一形变上的法线打光。单次扰动优先选择可见的自由端，而非第一个可动网格点；横向固定的案例沿上下方向施力。

页面没有底图版本选择。蒙版工程加载后，在贴图投影面板／图层栏开关阴影；数据贴图仍与当前工程绑定。

## 求解与最大边界

固定边与过渡边附近的规则网格行由作者边界替换，不把两者全部叠加：例如 0.28 边界紧邻 5/18，会在 650 px 长条上生成约 1.4 px 的短连接段，极易触发局部摆角上限并限幅整个网格。边界仍精确保留；普通网格行与作者边界的最小间隔按规则网格步距的 30% 处理。

使用固定 120 Hz 的二维 XPBD 距离约束，运动状态与作者配置分开。纵横边控制拉伸，较软的对角约束控制剪切，跨两行的约束抑制急弯；对角线不能与布料拉伸同等刚硬，否则宽布片会成为板材。

原画为无输入时的平衡姿态。回弹与阻尼决定时间响应；有限迭代后的速度也作纵向约束投影，避免位置修正反复注入高频抖动。

最终网格在全部输入叠加后再次检查位移、摆角、拉伸、剪切与三角形方向。越界时向有效静止形回退到有效边界，不能只靠限制鼠标力度。边界处仅移除向外速度，保留切向运动与回弹。

## 数据与画质

含剪贴投影的工程使用 Krita 读取隔离组的原生投影，保留组内正常／正片叠底与透明度继承；普通绘画层继续保持各自的身份和物理网格，飘带和裙摆不会合成成一个运动部件。隔离组仅在预览中生成合成片段，不改写源 KRA。依赖外部底图且无法隔离的混合仍明确拒绝，不静默换回原组装。

首次读取部件后补全地图。静态连续图层缓存成独立片段，仍处在运动层之间的原叠放位置；开关正式投影蒙版时，由 Krita 更新当前快照，保留物理绑定、效果开关、光照参数和原生图层会话，再补全当前地图。每帧更新顶点，在 GPU 上合成三张原尺寸贴图，不反复下载、CPU 重建或上传整图。源 sRGB 内先合成，再在线性颜色空间交给原 MToon 光照。

草稿保存到本机浏览器，按源工程 SHA-256 与尺寸区分；即使合成图相同，改过图层身份的工程也不能混用。可导出／导入 `character.physics.json`，包含求解器版本、真实图层 ID、绑定与范围；角色素材或部件身份不匹配时拒绝导入。它尚不是管线正式产物，也不写回 KRA。正式自动绑定、作者网格精修和参数烘焙属于后续制作。

## 参考与限制

- [XPBD: Position-Based Simulation of Compliant Constrained Dynamics](https://doi.org/10.1145/2994258.2994272)，Macklin、Müller、Chentanez，2016：距离约束的柔度和乘子更新。
- psd2live 固定版本的 [SWING](https://github.com/tsunehimatoi/psd2live/blob/ef527ddf9a7e738de642a0f19bdda17da1ef6191/docs/zh/guide/SWING.md)：固定边、弧形保长、自由端与多段跟随。
- 同版本 [SIMULATION](https://github.com/tsunehimatoi/psd2live/blob/ef527ddf9a7e738de642a0f19bdda17da1ef6191/docs/zh/guide/SIMULATION.md)：固定点、刚度、保形、拉伸／面积、静止标定与 XPBD。该项目记录了旧网格碰撞不可靠而移除的情况，不能把轮廓直接当成可靠碰撞系统。

参考制作结构与公开约束公式，没有复制 psd2live 的 GPL 代码，也不是 Cubism 求解器兼容层。规则网格与单侧固定是本阶段编辑范围；斜接缝、复杂连通区、身体避让、九轴、果冻及拟合烘焙仍需独立制作和验证。

相关验证：`node --test web/tests/studio-physics.test.ts`，以及对已启动服务执行 `node tools/lighting/physics-browser-check.mjs <工作台根地址> [项目名]`。浏览器检查使用真实原生图层，验证工具门槛、悬停受力、配置恢复、原尺寸导出和中性画面对照；证据写入忽略目录 `.web/physics-check/`。

独立案例验证：`node tools/lighting/physics-cases-check.mjs <工作台根地址>`，记录光照关闭时的黄色标记位移、alpha 轮廓变化、约束、循环与悬停施力，证据写入 `.web/physics-cases/`。仅有光影变化、只检查 shader 不报错，或只检查内部顶点变化，都不足以证明实际贴图运动。
