# 连续鼠标轻扫与物理验收

本篇记录 2026-10-26 在 pink-doll、pink-elf 泛化测试中发现的输入差异，以及用户确认的验收规则。两个人物在规则变更前尚未通过独立复核；新增测试的实现和数值检查不代表角色已通过。

## 为什么保留原九组，再加一组

原 light-brush 在第 60 步施加一次 `0.06 × freeLength` 的脉冲。sustained 在 60–299 步每 12 步施加 `0.08 × freeLength` 脉冲。它们检查短负载的响应路径、稳定性和回落，不能冒充用户连续划过鼠标的输入。

pink-doll 原配置的两肩在单脉冲中只有亚像素响应；独立补充实验在真实 masked alpha 命中下，以画布宽度 1%/秒连续接触 0.25 秒，得到约 3.17/3.39 源像素的可见锚点弯曲。这个实验原先明确为 supplemental，未替换原九组或批准角色。用户随后选择“加入真实连续轻扫验收，保留原九组”。

原九组 neutral、tip-impulse、support-release、support-reverse、sustained、extreme、combined、light-brush、airflow 的力度、时序及六项最大约束全部保留。新增 pointer-brush 使用下面的协议。

| 项目 | 协议 |
| --- | --- |
| 时钟 | 120 Hz 整数步；原 960 步后仍追加完整装配的无输入回落 |
| 选点 | 原尺寸图层 masked alpha，按真实层序排除被遮挡的像素；固定区不作为可扫自由面 |
| 来源 | UUID、内容指纹、源像素位置、可见 alpha、活动权重；无可见自由像素明确记录 |
| 路径 | 从选定像素出发沿挂点到自由段的切向移动，固定画布坐标，不跟着物体抓住或追踪 |
| 速度 | 画布宽度的 1%/秒；输入倍率 1 |
| 半径 | 画布高度的 1%，最小 2 源像素 |
| 施力 | 60–89 步沿线段与圆周探针检查当前变形表面的真实 alpha；只有命中才施力 |
| 权重 | 每步 `dt × 12`，与工作台鼠标事件一致；90 步停止输入 |
| 保留 | 全步无损轨迹包含命令、接触位置、路径、速度、半径与权重 |

每组件一条独立路径在同一完整装配内测试，用于覆盖全部自由面；这是多个局部接触的组合验收，不宣称单个鼠标同时出现在多个位置。隐藏组件通过真实父支撑和风验证联动，不凭空施加鼠标力。

## AI 应当看什么

原九组仍查看规定时刻、当前光照、法线/深度诊断、事件窗、源尺寸接口及最终两张回落图。新增测试还必须查看接触中的 72 步、停止时的 90 步，以及被选中源像素的最大位移前后 2 步。完整均匀序列与 60/120 Hz 加密窗口保持同一取景；局部保留源像素，不用放大图冒充原尺寸证据。

同时报告网格峰 `visiblePeak` 与源像素峰 `sourcePixelPeak`。网格可能延伸到透明、被遮挡区域，所以前者不能证明人看到的衣片在动。原尺寸颜色图、折纹、边界、根部稳定及后段滞后共同判断自然度；单独“位移不为零”不是通过依据。连续接触计数为零是命中失败，不能解释为材料自然。

小翼片在一次极弱脉冲下亚像素运动可能符合负载比例。真正扰动的可见柔软程度由连续轻扫、微风与支撑牵动共同判断；不为了让旧弱脉冲变得夸张而随意加大受力、缩减固定区或放宽安全约束。持续输入的真实僵硬、跳变、顶限、回退、层序错误仍须返修。

无真实 normal/depth 时，默认平面诊断只检查轮廓/UV，报告明确未验证内部真实贴图。连续轻扫不补造这些贴图，也不绕过投影审核。

## 独立实现与恢复

协议、源像素解析、轨迹和接触函数均在 skill 的 shared/physics-evidence；前端与 Worker 引用同一逻辑，不反向导入 web。Node 适配读取原 masked PNG、严格核对 bounds，前端使用已经加载的同分辨率像素；自由预览无需提前扫描所有像素。

无图合成探针可以使用明确标注的 geometry-only 路径；它只能验证数值，不允许签发角色视觉通过。输入版本、源像素/层序或求解规则变化使旧标定与证据失效。规则基线证明原源图、groups、范围和参考未变后，归档旧反馈/返修预算及完成标记，保留分析、作者草稿与 B 会话，再按新代标定和新 C 实际看图。原失败记录不删除；同指纹再次恢复不会重新清空轮次。
