# 同页验证、画质与问题定位

这些检查来自本轮实际问题。它们用于验证已经选择的功能，不要求每个小文案变更重跑所有物理与画质测试。

## 1. 一个人物预览，多个控制与隔离试验

光照、图层、物理、嘴型以及未来动作和表情应共享持续挂载的预览。切换页签保留相机、选中 part、模拟与暂停状态；不要建立彼此不同步的物理页面。

不同物理可以独立验证：眼部隔离眼眶／虹膜瞳孔／高光，胸部隔离左右／上下／聚拢，时间轴支持暂停和逐帧。它们共享同一系统与画布，验证入口独立不等于再建一个引擎。

| 操作 | 规则 |
| --- | --- |
| 首次进入 | 默认移动／平移人物视图 |
| 移动光源 | 明确选择后才把指针用于调光 |
| 物理扰动 | 只有选择扰动工具才施加鼠标力；选择后悬停划过即可，适合触控板 |
| 扰动对象 | 仅摆动物体、仅果冻物体、全部物理；与仅当前 part 取交集 |
| 切换工具或对象 | 停止不符合条件的新力，已有运动继续自然衰减 |
| 完全隔离 | 先选择范围，再复位，用一致脉冲比较 |
| 切页、失焦、离场 | 正确停止指针输入、取消遗留事件与资源，不产生隐形力场 |

列表筛选只是找部件，不自动更改受力对象。移动、调光、扰动门槛要真实作用在输入层，不能只改变按钮外观。

## 2. 选中的轮廓必须就是正在变的部件

外接矩形适合粗筛，不够用于精确选取。按当前绘制顺序由前向后找三角形，反解重心坐标回到原 UV，再读本层 alpha；透明洞、眼口遮挡和动态裁切也参与判断。

鼠标力场可以使用稀疏的当前形变轮廓采样，但应与可见部件一致。选区、力场与真正渲染网格各有精度预算，不能把粗采样命中称为逐像素精确。深度图辅助光影，并不能替代 part 身份和 alpha 的归属。

## 3. 保持原图精度，优先消除重复工作

本轮颜色、法线、深度、光照和投影缓冲保持原始 1024×1536，扰动、暂停和单帧导出不切低清档。图集保持裁片原尺寸，使用预建拓扑、静止帧缓存、批量绘制和共享结果减少重复计算。

参数中的法线平滑、投影软边属于美术效果，不是缩小纹理。需要更高硬件性能时应测实际瓶颈，不能把降低皮套精度作为用户无感的自动补偿。软件 GPU 的帧率不代表用户笔记本硬件性能。

原素材的嘴部只有约 20 像素宽时，高清画布也不能补出嘴部笔触细节。导出无损原尺寸，再用整数倍最近邻放大能看清每个已有像素；这种放大不是超分辨率，也不能称为新增了细节。

## 4. 三类“黑线／白块”必须分开诊断

| 现象 | 本轮发现 | 正确排查方向 |
| --- | --- | --- |
| 胸上方暗接缝，关光仍有 | UV 把像素边界当中心，裁片缩进半像素；透明黑 RGB 被插值进边缘 | 检查边界 UV、alpha 预乘和混合；不要拿模糊或降低阴影掩盖 |
| 闭眼后打光出现线／网格暗痕 | 下层脸皮取得了眼部法线／深度，原来开眼时被覆盖，闭眼后露出 | 语义范围排除眼口取样，补全下层自身表面；核查动态开口和方向修正 |
| 唇线上方白块，隐藏上牙仍有 | 命名为上唇的源层含有应属裸露牙齿的像素 | 回到原图纠正语义归属；图层顺序、shader 和嘴型参数都不能单独修复 |

第三项以本轮用户最新判断为准。此前“可能是唇部高光”的解释不再作为制作依据。检测到白块在上唇层，只能证明它目前存在哪里，不能证明它本来就属于上唇。

排查顺序：

1. 原图与当前中性渲染对照，确认基线。
2. 关闭附加光照。问题还在，先查颜色、alpha、UV 和源图语义。
3. 单独隐藏疑似图层。异常仍在，寻找其他层里的重复／误归像素。
4. 看法线、深度、归属置信度与开口，区分贴图归属和方向变换。
5. 冻结姿态改变光源，再冻结光源改变姿态，定位相互影响。

## 5. 最小的动态画面集

| 对象 | 需要的时间点／姿态 |
| --- | --- |
| 长发与衣料 | 固定区静止、首个自由段弯曲、末端极值、回归 |
| 胸部 | 单次受力、主极值、主反转、次级极值、衰减尾段 |
| 眼部 | 开眼、闭合中、完全闭合、刚重开、内部余颤结束 |
| 嘴部 | 原画、闭嘴、微张、半开、最大开口、悲喜与已选特色组合 |
| 光影 | 同姿态左右光源、投影开关、地图跟随与方向修正开关 |

原尺寸单帧与整脸／整身效果都要看。连续过程检查的是相位、线宽、遮挡和中间形；不是从大量截图中选一张好看的作为完成证据。

## 6. 制作状态与保存

角色身份、素材版本、部件 ID、参数范围、关键形、允许组合和手调值要能保存并恢复。导入时验证角色与皮套版本。旧默认值可以有明确迁移，不能悄悄覆盖用户手调值。

试演和外部输入采样到独立姿态，不覆盖作者草稿。辅助网格显示不等于完整网格编辑器，本地草稿也不等于已回写正式模型。

本轮音频导入与近似元音驱动作为工作台输入试验已实现，但不计入嘴型制作：清晰人声适用，伴奏和多人声会干扰，尚无可靠人声分离。摄像头驱动、完整头身九轴与正式动画资产仍是后续事项。

## 7. 从试作到正式可用

先确认身份与分层语义，再验形变、遮挡、时序和组合。数学测试能检查固定边、网格方向和一致性，无法证明牙齿识别正确或角色好看。用户指出反例后，应将该范围从“已验收”退回待修，保留已验证的其他能力。

本轮嘴部暂按用户要求保留现状；正式教程记录应修正的原则和失败依据，不宣称已经完成素材修复。
