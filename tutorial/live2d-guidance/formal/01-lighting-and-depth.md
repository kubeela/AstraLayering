# 光照、法线、深度与动态投影

依据：[L01 字幕解析](sources/lighting-video.md)、[Jianma 实战](cases/jianma.md)。本轮验证了固定视角下的动态打光和可见深度投影；完整三维重建、九轴转面与隐藏面的正确投影未完成。

## 1. 三种问题分别需要什么

| 目标 | 必要信息 | 不能混淆的边界 |
| --- | --- | --- |
| 一个面朝光还是背光 | 法线方向 N、光源方向 L | `N·L` 只描述朝向，不知道中间有没有头发或手 |
| 刘海投影到脸、头投影到脖子、裙摆投影到腿 | 遮挡物与接收面的相对位置，加沿光线的可见性查询 | 有深度图不等于已实现阴影；还需要偏差、采样、透明覆盖与合成 |
| 烟雾穿插、光条随表面起伏扭曲 | 深度、合成／置换规则 | 深度不只用于阴影；L01 明确讲了这两种用途 |
| 二分明暗 | 朝向或其他明暗场，加阈值和美术控制 | 二分是表达方式，可以作用于明暗分区或投影遮罩，不是一种几何来源 |
| 图中已经画好的暗部 | 原画像素，必要时有独立阴影层 | 关闭 shader 阴影不会抹掉原画中的暗部 |

法线图保存方向，常见编码为 `N = normalize(2 × RGB - 1)`。深度图保存视角下的远近，必须约定黑白方向。本轮为白近黑远的相对深度，不是米制距离；正常的相机距离、Z 值和相对靠近值不能不加转换地混用。

法线、深度属于数据纹理，不能按彩色照片做 sRGB 解码。原画颜色的乘光计算则应在线性空间进行，最后编码回 sRGB。法线的图像 Y 与渲染坐标 Y 是否相反必须用左右／上下移动光源检查。

## 2. 可以先生成整张图，再按部件使用

本轮从一张 1024×1536 的完整人物生成同尺寸法线与深度，保留原图 alpha。无需先为每一块发丝、牙齿分别请求生图。生成前要固定画面尺寸、姿态、裁切和人物对齐，生成后检查轮廓、眼口位置和材质边界有没有漂移。模型“看起来像”不代表逐像素配准正确。

但整图只记录当时可见的表面。头发盖住脸时，同一坐标上的法线属于头发；不能把那一块直接裁给脸底。部件活动后出现的新表面没有观测值，需要补全并标明估计。

本轮采用的分配方法：

1. 用已确认的 part ID、原画位置、alpha、穿戴遮罩和绘制顺序判断归属，不用生成深度重新猜绘画层级。
2. 前向透射率 `T = ∏(1 - alpha_front)`。部件覆盖充分且前方没有显著遮挡的像素，才接收整图同坐标样本。实例门槛为本层 alpha ≥ 0.65、T ≥ 0.8；它们是可调整的归属门槛，不是模型准确率。
3. 眼口等语义区域要排除下层皮肤取样：眼皮线之间即使透明，也可能含整图模型估计的眼球法线。只看不透明像素会把眼球或嘴腔数据漏进脸底。
4. 在本层连通区域内传播已知样本，以固定已知边界的平滑插值填洞，不跨透明洞、不修改已知值。完全无样本区域使用同运动组估计或显式默认，并显示估计状态。
5. 归属置信度只能说明“这个样本是否来自本层可见区域”，不能证明 AI 估计的几何是真实的。

浅纱和半透明层会混合多个表面；单层深度难以完整表达。能从分层精确定位目标像素，不代表已经知道隐藏曲面。

## 3. 柔和与二分应分开调哪些量

连续光可从 `max(0, N·L)` 起步。二分权重可写作：

```text
w = step(threshold, N·L)                                  # 硬边
w = smoothstep(threshold-softness, threshold+softness, N·L) # 带过渡的二分
```

| 参数 | 主要改变 | 常见误用 |
| --- | --- | --- |
| 光源方向 | 明暗分区所在位置 | 用增强光量补救不合适的方向 |
| 环境光／主光比例 | 暗部基线和整体对比 | 环境光过高，使二分开关几乎看不出差异 |
| 二分阈值 | 分界位置、受光面积 | 把阈值当成阴影浓度 |
| 二分 softness | 分界带宽 | 过宽会变回大面积渐变；过窄会暴露噪声 |
| 阴影深浅、整体影响量 | 明暗差与保留原画程度 | 与 softness 同时减弱，最后只剩很淡的分区 |
| 法线强度／平滑 | 局部朝向起伏与细碎明暗 | 脸上过强会像立体布偶；过度平滑会失去局部结构 |
| 亮部保护 | 限制原画浅色被再次提亮 | 不能以保护亮部为由把暗部也全部压平 |
| 投影强度、深度尺度、投影柔和度 | 部件间阴影 | 与 `N·L` 二分边缘是不同控制 |

二维原画已经包含明暗和高光；直接在其上叠强高光或大增益，易使脸发白、鼻唇塑料化。本轮采用保守增益、较弱主光、亮部保护及有色暗部，并保留原画对照。艺术上允许修改估计法线或加入局部作者遮罩，不能把“法线越真实”当成“角色越好看”。

Jianma 的偏好经历了强对比 → 右中连续柔光 → 需要更清晰分界的柔和二分。这说明方向、边缘与明暗差应分别调节，不能把某一阶段的“不要二分”固定成角色永恒规则。当前样例方向为画面右中，方位 52°、仰角 0°；数值仅适用于本文约定。

首次加入深度投影的提交保留了原有柔光基础参数，只增加投影查询与控制。之后有合成、画质和二分可读性的独立修改；“深度开关关了仍更柔和”不能直接推出深度算法改变了所有基础明暗。具体沿革见[案例](cases/jianma.md)。

## 4. 深度投影如何计算

在接收像素处确定表面位置，沿朝光源的射线检查途中是否遇到更靠光源的表面。单张深度图的原型把这一过程投影到屏幕上：

```text
原画 + 形变后的法线／深度
    → 当前可见表面
    → 沿光源方向查询深度差
    → 有偏差与软边的遮挡量 O
    → 主光 × (1 - O × 投影强度)
    → 加环境光，应用原画保护与颜色转换
```

必须有自遮挡偏差（避免表面把自己涂黑）、足够的取样距离、透明覆盖判断、离屏和背光处理。步长过大漏掉细发丝；偏差过大使阴影漂离接触处；偏差过小出现暗纹。二分投影可以对遮挡量阈值化，但仍需边缘抗锯齿。

本轮保留环境光，只衰减主光；深度尺度是美术参数。当前屏幕空间求解只对朝向镜头一侧的光执行有效追踪，不能把关闭或跳过背光查询称为背面阴影正确。

**手从身体旁移动到脸旁，部件自身的平面深度几乎不变，阴影也可以改变。** 横向位置改变了射线能否击中手。前提是手与脸的深度顺序、运动位置、光源、接收面和遮挡算法一致；不是“必须沿 Z 移动才会产生新的投影”。它是否挡住裙上的光仍由完整光线关系决定，不能只按屏幕重叠猜测。

单层可见深度仅能保留每个像素最前面的表面。被手或裙摆完全遮住的接收面、离屏遮挡物、背面、厚度以及穿插都可能缺信息。静态绘制顺序也不会因 Z 偏移自动重排。因而本轮结果是同视角近似；完整跨层关系需要分层几何／多层深度、光源视角阴影或另行建模。

### 作者阴影遮罩与动态投影如何选择

对鼻唇的固定画法、刘海下需要特定轮廓的暗部等，作者遮罩更容易控制美感；让遮罩随相应表面变形，再按光向或姿态控制强度／关键形。它表达的是选定的画法，不自动具备任意光向的真实投影。对手臂移到脸旁等新的遮挡关系，仅有固定遮罩通常不够，应由当前几何／深度查询驱动，或另作该动作的关键遮罩。

两者可分工使用，但要检查是否与原画暗部重复叠黑。本轮已验证动态深度投影；完整的按光向选择作者阴影关键形库仍是后续制作路线，不能列为已实现。

## 5. 形变时法线与深度能不能一起变

能。要区分**纹理位置跟随**与**向量方向修正**。

- 颜色、法线、深度使用同一源 UV 和同一部件映射，避免运动后读取原位置的另一部件。
- 对局部可逆形变 `F`，方向用 `N' = normalize(J⁻ᵀ N)`，其中 J 是同一映射的局部变形梯度。只移动法线图像不改变 RGB，等于方向仍停在原姿态。
- 平移不改变方向；旋转要旋转方向；非均匀缩放或剪切需要逆转置。网格翻折或退化时应限制形变，不能归一化后假装恢复了正确曲面。
- 当前实现从相邻顶点求局部切向，并以原相对深度加局部 Z 偏移更新深度。这是局部 2.5D 近似，不是重建真实体积。
- 轮廓、开口和目标遮罩也要跟随同一最终映射；只更新颜色而不更新遮罩会在闭眼、闭嘴时漏出错误明暗。

九轴有两条可并用的路线，但本轮没有完成其全域验证：

| 路线 | 适合的范围 | 制作要求 |
| --- | --- | --- |
| 原贴图跟随网格，再修正方向 | 同一可见表面的小到中等形变、头发与局部果冻 | 维持对应关系、局部梯度与深度；大转面暴露的新内容另补 |
| 制作边界姿态的法线／深度，中间插值 | 明确制作过的头身关键姿态 | 对齐语义、UV、深度尺度、坐标系；法线插值后归一化；开口和遮挡变化需分段 |

两张阴影图有起止状态，不保证直接插值就得到正确中间阴影。直接混合可能出现双影或遮挡拓扑错误。可控的作者遮罩可以做关键形插值并补修正；需要随光源任意变化的投影，应优先从当前姿态数据重新计算。

## 6. 最小验收

同一姿态依次看原画色、法线、深度、明暗分区与投影遮罩；对照开启／关闭投影、开启／关闭贴图跟随、开启／关闭方向修正。再做光源左右移动、一个部件摆动、一次闭眼／闭嘴。只在打光图中异常，检查方向和归属；原画色里就有线或白块，优先查素材、UV 和 alpha。

这套检查已用于本轮调试。新增九轴、手部遮挡脸或多层穿插时，必须重新检查具体关系，不能沿用“之前光影可用”的笼统结论。
