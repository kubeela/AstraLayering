# 共用物理与头发、长绳、衣料

依据：[Cubism / psd2live 来源](sources/README.md)、Jianma 部件运动的实际迭代。正式采用“求解运动”与“作者形变”分开的结构。

## 1. Cubism 的物理解决什么

Cubism 的典型流程是输入参数经归一化、权重和反向设置，驱动虚拟粒子／摆链，再把链的角度等结果映射到输出参数。输出参数采样作者制作的关键形，最后才得到图像变形。

```mermaid
flowchart LR
  I[动作或输入参数] --> P[虚拟摆链 / 惯性响应]
  P --> O[归一化输出与限幅]
  O --> K[作者关键形 / 空间权重]
  K --> M[各层最终网格]
  M --> R[颜色 · 法线 · 深度 · 遮罩]
```

它不是看到一块头发图片就自动求出真实头发运动的通用软体系统。参数名、节数或阻尼值相同，也不会自动产生相同美术效果。psd2live 的 PHYSICS、SWING 和 SIMULATION 分别提供参数驱动、摆动制作与 XPBD 参考路线；本轮借鉴固定区、分段输出和保形等原则，没有接入其 XPBD、烘焙或拟合实现，也没有复制其 GPL 源码。

本轮工作台自行实现固定长度粒子链和解析阻尼弹簧，共享 120 Hz 固定步。该实现不是 Cubism 求解器兼容层，面板数值不能逐项对号复制。

## 2. 一套系统，按运动性质选择绑定

| 模型 | 适用对象 | 主要形变 |
| --- | --- | --- |
| 连续弯曲的摆链 | 长发、长绳、飘带、袖尾 | 固定根部，自由段弯曲，末端滞后 |
| 整体摆动 | 耳坠、较硬挂件 | 围绕挂点转动，尽量保持自身形状 |
| 局部果冻 | 胸部、眼内组织等 | 支撑边界固定，局部挤压与延迟回弹 |

对象的绘图层与运动组不必一一对应。同一运动组可以包含不相邻的绘制层，保持原先叠放顺序；胸部皮肤与贴身衣料也能共享一个连续场。不能只因为名称中都有“头发”，就把贴头短发和垂落长发绑成一块。

## 3. 头发从哪里开始动

制作时先标出连接位置、静止垂落轴、影响长度、固定区和自由段。头顶贴头部分不动，弯曲从离头的自由段逐渐出现；发尾负责较大的位移与延迟。

```text
支点 ─ 固定区（位移严格为零）─ 过渡区（连续接入）─ 自由段 ─ 末端
              固定边必须有网格行                  位移 / 弯曲逐渐增大
```

可使用的连续权重示例：固定区外将纵向位置归一化为 t，再用

```text
w(t) = smoothstep(0, transition, t) × t^(1.5 × bendBias) × influence
```

让根部从零权重接入，末端集中度决定弯曲更靠近哪里。固定区内不要用“很小但不为零”的位移冒充固定。每节长度、摆角约束控制运动范围；根部可以比末端更受限。

中心线应连续，根部切向接回原发束方向。本轮采用 Hermite 曲线表达链之间的形状。对宽发片和裙摆，横截面适当保持平行可减少整块板材转动感；对绳状细束可以允许截面跟随切向。它们是造型选择，不是越柔越好。

## 4. 网格怎么布

1. 沿长轴安排足够的纵向分段，以承接曲率和节间相位变化。
2. 在固定边、过渡边和自由端插入明确网格行；倾斜固定边也要对齐，避免大三角形横跨固定与活动两区。
3. 横向分段服务于宽度变化、局部弯曲或斜轴，不为顶点数量本身加密。本轮宽发片横向最多四格是该实现的预算，不是所有头发的推荐上限。
4. 不同连通区应有各自有效的挂点和活动范围，透明洞不参与受力。
5. 观察轮廓、内侧发纹与相邻发束，确保内部纹理不会被拉成橡皮；必要时调整关键形或拆运动组，而非只加密网格。

本轮刘海固定上部约 42%、裙腰约 23%；贴身袖筒固定约 72%、仅输出约 22% 的形变。这些数值记录的是 Jianma 的初始绑定。其他角色应按真实贴头范围和缝线重新标定。

## 5. 衣物为什么不能全部一起摇

先区分贴身区、连接缝、自由布片和硬装饰。贴身袖筒主要跟随手臂，袖口长尾才有明显自由摆动；裙腰固定，裙摆逐渐增大形变；肩侧垂纱按自己的连接边受力。整体旋转一整件衣服，通常会让连接处滑动、穿帮或产生纸板感。

同一表面的线稿、纹理、贴身装饰应共享精确映射；悬挂装饰则需要自己的运动响应。二维摆链不处理布料碰撞、自碰撞、厚度和真实接触，本轮鼠标划过只是外力试验。

## 6. 果冻的共同时间原则

简化惯性可以采用 `x'' + c x' + ω²x = F`，其中 `ω = 2πf`。欠阻尼产生多次逐渐衰减的回弹；临界和过阻尼用于快速无振荡回稳。自然感取决于频率、阻尼、形变和相位的组合，并非只把阻尼调低。

本轮在固定步内采用每步恒定力的解析积分。主位移与形变状态分开，后一级追随前一级，产生相关而不同步的输出。不要把位移、宽高缩放和所有内部细节都绑定到同一个正弦值，也不要靠随机抖动制造“活”。

限幅优先作用于外力、可见位移和组合应变。可用 `limit × tanh(value / limit)` 平滑压住极端输出；不要碰到位移上限就清掉向外速度，否则会突然停止、失去多弹的连续感。胸部与眼部有不同节奏，见各自教程。

## 7. 可重复的调试顺序

先暂停并确认固定区，再单次施力，观察受力、主极值、反转、第二次回弹和尾段。把同一脉冲用于参数前后比较，避免一边随意划鼠标一边猜参数。改变固定区和输出形状后再微调时间响应。

同页扰动提供“仅摆动物体／仅果冻物体／全部物理”，与“仅当前部件”取交集。筛选只是停止新力，已有运动应继续衰减；需要完全隔离时先选范围再复位。只有选中扰动工具才接收鼠标力，选中后悬停划过即可，不要求按住按钮。具体交互约束见[验证教程](07-review-and-quality.md)。
