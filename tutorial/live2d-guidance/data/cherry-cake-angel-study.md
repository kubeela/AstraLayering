## 实际取得与格式

ZIP 为 68,357,883 字节，13 条目（2 目录、11 文件），条目解压总长 82,342,729 字节。Unicode Path 扩展字段提供正确中文名；没有仅凭乱码路径解压。已检查穿越、符号链接、重复路径、类型和体积，解压校验 CRC，复制到本地 `../local-assets/cherry-cake-angel/` 后逐文件 SHA-256 一致，原 ZIP 与工作目录副本保留。

有 moc3、2 张 8192×8192 RGBA 纹理、model3/cdi3/physics3、VTube/xyplugin/固定物件配置、icon 和一个 motion3。没有 PSD、cmo3、can3。CDI 中有含 `.psd` 的部件标签，仅是标签，不代表工程或 PSD 已取得。moc3 仅核验 MOC3 文件头，不执行。

[机器可读研究索引](cherry-cake-angel-runtime-study.json) 包含逐文件 hash、资源引用、187 个参数标签、14 个显示组、110 个部件标签、63 组物理输入输出关系；model3 引用全部存在。显示组和部件标签不是变形器父子树。

## 经实际纹理验证的拆分观察

已在本地检查 icon 与两张实际纹理，未将这些图像发布到 git：

- texture_01 中，可见完整椭圆脸底色岛与分开的脸轮廓岛。模型可见脸部在 icon 中是一个整体，但图集保留了可分别分析的颜色与轮廓素材。这支持研究“完整底色与轮廓的分离责任”，不能单凭图集认定具体网格、蒙版或原 PSD 层级。
- texture_00 中，多条完整长发束分别存在，并保存大块裙形及配饰素材；texture_01 中，长荷叶边/装饰条、肤色肢体形状与蛋糕小配饰分别成岛。
- 这些实物证据说明研究不能只看整体立绘，还要分析底形、轮廓和装饰条的不同颗粒度。图集摆放位置服务打包，不等于绘制层序；没有据此修改 generic。

JSON 给出脸底/轮廓候选的原始纹理近似 ROI 坐标，供取得合法源资产后定位观察；不是精确分割、原图层 bounds 或语义真值。完整遮挡补形与网格对应关系仍待验证。

## 变形相关：能确认与不能确认

附带循环 motion3 的元数据为 3.967 秒、30 FPS、5 条曲线。已解析段端点统计，不复制完整曲线；五个曲线参数 ID 在 CDI 标签中都未匹配，model3 未注册该 motion 文件。因此记录“附带动作”而不宣称它已经与此模型正确关联或播放。
