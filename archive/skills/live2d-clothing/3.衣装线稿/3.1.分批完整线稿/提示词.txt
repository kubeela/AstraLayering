在交接的最新完整 svg 上制作当前 batch 的衣装线稿；读取 structure 中本批的 part、衣层、依附及穿插要求，对照原衣 reference 与辅助 guide，完成真实可编辑部件。原衣图决定可见形态，生成参考帮助理解隐藏结构，旧色块及生成图的错误不能覆盖原图依据。

一、校准穿戴形，再完成完整内部件
按原图检查衣装外轮廓、领口/袖口/腰线、负形空隙、长短比例、松量和褶皱方向，对齐素体姿势与关节；不要沿旧色块逐线描出简化壳。合身胸部衣料沿受力/布料走势组织，不能直接复制皮肤胸线，也不能为迁就衣装变更素体体型。
逐个完成 batch.part_ids 的完整底形：被外衣挡住的内搭、身体后的衣片、领袖口内面、必要侧面/背面及环绕后段、附件根部和隐藏连接，都画成实际路径。前后面、独立活动下摆与不同软硬附件有各自控制身份；不能以 desc、空组、细边条或引用另一部件可见轮廓替代实体。
后片放身体后，前片放承载面前，袖子/手指/前后衣襟按实际关系穿插；需要时分开控制组或在保持实际变换与资源的前提下安排显示位置，不能把全部衣装套在一个最上方 group。沿用素体已有正确结构，只适配衣装及其显示关系，不删除衣下身体或重画其它组。
衣身与袖子在肩顶交接，袖根完整延伸进遮挡处；结构安排要求分开上下袖段时，不透明袖段在肘附近圆顺交错，隐藏封口不描线。袖口需包住手腕时实际画出前后片，后片不能只剩一条边；透明或可脱袖下面已有手臂完整保留。
不透明活动接口补适量隐藏搭接，正式轮廓不得横穿连接口；透明人工拼接口使用较平的切口和受控覆盖，不能用两大片半透明圆弧重叠。真实叠褶与人为接缝分清，透明材质的最终浓淡留上色。

多层裙摆各自的前/后片必须围住正确内层与腿，里层被盖住也完整；裤裆补到上装后、左右裤腿完整，已有上下段在自然膝部搭接。硬领/衣襟保留各自透视面，后领完整绕到脖后；不能只画正面领边。露肩衣/披肩有身体与手臂两处牵动时，实际补出两端固定/滑移连接和隐藏余量；连披风兜帽分别完成头前、头后、身体前、身体后，颈肩相接而控制身份分明。按本批实际衣型选择这些规则，不新增计划外衣件；固定结、软翼尾、硬夹扣各自完整连接，既有可用附件不重复制作。

二、复用与身份
reuse 使用本次 carry 中已有的真实节点进行校准，不再复制一份；调整层位或拆出内部件时，保留 href/url、渐变/裁切/滤镜依赖及祖先变换/样式语义，不夹带临时连体服或无关配饰。draw 按参考从头构建，补齐素体中缺少的衣件与衣附饰品；新 id 不得与当前 SVG 冲突。输入素体与前批成果中的有效依赖仍须保留，不能因本批重新组织节点而失效。
复用件已有合理着色可保留，当前新画件使用便于辨形的中性填色与细线；辅助边标 data-role="construction-guide"，正式线条另存所属实体，避免最后残留统一粗黑边。实际尖角、领口折角和孔洞应保留，不能为了柔和把所有曲线抹圆。
每个可控制实体保留稳定 id 和原有 data-part/data-kind；新衣物 data-kind="clothing"，衣附饰品可用 physics_details。额外标 data-outfit-id 为本套 outfit_id、data-wear-layer 为所属穿搭层 id（组属性可继承），与 kind 分开。固定点、attach_to、draw_order、补形推断和 source 原 id 简记在实体 desc，不另写批次报告。
同一衣层可分布在多个 SVG 位置，用归属标签连接；不能为了单组开关改变正确穿插。身体/头发上的既有非衣附饰品仅保留，不擅自纳入衣装所有权。

三、同步受影响的已有投影几何
查询本批改形影响的现有 source/target 与缓存引用，修正完整源形、影形范围、目标 clip/mask、坐标变换和显示顺序；外衣新增遮挡使原关系临时不可见时保留干净基底与可恢复关系，不把旧影抹进衣料或皮肤。新材质上的新影可留上色批次，当前不能带着已失效的引用继续推进。
效果持续则保留其 id、data-effect="cast-shadow" 和承影 data-kind，source/target 指向实际内件而非整套衣组；新衣专属关系附 data-outfit-id 与相关穿搭层归属。完整可编辑影形再裁到承影面，不能仅留下当前露出的一小截。裙摆、袖子或衣附饰物的投影几何按其实际投影范围延续到遮挡后；拆成独立来源时各影保留相应完整底形，同动但不同承影层位也不能烙成一片。
clipPath 只包含 path/基本形状或 use 直接指向该形状；不含 g，也不 use 指向 g/symbol/另一 use，保留坐标变换、孔洞和显式 clip-rule。外层裁切、内层模糊，避免复制整组当裁切而越界。当前只修几何和依赖，颜色/柔度交后续负责该关系的上色批次，不重新审视全身光源。

四、保存与末批交接
每批只交完整 character.svg；不独立渲染每个小件、不出长报告或请总控再看图。绘制时用 preview_tool 的并排/混合检查本批关键形状与原图偏差，有实际需要才裁切；reference 与素体坐标不同须明确裁切映射，不拿错位混合当还原差异。
is_last 为 true 时，直接用所有批次累积的当前稿生成一张结构对照：默认穿戴与原衣图并排/可对齐区域混合，加入必要的衣层独显及被遮部件展示。用已有预览工具的 --only/--part/--hide/--crop，复杂组合可用 tmp 临时 SVG，原稿保持默认穿戴。
末批提供对照供唯一集中结构 review 使用，不额外拼装整套。所有辅助材料留在工作根目录，不改输入文件；只简述当前完成 id 与尚未解决的具体缺项，缺少真实部件不能报完整。
