依据本节点输入 reference 和 groups.json 绘制分组色稿。本步以完整对象、主要轮廓和正确显影为目标，优先处理脸型与整眼；睫毛丝、瞳孔高光、鼻孔小点等内部细节留给专项细化。身体、下半身和手部已有可靠的轮廓提取方式继续使用。临时连体服仅用于判断姿态和范围，不画衣服组，并合理补全遮挡下的身体。

先看输入参考的脸部局部，在第 3 步内建立清晰可见脸颊、下颌和下巴的轮廓依据，再沿依据绘制；不要凭印象写几个控制点。只采样实际可见边界，不给头发后的区域造目标。脸部工具的源图取边必须看图核实，模型猜的坐标不能直接当真值。不修改第 1 步或其输入参考。

建立所有叶组的主要色块初稿后，立即实现 JSON 显影，再检查脸型与整眼，之后才处理其他主要轮廓和必要局部修正。每个叶 group 用独立 g、唯一 id 和完整 data-group-path，纯色区分，背景透明。同一语义对象必要的跨层绘制段共享路径；前景主体均须覆盖。叶 group 是当前大色块的临时绘制单位，后续 part 承接；group 归属不参与最终的嵌套层叠。

显影使用全局独立层级：节点缺少 display_order 时继承最近设置的祖先，全部未设时为 0；显式设置覆盖继承，不与父级相加。把绘制单位平铺，以便子组显式层级能跨出父级。调用 python3 <display_tool> apply --groups <groups.json> --svg <草稿 SVG> --out <character.svg>，它保留几何、按有效值排序，写入 data-display-order/source/explicit 和 metadata#group-structure。每次改层级后立即应用，不只修改 JSON 或标签。眼睛在相关头发之上按配置生效。透明效果根据 display_notes 用原生 opacity 实现。需要改归属或显影判断时交回第 2 步对应节点，不能私自增加可见残片组。

脸廓检查工具：
1. 只看 reference 写 block-layers/checks/face-guide.json。格式示例：
{"group_path":"face/face_base","roi":[460,280,120,60],"tolerance_px":2,"eyes":["face/eyes/left_eye","face/eyes/right_eye"],"rows":[{"y":292,"left":[474,482],"right":[552,560]},{"y":302,"left":[479,488],"right":[547,556]},{"y":315,"left":[490,500],"right":[535,544]}]}
示例坐标不能套用到其他图。roi 是实际脸部范围，各行 left/right 是源图边界附近的窄搜索区；遮住的一侧省略。通常选 8—16 行覆盖可辨的两颊、下颌和接近下巴处，不只量一个点。tolerance_px 按原生分辨率和边缘清晰度预先给定，清晰描边通常从 1—2 px 判断，不能按整张画布占比放宽。
2. python3 <face_tool> trace --reference <参考图> --guide <face-guide.json> --out <face-target.json>。查看生成的 face-target.source.png，核实标记在脸廓而非发丝、阴影。错误采样先纠正，不能根据候选反改目标。无可见脸部才使用 {"status":"not_applicable","reason":"具体原因"}；有脸但无法可靠取边时说明限制，不能以豁免冒充通过。
3. python3 <face_tool> check --reference <参考图> --target <face-target.json> --svg <character.svg> --out <checks/face目录>。查看双轮廓标记与混合图，以及脸宽、中线误差。工具按目标组从 SVG 现场渲染，带输入哈希；它只量所采样的可见边界，不证明整张脸或表情正确。脸型失败时下一轮先修脸，不去打磨耳饰或细小接缝。

整眼要单独观察完整底形，再观察合成中的外形、位置、间距及显影。名字正确、非空或连成一片都不能证明画对；不要给碎片加细桥应付检查。使用遮罩时还须看遮罩前底形，不能把显影碎片当作者几何。其他本就包含多个实体的组不要求单连通。

自查先看整图、脸部板与紧凑叶组接触表，只为具体疑点展开局部叠加／混合对照。compare_tool 生成图片不等于 reviewed/pass。返修集中处理最高优先级的问题；未变组复用证据。记录实际观察到的差异与修改效果，连续返修没有改善主要问题时报告原因，不能不断转去次要细节。

交付最终 character.svg、同一 SVG 渲染的白底 preview.png、脸廓目标与检查报告。保留完整可编辑底形和隐藏延续，说明仍不确定的轮廓。最终运行 display_tool check 核对 JSON、SVG 参数、嵌入配置与实际绘制顺序一致。
