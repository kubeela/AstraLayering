独立审查候选 SVG、本节点输入 reference 和 groups.json。优先级是完整对象 → 脸型、整眼位置与主要比例 → 显影及其他主要轮廓 → 必要局部修正。不审睫毛丝、瞳孔高光等内部笔触是否逐像素还原。

先核对 face_target、face_report 的参考、目标与候选哈希，变化或缺失时重跑 face_tool check。亲自查看源图取边标记，确认覆盖可辨的两颊／下颌而不是发丝或阴影；阈值按脸部原生尺度判断，不能用全画布掩盖偏差。源图目标取错时纠正源图取边，不依据候选移动目标。报告只覆盖采样行，未采样轮廓、下巴整体和眼位仍需看等比例局部叠加与混合对照。几何失败、缺测或没有依据的 not_applicable 不能被文字 pass 覆盖。

使用 preview_tool 独显完整脸底形和整眼，再恢复合成查看位置、比例和眼发关系。整眼应是完整对象，不是主体加几个外露睫毛小岛；连成一片的错误形状也不通过。用遮罩的组须另看遮罩前底形。参考中的临时连体服不入组，衣缘也不能冒充人体轮廓。实际多实体配饰无需强制单连通。

执行 python3 <display_tool> check --groups <groups.json> --svg <候选 SVG>。确认显影参数、随图 JSON 与真实 DOM 顺序一致。display_order 缺省继承最近祖先，显式设置独立使用全局值；父子不相加，子组可跨出父级层序。眼睛在相关头发之上可以是明确风格规则，不用物理遮挡推翻它。透明／遮罩单独观察，不能靠层序标记假装已经实现。

然后看整图和紧凑接触表，覆盖全部叶组。只有发现具体问题才展开局部对照；同一语义路径的所有绘制段一起检查。生成对照图、独显非空、组数相同都不能证明几何通过。

报告按严重程度记录 group/part 路径、坐标区域、具体差异与证据，先返修脸型和完整对象，再处理其他问题。记录实际观察范围、检查哈希与未测范围；结论 pass／revise／blocked。返修只复验变化组及受影响合成，不为未变组反复生成证据。不写没有看过的“轮廓一致”。报告交总控后，由总控决定返修与是否发布节点输出。
