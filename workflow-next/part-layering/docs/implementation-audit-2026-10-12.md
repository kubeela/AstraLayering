## 六项审计事项及当前确认情况

这些事项在审计中披露。用户随后明确允许保留辅助生图的“同一处问题只生成一次”提示词约束，并暂时保留 blocked 停下当前组、下次启动重新审查的行为；随后授权提高父范围采样精度并优化边界情况，现已接入四倍采样及覆盖差判断。其余行为暂未修改。分块查看一项描述提示词要求与程序可验证条件的区别，不表示程序另设了较宽松的视觉审查标准。

| 项目 | 当前实际行为 | 聊天依据与影响 |
| --- | --- | --- |
| reviewer 的 blocked 停止策略（已确认暂时保留） | reviewer 可以提交 blocked。调度将当前组留为 pending，本次启动不再派发该组；其他可执行分支继续。下次启动重新审查已有 SVG。 | 最初未明确约定；本次用户确认暂时保留。结果中显示“无法核对（blocked）”。代码：outline-agent.ts、workflow.ts。 |
| 辅助生图次数限制（已确认保留） | 绘制和返修提示词要求“同一处问题只生成一次辅助图”。这是提示词限制，没有程序调用计数。 | 最初未获确认；本次用户明确表示可以保留，并要求查看原文。代码：prompts/5-组轮廓.md、prompts/7-轮廓返修.md。 |
| 跨启动绘制会话 | 同一次启动内首次绘制与返修沿用一个 thread；退出后关闭，下一次启动创建新 thread，只恢复文件、进度和反馈。 | 用户要求一次绘制任务保留绘制窗口；跨 CLI 启动是否仍属于同一任务、是否恢复原 thread，没有明确确认。代码：layering-steps.ts、tool-agent.ts。 |
| 已通过结果的有效性检查不足 | 已登记 completed 时只读取文件、粗检 SVG 文本。没有核对当前 SVG 是否仍对应已通过 review 的 candidateHash；参考、提示词改变也不会自动让旧完成记录失效。 | 用户要求跳过已完成工作，但“文件后来被修改仍算完成”没有依据。在临时目录已复现：修改 completed SVG 后，outline/review 仍被跳过。代码：layering.ts 的 initialize/execute。 |
| review 提示词要求与程序验证范围 | 提示词要求先整图，再所有区域裁剪放大，并用 blend、edge 核对；submit_review 只要求至少一次候选的 blend 或 edge 观察，没有核验裁剪、倍率、两种模式或区域覆盖。 | 完整视觉核对由模型按提示词执行；程序只阻止没有实际对照就提交，不代表允许粗看一次。不能以工具提交成功证明完整检查，也不应未经确认另加固定调用次数或选框数量。绘制自检也只验证存在一次 blend 观察。代码：outline-agent.ts、svg-tools.ts。 |
| 父范围检查的采样精度（已授权并接入） | 父子 SVG 在同一四倍网格上渲染，先计算子减父的 alpha 覆盖差，再以 128 阈值识别未覆盖采样，任一个达到阈值即失败。允许贴边和共用曲线，不扩张父范围、不按数量豁免；孔洞仍保留。报告选框和面积为原图单位。根组没有父 SVG 时不检查父范围。 | 原实现仅按原分辨率检测，精度降低未获明确确认。用户本次明确要求提高采样精度并优化边界情况。验证包含合法曲线细分的旧误判、四分之一像素真实越界、共边、孔洞和分离区域。代码：svg-tools.ts。 |

本次只复现和披露缓存失效问题，没有改动真实运行进度，也没有自动重跑已通过结果。

## 后续落实：agent 并发与容量错误恢复

用户随后要求 agent 总并发默认 3，并将并发、重试从调度层剥离。已新增独立调用运行层；组调度仍默认 5。核对安装版本 0.161.0 的固定版本源码，并用本机模拟 HTTP/SSE 服务运行实际 CLI：无服务端等待建议的容量错误直接返回 serverOverloaded、willRetry=false，增加流重连次数不能解决。先保留内置重试，最终临时服务失败才沿用原 thread 继续；等待为 5、10、20、40、60 秒，之后保持 60 秒，不设次数上限。SDK 不再因中途 error 通知提前切断内置重连。完整规则、恢复提示词原文、源码与模拟证据见 [agent-runtime.md](agent-runtime.md)。
