# 眉眼嘴关键造型审查

审查对象为当前 `1.4.嘴部制作/character.svg`、同目录 `materials.json` 与 `关键姿态/` 中的静态目标。直接渲染了目标 SVG，并对照基准默认脸、角色面部、风格参考板和两张局部关键形对照。`原画风格参考.png` 是本轮 SVG 渲染裁切，不是另行提供的原画。

## 结论与最小返修

1. **owner_node: `expression_eyes`；目标姿态：`ordinary_closed`、`smiling_closed`、`half_lidded`。** 两眼均受影响，相关 SVG id 为 `eye_right_upper_lid_ink` / `eye_left_upper_lid_ink`、`eye_right_upper_lash_sweep` / `eye_left_upper_lash_sweep`、`eye_right_closed_lash_fan` / `eye_left_closed_lash_fan`、`eye_right_upper_fold` / `eye_left_upper_fold`、`eye_right_expression_skin` / `eye_left_expression_skin`。普通闭眼目前读成一条很长、近乎等黑的尖楔，睫毛只剩眼角和少数向下的刺；对应参考的上睑皮肤厚度、连续睫毛束及收尖层次明显丢失。闭眼笑虽然改成上拱弧线，但仍是硬黑带和外眼角黑块，下睑被笑意挤起的肤肉与阴影不够可辨，正常脸近景更像两条画在脸上的黑弧。半闭眼的虹膜遮挡基本成立，但上睑仍显厚黑直带，几根睫尖垂进虹膜，上眼皮的光影与下降的睑缘缺少一致的体积转折。请先重画这三个目标的睑缘、睫毛束与睑部体积，再使折线、下睑和眼周明暗随之接合；保留真实发丝投影。不要仅靠调低黑色透明度、模糊或裁切隐藏黑带。

2. **owner_node: `expression_mouth`；目标姿态：`neutral_half_open`、`neutral_open`、`smiling_open`、`sad_open`。** 相关 SVG id 为 `mouth_inside_complete_shape`、`mouth_upper_skin_complete_shape`、`mouth_lower_skin_complete_shape`、`mouth_upper_lip_color_shape`、`mouth_lower_lip_color_shape`、`mouth_teeth_upper_complete_shape`、`mouth_teeth_lower_complete_shape`、`mouth_tongue_complete_shape`、`mouth_tongue_soft_light`、`fx_mouth_lower_on_skin_complete_shape`。半张口是横向暗槽，上唇原有双峰像悬在槽上；中性全开到笑口时，口腔成为规则的深色梯形／V 形，笑口两角是锐尖，整条白牙如一块水平贴片，宽圆舌面和下唇也缺少自然接合。悲口尤其明显：上唇双峰抬在口腔上方，口腔呈深色菱形，下方两角露出白三角，读成几何贴片而非下垂嘴角、牙舌与柔软唇瓣；正常脸部的悲伤神态因此不成立。请从各目标的嘴角、上下唇与口腔轮廓重新确定形体，然后按新的开口调整牙舌的前后遮挡、唇色、亮部和嘴周柔影；只修这些开口目标及相应累计材料，默认闭口与静态轻嘟嘴无须重画。不要只改透明度或软化边缘来遮盖形体。

## 已核对的部分

- `materials_tool check` 通过，说明累计关键形数据与 SVG 引用能交接；这不是造型或动画验收。16 个目标均有 `character.svg` 与 `command.json`，command 为 `reset` 加 `set_parameters`，参数名和值落在当前 `materials.json` 的声明内。
- 默认候选脸与输入基准脸在眉眼嘴局部的对照中一致；闭眼目标的眼白、虹膜和高光已遮住；半闭眼仍能看见被上睑压住的虹膜；悲伤／愤怒眉形可辨；静态轻嘟嘴保留了柔和唇色与中央小口缝。本轮规格明确不制作外伸吐舌，故未把外伸舌当作缺项。
- 复验聚焦以上两组目标及其对应累计数据。当前 `character.svg`、`materials.json` 和 `关键姿态/` 暂不发布为通过别名；本审查不声称参数网格或动画已经完成。
