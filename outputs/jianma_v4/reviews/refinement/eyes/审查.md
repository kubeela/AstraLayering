## 眼黑颜色层次：通过

见[虹膜自身材料开关](evidence-v1/independent-iris-material.png)。以下结论来自实际渲染中的颜色范围与变化，材料层数量仅用于定位。

| 原图中的关系 | 候选落实与判断 |
| --- | --- |
| 上暗下亮的纵向变化 | `iris_vertical_tones`从上部深蓝紫，经蓝灰、中蓝过渡到下部浅蓝；下缘仍有蓝色承接，未以白色替代。关闭第5步效果后完整保留。通过。 |
| 中心与外缘差别 | `iris_center_transition`保留瞳孔邻域较沉的蓝灰；左右`peripheral_depth`使两侧边缘比局部亮带更深，但边缘仍为蓝色，没有粗黑边压缩虹膜。通过。 |
| 瞳孔接合 | `pupil_vertical_depth`及`pupil_peripheral_transition`保留深蓝核心和向外围的蓝灰过渡。中心与周围色阶能够衔接，原生尺寸未见白缝、黑洞或额外硬色环；高光关闭后瞳孔底面连续。通过。 |
| 左右局部亮蓝色带 | 主眼左下约`x=412–416 / y=198–203`的宽浅蓝区，与右中下约`x=420–423 / y=198–202`的较窄亮蓝区均可见。关闭左右色带会实际减弱对应位置亮度；它们不是单一纵向渐变的别名。通过。 |
| 纹样与亮度范围 | 未额外制造原图无法辨认的放射纹或机械同心环。浅蓝局部仍在蓝色虹膜内部，高光有独立开关，不承担全部材质层次。通过。 |

独立16倍局部检查中，完整自身颜色相对仅保留虹膜纵向底阶有18,783个像素变化；单独关闭左右局部色带有9,287个像素变化。数值只证明材料确实参与渲染，不作还原度评分。目标眼保留对应材料和完整镜像分布。

见[眼周与效果开关独立对照](evidence-v1/independent-skin-and-effects.png)。对照范围包含眼窝、上眼皮、内外眼角及下眼缘以外的皮肤。

| 区域 | 实际检查结果 |
| --- | --- |
| 上眼窝与上眼皮 | 外侧粉棕较重，向中央及内侧变浅；睫毛根上方有实际面积的暗肤，上方另有柔亮肤面与暖粉过渡。关闭眼周组后这些体积消失而窄褶线仍在，证明没有用褶线充当全部上眼窝。通过。 |
| 外眼角 | 暖粉暗面沿外下方向展开，与既有面颊红晕衔接；没有向整片脸重复铺红，也不是绕眼一周同等强度的模糊圈。通过。 |
| 内眼角及鼻侧 | 上眼皮内端有暖肤过渡，眼角外侧有局部柔亮面，向鼻侧接入较浅脸底。原图此处变化较轻，候选保留轻重，没有凭空加深内侧凹槽。通过。 |

所有区域归入各自`eye_*_surround_skin`，可整体或逐层关闭，位于`gaze`之外。真实脸面裁切与眼球/正式眼线排除关系有效；柔色先生成，再受保护区域约束，不把眼周色误裁到眼裂内部。主眼关闭第5步效果后上述皮肤层仍在；关闭眼周组才恢复平淡的上一步皮肤。目标眼也保留相同区域和独立归属，未烙入face。

## 分层与独立效果：通过

完整眼白、虹膜、瞳孔、睫毛与高光源形继承已审线稿的补全结果。眼白受眼裂裁切，眼皮在眼内后方，上下眼睑及下睫毛在眼内前方。构造辅助组保持关闭。没有通过删去隐藏底形获得当前外观。

每眼有上、下眼睑分别投向完整眼白及完整虹膜的四项投影；另有独立眼内反光。`data-source-id`分别指向本眼上/下眼睑，`data-target-id`指向本眼完整承载面，`data-complete-path`指向完整投影形或高光源形。来源、承载面与完整路径均有效。

虹膜投影与`gaze`同级，由眼睑来源驱动，未挂入移动眼珠组；各效果同时受完整承载面和当前眼裂限制。高光保留相对本眼`gaze`的关系元数据并可独立关闭。当前交付为静态分层素材，尚不包含动画绑定，这与本步交付范围一致。

复用同版本第5步的完整路径/双重裁切、来源连同对应投影关闭证据及第6步的目标五项效果独显证据，未见越界软影、残留投影、重复压暗或反光白洞。独立重渲染候选并关闭主眼全部第5步效果后，与新版4.4干净基准局部像素差为**0**；虹膜与皮肤自身材料均保持。第6步同版证据还记录双眼效果关闭与镜像后4.4基准像素差为0，本次复用该结果。

## 镜像与前发关系：通过

遵守`eyes_symmetric=true`，源为`eye_right`、目标为`eye_left`，完整目标只应用`matrix(-1 0 0 1 888 0)`，锁定轴为`x=444`。独立审计确认主眼相对第5步XML不变，除目标眼外的其他顶层部件不变。按139项id映射检查，除明确的整组镜像元数据及真实脸面坐标换算外，源到目标对应属性差异为0；目标唯一外部资源引用为`face_base_shape`，没有对主眼内部资源的依赖。重复id、失效引用均为0。

真实脸面支持在目标局部坐标中作逆变换，再随眼组返回同一全局脸面，未复制出镜像脸部实体。原图左右细小光照差异不构成推翻锁定完整镜像策略的依据。

两眼完整组均早于两组前发绘制，所有睫毛、眼内与眼周层均在各自眼组内。关闭头发的独立诊断图及同版独显证据中，完整被遮挡内容存在；正常图无发上眼线碎片、额外前景实例或露出窗口。前发仍是未完成的分件底色，材质与发下实际可见程度留在hair阶段处理，不构成本眼部返修项。
