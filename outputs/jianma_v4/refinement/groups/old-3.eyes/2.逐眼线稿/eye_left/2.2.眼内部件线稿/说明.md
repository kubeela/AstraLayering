# eye_left · 2.2 眼内部件线稿

沿用已核对的 2.1 完整稿，在角色左眼（画面右）中加入完整眼黑、瞳孔和一枚独立高光。原图决定可见比例；生成拆解板只提供完整底形和节点拆分的结构提示。本步没有加入生成板的放射纹、多枚反光或额外图案。

## 结构和裁切

| 内容 | 稳定 id / 几何源 | 控制关系 |
| --- | --- | --- |
| 固定眼白裁切外层 | `eye_left_interior` → `eye_left_sclera_clip` | 裁切固定在当前眼坐标，不随视线移动。 |
| 固定可见开口 | `eye_left_aperture_window` → `eye_left_aperture_clip` | 引用上一部的 `eye_left_aperture_geometry`；开合通过这个边界裁切眼内部件。 |
| 视线组 | `eye_left_gaze` | 只移动眼黑、高光及其辅助显示，参考原点 `(470.15,196.25)`。 |
| 完整眼黑 | `eye_left_eyeball` | 内含虹膜和瞳孔，各自可编辑。 |
| 虹膜 | `eye_left_iris` → `eye_left_iris_geometry` | 完整略不对称椭圆，未按生成板强制画正圆。 |
| 瞳孔 | `eye_left_pupil` → `eye_left_pupil_geometry` | 普通纵向椭圆，几何中心 `(469.3,197.2)`，半径 `(2.1,2.6)`；上部受眼睑遮挡。 |
| 高光 | `eye_left_highlight` / `eye_left_highlight_surface` → `eye_left_highlight_geometry` | 单独节点，归属于视线组；只保留一枚原图可确认的小高光。 |

绘制顺序为完整眼白 → 眼内部件 → 上眼睑 → 下眼睑。上下眼睑、眼周、前发不在 `eye_left_gaze` 内。视线组没有缩放；眨眼也不依靠压扁眼黑。后续开合控制应同时驱动开口边界与眼睑显示形态，本步仅验证裁切归属。

虹膜用中性浅灰，瞳孔用中性深灰，高光用白色，均 `stroke="none"`；这些是形状显示所需的中性填充，没有角色颜色和新增渐变。仅为显示边界的虚线位于 `eye_left_interior_construction_guides`，标记 `data-role="construction-guide"`，默认隐藏；虚线均引用正式几何，没有另外描一份形状。关闭辅助线后眼黑和高光仍存在，不留下永久黑圈。

## 隐藏补全和眼睑遮挡

完整虹膜包围盒约 `(462.00,188.93)–(478.45,203.50)`；它的宽高约 `16.45 × 14.57 px`。上半部在原图不可见，补全为略宽、左右曲率有轻微差异的完整椭圆。这个完整尺寸只用于可恢复底形，未参与上表的可见比例比较。

在 `x=470.15` 的中心纵截面，完整虹膜从 `y188.95` 到 `203.50`，当前可见从 `195.40` 到 `203.37`，因此候选上方隐藏约 `6.45 px`、下方隐藏约 `0.13 px`。隐藏量是候选补全得到的数值，不是声称能从原图量出被遮住的上缘。原图直接能确认的是：上睑切过虹膜上部，下缘接近或轻微压住虹膜底部。

本步没有修改 2.1 已确定的上下眼睑、完整眼白及其裁切几何。同坐标检查未发现足以要求回修眼裂的确定性几何错误；原图低分辨率造成的边缘区间与外角前发遮挡问题继续保留在说明中。
