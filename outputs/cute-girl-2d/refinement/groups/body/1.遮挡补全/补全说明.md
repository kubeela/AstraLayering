# body 遮挡补全说明

- 节点：`group_completion`；目标：`body` / `data-group-path="body"`。
- 输入：`block-layers/groups.svg`、`structure/groups.json`、`references/base-subject.png`；均只读。
- 输出：本目录 `groups.svg`，保留完整七组内容与原绘制顺序。画布仍为 `1024 × 1536`、`viewBox="0 0 1024 1536"`。
- `body` 为根级节点，无父 group 范围需要扩大。树结构与全部路径绑定未调整。

## 补全位置与依据

1. **肩胸与长发遮挡，约 x=411–667、y=281–466。** 将胸腹主体、右肩可见块和右侧细片通过发下连续躯干连接。左肩被杯和发束遮住，依据颈根、抬臂根部、右肩宽度及腰线推断；按当前姿态保留左侧肩线较低的差异，没有机械镜像整侧。右肩原可见外缘直接沿用输入曲线。
2. **颈根重叠，约 x=503–567、y=260–293。** 从原锁骨上缘向颈组延长约 23–33 px，以圆弧端部保持连接余量；未延伸至下颌。
3. **双肩连接端，左侧约 x=411–441、y=329–373，右侧约 x=625–667、y=317–368。** 顺两臂根部走向加入接近半圆的端部，与 arms 形成重叠。腋下以短平滑曲线回接躯干，保持肩与侧胸的自然收束。
4. **侧胸至腰部，约 x=437–621、y=371–535。** 沿可见胸腰宽度渐收，补齐两侧发束下的断口。原右侧细条与主体之间的空隙属于发束遮挡，没有将其保留为躯干孔洞。
5. **骨盆衔接，约 x=440–605、y=533–568。** 将原腹部下缘向 pelvis 内延长，中心约增加 23 px；下缘顺横向腹腰结构收成宽圆弧，并与两侧腰线连续连接。

原 body 路径逐字保留，仅在同组内加入一条无描边、同填色的补形路径；其余六组的 XML 内容保持不变。新范围位于发束／杯的遮挡下，或 neck、arms、pelvis 的连接重叠区。左肩等不可见边界属于上述可见锚点支持的形体推断。
