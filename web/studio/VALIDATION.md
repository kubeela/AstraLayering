## 可复验入口

```sh
pnpm check:web
pnpm test:web
# 对已启动的工作台进行真实浏览器检查；需要环境中已安装 Playwright 及 Chromium
node tools/lighting/browser-check.mjs http://127.0.0.1:4387/
```

如果 Playwright 安装在另一处，通过 `PLAYWRIGHT_MODULE` 提供其模块路径；不要把本机路径写入源码。浏览器检查产物在忽略目录 `.web/browser-check/`。该检查不启动绘图、不调用模型，也不替用户写艺术“通过”记录。

## 技术边界

- 上述浏览器检查使用软件 GPU，不据此声称真实设备达到某个帧率；交互按需渲染，空闲不运行连续渲染循环。
- 本期只有固定视角的 2.5D 高度表面，不能恢复隐藏面或任意姿态的新几何。角色动画、九轴、物理、表情和 Cubism 导出均不在已实现范围。
- 脸部的明暗造型仍取决于法线 / 深度质量。成熟材质并不能自动替代美术法线、方向遮罩或 SDF。
- 原画、法线和深度的原始文件保留完整尺寸。用于稳定投影的浮点滤波属于派生几何数据，不修改皮套原画或线稿。
