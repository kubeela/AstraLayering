# 中性半张嘴：模型与提示词单案例对照

## 目的与范围
比较两个因素：模型（Sol/Astra，均 xhigh），提示词（现行节点原文/原文附加原嘴结构连续性要求）。只做 `mouth_open=0.5, mouth_valence=0` 的一个静态目标，不做整套表情。

## 固定条件
- 四组使用同一份上游完整 SVG 快照和三份既有视觉参考。
- 每组全新会话、相同工具、六分钟制作预算、不计工具被动等待。
- 每组一次视觉自查、最多一轮自修；不给来自其他组的反馈。
- 现行提示词按单案例裁掉其他姿态和材料协议交付要求，其余绘制要求保留；新提示词仅追加连续性段落，原文保留。
- 主控不绘制、不修正候选，统一重新渲染并验证嘴外改动；独立评估仅接收匿名图片和事先固定的四项标准。

## 因果解释边界
每格只有一次生成；存在生成随机性，不能把单例结果推广为普遍模型能力排名。
缩小任务、使用新会话和限制返修都会区别于原先长会话、多姿态流程；现行提示词在本例的成功不能证明原流程始终有效。
这是视觉关键形测试，没有绑定参数或检验中间帧，不能宣布动画制作通过。
各组对0.5开度可能存在理解差异，评估应明确可见开口大小差异，不能让更小开口隐藏问题从而虚报优势。
