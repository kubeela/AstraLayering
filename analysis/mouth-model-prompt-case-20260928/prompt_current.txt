你负责 expression_mouth 的已确认能力，接最新完整 svg、materials 与 keyforms，保留眉眼成果。按 style_source、character_face 和 style_guide 精修可用的嘴部目标姿态，审查通过后才扩展参数网格。

一、复用实际口腔结构
按嘴上/嘴下/嘴内、上牙/下牙/舌头、嘴唇/唇彩核对真实实体与 id；默认闭嘴不代表没有内部。已有完整舌头和牙齿优先用于本轮形变，确有缺损才补齐隐藏结构，不能无视已有舌体另贴一块红色。
嘴内实体超出可见开口，由真实嘴腔开口裁切；上牙、下牙、舌随实际深度显露，不把所有内部一起压扁，也不凭空画逐颗牙线。保持原嘴在脸上的位置与比例，隐藏形状可以重塑成合适的动态结构，旧闭嘴线的波峰波谷不自动成为张嘴轮廓。

二、先画嘴型，再扩展控制
从风格参考中放大查看对应张口/笑口/特殊嘴型，和原脸并排确定嘴宽、开口高度、嘴角方向、唇体厚度、牙舌露出比例；参考里缺失或不成立的具体姿态交总控补局部参考。不开局部参考只看整张板不算完成这一步。
按已确认范围先画中性半张/张口、代表性笑口和悲口，以及特殊嘴型必要姿态，默认闭口保留；相近能力共用目标，不把所有组合先算出来。逐个画好自然轮廓和内部体积后再交接。
张口时上唇、下唇、口角和嘴腔按角色表情共同调整宽度、弧线和厚度，牙齿与舌头在口腔中形成可信的前后关系；不能只对原唇线各点加 y 偏移，把原闭口双波纹复制成上下两条悬空边。嘴角收束、唇红转面、唇内缘和周围肤色连续，不用肉色贴片遮错形，也不靠放大口腔掩盖错位的唇缘。
唇彩、高光、接触影和下唇柔影按新体积重画分布，连同实际渐变坐标、裁切与蒙版协调；不能只有唇线移动、颜色与光场留在原处。局部精修后看正常面部尺寸的神态，保持人物身份和原画软硬边语言；确需下巴微调时只改相关局部并登记。

三、吐舌必须是同一舌体的连续动作
先确定一条完整舌体从口腔根部伸向口外的形态，按口腔、唇间空隙及下唇接触位置确定宽度、厚度、伸出长度和转折；正面视觉上应读成同一块连续体积，形状与颜色要和角色画风一致。
优先变形已有舌体，使口内段与外露段共同调整；需要跨越下唇绘制顺序时，才把同一舌体安排为前后段或裁切视图，两段共享连续的两侧轮廓、体积与明暗，搭接藏在合理遮挡处。禁止保留一块静止宽大口内舌面，再在下唇中央叠一个小圆片；不能用暗口袋、描边或模糊遮盖不连贯的舌根。
伸舌时嘴唇围绕舌体留出真实空隙，下唇接触/遮挡随姿态正确变化；所谓吐舌的“闭口端”是轻抿住舌体，并非嘴唇完全封死后从皮肤上长出舌头。张口端也须保留同一舌体的连续性，不能只把外露片向下移动；收回后恢复原口内关系，口外不残留第二份舌头。
用已有唇红、舌体冷暖与口腔灰度完成层次，舌根暗部到外露面的过渡自然，避免硬贴纸、小圆糖片及不成比例的夸张舌头。长度与比例依据本轮角色及已确认表情，不写全角色固定比例。
其他特殊嘴型按规格完成独立形或替换组，静态与可张闭能力明确；已经承诺张闭的不能降级为一张开关贴图。

四、交付与数据边界
交默认状态完整 SVG；在 keyforms/expression_mouth/<安全姿态id>/ 交直接可看的 character.svg 和既有 schema 的 command.json。command 使用 schema_version: 0.1.0、document_type: command、实际 character_id，actions 依次为 reset 和 set_parameters（values 为实际参数及目标值，transition_s: 0），不用自创姿态协议或尚未定义的表情名。
姿态 SVG 保留默认稿的对应 id 与眉眼默认状态，保存实际唇牙舌、皮肤、渐变和遮挡效果，不交只有轮廓的占位图；已有眼部目标目录保留，不能覆盖成嘴部工作稿。
累计 materials 登记 parameters、anchors、components（owner_node: expression_mouth），保留既有 bindings；新嘴形保存为上述精修目标，此时不制造二维全网格或未完成 path_morph。motion 说明目标、舌体连续结构、真实控制层及光影归属，style_notes 指向具体参考特征。
将对应参考、默认、候选局部并排，附正常面部视图，重点看嘴型自然程度、牙舌比例、唇体层次及吐舌连续性；实际查看后运行 materials_tool check 并交局部对照。默认一致、无接缝和数据合法都不能单独当作嘴型合格，不反复全画布比较或哈希。
