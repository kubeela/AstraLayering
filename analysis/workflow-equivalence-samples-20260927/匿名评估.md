# 匿名产物抽样评估

评估范围：只读给定参考、当前输入 SVG 与匿名候选；不读取原提示词或版本映射。A/B 在各样例中独立看待。下列结论按实际对象、路径、裁切、层序与可见结果作出，不以 ID 齐全或双方写法相似代替验收。嘴部只评嘴型校准与完整线稿；投影只评本隔离样例。

## 1. structure：earring_left、foot_chain_left

### 候选 A：主要安排可执行，但转头显露方向有实质错误，不能整份通过

- **覆盖与附着有依据。** 耳坠固定于 `ear_left`，暂定 `(492, 222–230)`；足链由 `foot_left` 承载、跨 `calf_left` 与足踝交界，所列踝环两侧与脚背交汇坐标能对应当前 SVG。当前耳坠确实是一个含多段子路径的单色形体；足链确实含等粗连接和近等径圆珠。要求按参考校形而不照抄占位轮廓成立。
- **完整隐藏结构与拆分基本成立。** 固定座、柔性连接、硬宝石/坠体有不同变形理由；绕踝前后段分绘、两端连续接回、保留脚背中轴与两侧斜链，能满足遮挡与转足后的完整性。耳后连接、发下链段、侧厚和背面均有交代。下方坠体数量没有被武断写死，也没有把头发算入耳饰。
- **转向判断写反。** 文中写“向角色左侧转时，左耳一侧显露更多”，并把右转写成左耳遮挡加重。此角色正面朝向观察者，角色左耳在画面右；按通常头部左转（鼻尖向画面右）理解，左耳趋远，右转才趋近。这会把耳后连接/侧缘显露的方向交给后续节点时颠倒。不能把它视为文字风格差异。
- **effect 引用全部可核实。** 四条交接关系与实际 `data-source-*` / `data-target-*` 一致：`fx_hair5_left_long_on_earring`、`fx_hair5_left_earring_on_back`、`fx_lower3_foot_chain_left_on_calf`、`fx_lower3_foot_chain_left_on_foot`。也明确由完整线稿阶段校影。只是没有像 B 那样明确限制“踝后隐藏链不可投到正面”，后段改形影响小腿承影的表述稍宽。
- **保守程度尚可。** 必要隐藏面标为推断，不添新饰物。长链与上段的相对摇摆被提前要求拆开，较 B 更积极，但有软硬与运动差依据，不能仅因控制组更多判为无关工作。

### 候选 B：本次结构规划通过，仍只是可执行安排

- 同样正确保留两件整体身份，定位到真实耳垂、足踝和脚背；对耳坠镂空/水滴连接、足链两级 V 和中央下垂链的描述与参考局部相符。
- **左右转头有明确约定且方向正确：** “鼻尖朝画面右”时左耳趋远、遮挡增加；朝画面左时左耳趋近、可能显露耳后钩根和侧厚。避免了 A 的方向倒置。
- **隐藏补全足够具体：** 耳后钩根回折、宝石后连续接链、绕踝完整后弧和左右接头、链内侧与必要硬件背面均列出。补全要求要求在佩戴图里让踝后链被皮肤遮住，不把背面补成额外脚背饰物。
- 软硬分绘与控制拆分有区分：链节不逐环、珠粒不逐珠建立控制；末坠仅在确需不同摆幅时追加独立控制。硬件不随软链拉伸的要求仍明确，未因保守控制数量丢掉完整实体。
- 四条 effect 均引用到实际对象，并明确细链校形影响后发/耳坠裁切、足背承影；对踝后链不能直接在小腿正面落影的约束比 A 更可执行。隐藏接法、曲率与背面是推断，而非声称原图可见。

**两者实质差异：** 核心对象覆盖、固定点、完整后环和 effect 交接接近；A 的左耳转向说明存在功能性错误，B 的方向说明及前后投影责任更准确。因此不能把本样例写成完全等价。两者都没有交付补全图或动态转向结果，不能据规划宣称隐藏形体已画出、运动已验证。

证据：`evidence/structure/{A,B}/结构安排.md`、`补全要求.txt`；`structure-input.svg` 中上述两个对象及四个 effect 的实际节点；参考图局部核对。评估者临时对照图：[当前耳坠与参考](D:/Resources/workspace/AstraLayering/analysis/workflow-equivalence-samples-20260927/evidence/reviewer/structure-ear-input.png)、[参考耳坠与足链局部](D:/Resources/workspace/AstraLayering/analysis/workflow-equivalence-samples-20260927/evidence/reviewer/structure-reference-crops.png)。

## 2. mouth：嘴型校准与完整线稿

### 候选 A：六实体与闭嘴遮挡结构通过；可见嘴缝校准仍不足

- **六项均为非退化实体。** `mouth_inside` 是有真实面积的闭合口腔路径；上牙有牙弓与上方延伸，下牙有完整带状牙弓及下方延伸，舌为完整圆钝面并延伸至下唇后方。上、下嘴各含独立肤色盖片、唇面及线形，不是只放六个空组。
- **口腔裁切真实完整。** `mouth_full_cavity_clip` 的路径与完整 `mouth_inside_shape` 一致，范围约为 x=431–457、y=236–252；牙舌原始路径还在唇后延伸。内部没有沿默认闭嘴缝裁成细条。
- **当前闭合靠盖片完成。** 六组可分别控制；默认无牙舌外漏。隐藏上下嘴后的高分辨率视图能看到完整口腔、上下牙与舌。评估者再把上嘴上移 3、下嘴下移 3 个根坐标单位，内部正常显露，证明并非只在隐藏盖片时“看起来完整”。
- **可见保真问题是嘴缝过平。** 参考闭嘴缝有两侧上拱、中央回落；A 的主线 `mouth_upper_line` 起伏很弱，成一条较平的横向带，改变了闭嘴神态。整体位置与宽度接近参考，唇峰大致正确，但不能据这些掩盖嘴缝曲率差异。此问题属于嘴型校准，不是最终上色差异。
- 其它既有 SVG 子树保持不变；根 defs 只新增嘴部自己的 `mouth_full_cavity_clip`。

### 候选 B：六实体、默认闭嘴与嘴缝校准通过；独立运动存在盖片余量问题

- 六项同样具备独立且有面积的完整实体。`mouth_inside_complete_shape` 是约 x=430–458、y=235–255 的完整口腔；牙舌裁切引用它，未被闭嘴缝锁死。上牙、下牙、舌均有唇后余量，结构对照与隐藏盖片图支持路径所显示的内容。
- 上下嘴有各自肤色盖片、唇面和线形，默认闭嘴无牙舌外漏。`mouth_upper_seam_line` 的双侧起伏和中央回落较 A 更接近原图；嘴型位置、宽度也相符。线形仍是干净而较硬的矢量线稿，不能宣称已复制参考的柔软唇部渲染；本阶段不以该材质差异判失败。
- **具体独立控制限制：** 在同样的上嘴 −3 / 下嘴 +3 根坐标单位平移反事实中，口腔能够打开，但 `mouth_lower_skin_cover` 的大盖片随下嘴移动后，在下颌左右边缘越出脸底，出现角状断口/肤色外溢。原始盖片的下边已延伸至约 y=258–260，且没有脸面裁切保护。因此“有独立组”成立，“小幅位移始终不破脸界”不成立。该缺陷不能被默认闭嘴通过所抵消。
- 其它既有 SVG 子树完整保持不变。

**两者实质差异：** A 的口腔较浅、牙弓边缘略有齿列起伏，B 的口腔更深、牙弓更整片；这些属于原图闭嘴下的合理补形差异，没有足够证据把某一内部口型认定为唯一正确。B 的默认嘴缝保真优于 A；B 的大下嘴盖片又在本次位移检查中暴露越界问题。不能把两者概括成“相同能力、仅字数不同”，也不能只选一个默认截图来宣称全面优胜。

**未测试项：** 没有完成表情绑定、连续张合、牙舌联动、转头或极限开口。±3 位移只是对上下嘴组施加刚性平移的小幅反事实，用来检验实体与盖片行为；它不是实际网格变形或绑定测试，也不是最终动画验收。因此 B 的越界现象应作为盖片余量与控制方式的诊断限制，不能直接推论实际绑定后的动作必然失败。现有结构对照也不能替代上述测试。

证据：`evidence/mouth/{A,B}/character.svg`、`结构对照.png`，中立 [默认高分辨率对照](D:/Resources/workspace/AstraLayering/analysis/workflow-equivalence-samples-20260927/evidence/mouth/comparison-detail.png)、[隐藏上下嘴对照](D:/Resources/workspace/AstraLayering/analysis/workflow-equivalence-samples-20260927/evidence/mouth/hidden-parts-detail.png)，评估者的 [小幅张嘴反事实](D:/Resources/workspace/AstraLayering/analysis/workflow-equivalence-samples-20260927/evidence/reviewer/mouth-open-counterfactual.png)。没有修改候选或输入。

## 3. shadow：隔离的前发投影

### 候选 A：本隔离样例的投影结构与默认外观通过

- 实际投影源为 `hair_front_right`；目标 part 是 `face_base`，其内部 `face_surface` 与 `ear_surface` 分别承影，符合输入中耳面确实属于 `face_base` 的结构。
- `cast_hair_front_right_on_face` 与 `cast_hair_front_right_on_ear` 各有一条完整封闭影形，两个路径的 d 相同且可以分别编辑。路径保留头发后方的大块范围，不是只画当前可见的细暗边。
- 两个 clipPath 分别直接引用实际脸、耳 path。效果位于 `face_base` 内，继承与两片承影面一致的 `translate(55 15)`，没有漏变换或双重平移。模糊施于影形，外层再按承影面裁切，边缘不泄出皮肤。
- 默认阴影位于头发右缘的脸面与耳部，颜色 `#CDA9AB`、`stdDeviation=1.5`，整体宽度、位置、柔边与参考接近。未发现能支持“结构失败”的证据。
- 将给定 `off.svg` 重新渲染并与 `shadow-input.svg` 同方式渲染核对，恢复输入画面。关影不是通过修改基础肤色伪造。

### 候选 B：本隔离样例的投影结构与默认外观通过

- source/target 同样对应实际对象；脸、耳两个目标 ID 正确。
- 完整闭合影形存为 `hair_front_right_cast_shape`，脸和耳效果各以 `use` 引用；一处编辑能同步两片承影投影。它保留完整隐藏面积，不是可见边缘的补丁。
- 脸/耳单独裁切，同样继承正确的 `translate(55 15)`。投影分别排在对应表面之后；模糊在内、承影裁切在外。默认画面中没有越界染背景或漏掉耳面的可见缺陷。
- 色值与柔边参数同 A；默认暗边轮廓略有差异，视觉上同样贴近参考。给定 `off.svg` 的同方式渲染也恢复输入。

**两者实质差异：** A 的两片承影影形独立保存，B 共享一条完整定义；前者可分别调形，后者更容易保持来源轮廓一致。二者完整影形的曲率也不完全相同，B 的下段与 A 有细小宽度差异；当前参考与默认视图不足以将该差别判作明显保真胜负。两者均通过本样例的实际硬要求，这个结论基于路径、坐标、裁切及关影核对，不是因为双方文字或缺陷相似。

**未测试项：** 没有验证头发移动后投影自动跟随、非默认角度、其它投影源或整头发绘制质量。`data-source-part` 只是可追溯归属，不能单凭此属性宣称已有运动驱动。
