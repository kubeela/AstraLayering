# 旧工作流提示词迁移：三组实际产物对照

## 1. 结论

本轮实际运行了三个旧流程节点的新旧两版，共六次独立任务，没有运行新的衣装工作流。结构识别、嘴部完整拆分和投影裁切确实能够在不读取教程原文的新版中完成，但**这次嘴部校形出现了可见的保真差异，因此不能给出“效果全面等价、全部通过”的结论**。

| 抽样节点 | 实际结构/功能结果 | 画面或规划差异 | 本样例支持的结论 |
| --- | --- | --- | --- |
| physics_details / 结构分析 | 耳坠、足链、隐藏连接、环绕后段及四项既有投影关系均有安排 | 旧版把左转时左耳的远近显露关系写反；新版方向正确 | 本样例新版结构安排未见退步，转向说明更准确 |
| mouth / 嘴型校准与完整线稿 | 两版都画出六项完整实体，上下嘴遮盖可独立关闭，牙舌没有被固定窄缝锁死 | 新版闭嘴线更平，旧版更接近原图中段的起伏 | 本次内部拆分能力保留；嘴型保真尚不能判等价 |
| hair / 关联投影与成稿 | 两版均正确覆盖脸/耳、保持坐标变换，关闭效果完全回到输入 | 新版投影略窄，参考有效影区的误差高于旧版 | 两版达到本样例同等用途要求；细小像素差异不判为功能失败 |

这里比较的是线稿阶段的嘴型和结构，不把尚未执行的最终唇色、柔影上色质量算作失败；同时，“只是线稿”也不能免除嘴型校准的职责。

## 2. 如何运行，避免比错对象

旧版取删除教程前保存的实际提示词快照，并提供该节点当时绑定的教程；新版取本轮已融合知识的实际提示词，不提供教程。每对模型、推理强度、原图、输入 SVG、parts、辅助图和工具相同，分别用不继承主任务历史的新会话执行。

| 样例 | 模型 / 强度 | 实际输入 | 比较范围 |
| --- | --- | --- | --- |
| 饰品结构 | Sol / medium | jianma_v4 原图、parts、arms 完成后的 SVG；只选左耳坠和左足链 | 固定/摆动关系、实际层序、隐藏面及受影响旧影 |
| 嘴部线稿 | Astra / xhigh | 同角色 mouths 尚未制作时的 eyes 成稿、原图、已有线稿参考和 parts | 真实绘制、完整内部实体、当前闭嘴轮廓 |
| 头发投影 | Astra / xhigh | 已有 300×220 微型样例：一束头发、带平移的脸与耳、可见投影参考 | 两片承影面的裁切、独立效果及实际显示 |

第三项是控制范围的小样例，不是复杂整头发试跑；它没有用已成功的 SVG 当作答案。每侧只跑一次初始交付及节点要求的自查，没有收到评估意见后返修、重抽或挑最好的一次。六次执行的输入和提示词快照均已保留，候选文件在 17:03–17:09 保存；这不是逐模型的精确执行时长。

评估先保存用途判据，再检查真实 SVG、正常渲染、关闭上下嘴后的内部结构、投影开关差分，并交给不知道新旧标签的独立评估者集中判读一次。匿名标签各样例独立分配，避免一直偏向同一字母。

## 3. 实际产物与差异

### 3.1 耳坠与足链结构

两版都覆盖了本次指定的两个实际对象，没有把已有粗色块当成新轮廓依据：

- 耳坠都安排了耳部固定连接、细链和硬质坠体，说明耳后隐藏连接与被头发挡住的连续段，不按每个链环机械拆控制。
- 足链都安排了踝前、完整踝后环及两侧连接，区分脚背链、硬宝石和跟随足踝的关系；不是用一条侧边代替后段。
- 两版都引用了真实存在的四项投影：耳坠落后发、前发落耳坠、足链落小腿、足链落足面，并交给后续线稿更新。
- 两版都根据遮挡选择一次补全参考；本次只测试结构安排与参考要求，没有调用生图或开始绘制饰品。

**转向差异：**旧版写“向角色左侧转时，左耳一侧显露更多”，把近远关系写反；新版明确“鼻尖朝画面右”时角色左耳趋远、更受遮挡，相反方向趋近。这个差异已被匿名评估者独立指出，说明旧版带教程也不能自动保证正确；不能把错误的旧版结果当成新版必须复现的目标。

### 3.2 嘴部：内部部件齐全，但本次校形不等价

![同坐标嘴型对比](D:/Resources/workspace/AstraLayering/analysis/workflow-equivalence-samples-20260927/嘴部对比.png)

两版均有嘴上、嘴下、嘴内、上牙、下牙、舌头六个非空控制组，实际几何没有退化成窄缝。直接隐藏上下嘴后，完整口腔和牙舌可以显露；各牙弓、舌面保留遮挡后的延伸，推断内容已标记。两版均未改变非嘴部顶层实体的几何和主要绘制属性。

![隐藏上下嘴后的完整内部结构](D:/Resources/workspace/AstraLayering/analysis/workflow-equivalence-samples-20260927/嘴内补全对比.png)

关键区别在默认嘴型：旧版闭嘴缝保留了中段凹凸，新版画得更平，原图的表情特征因此减弱；这属于本阶段的校形差异，不能留给上色解释。两版都使用了自然渐细的实形线，没有把牙舌底形统一加黑描边。内部牙舌尺寸不同属于隐藏结构的推断差异，不要求两次推断逐像素一样。

对比图使用相同原图坐标，没有平移候选来伪造贴合；候选 SVG 在放大视口直接渲染，原图仅做等比例放大。正常视图和内部显露都只作测试证据，没有写入角色的正式 carry。

**额外诊断限制：**匿名评估将两版上下嘴分别刚性平移 −3 / +3 个原画布单位时，均可显露完整嘴内，但旧版的大下嘴盖片在下颌边缘越出了脸底，新版在这次诊断中未出现该现象；见[诊断图](D:/Resources/workspace/AstraLayering/analysis/workflow-equivalence-samples-20260927/evidence/reviewer/mouth-open-counterfactual.png)。它说明独立组仍需在后续绑定时注意盖片范围，不是实际网格形变测试，不能将这一现象直接判成旧版动画必然失败；嘴型保真与这个限制分别记录，不互相抵消。

### 3.3 头发投影：功能有效，局部范围有差异

![单束头发投影对比](D:/Resources/workspace/AstraLayering/analysis/workflow-equivalence-samples-20260927/投影对比.png)

两版都新增了独立的脸部投影与耳部投影，source 指向同一真实发束，target 指向真实 face/ear 表面；裁切沿用接收表面的平移，关闭新影后恢复输入，没有通过改肤色或移动发束伪造结果。

| 实际渲染量测 | 旧版 | 新版 |
| --- | ---: | ---: |
| 开关影响像素数 | 1401 | 1304 |
| 影响像素落在承影面外 | 0 | 0 |
| 关影后与输入不同的像素数 | 0 | 0 |
| 与参考影区的范围交并比 | 92.64% | 89.03% |
| 参考影区平均 RGB 绝对误差（0–255） | 2.95 | 4.60 |

影区以“与无影输入相比，任一 RGB 通道差异大于 1”的像素确定，参考有效影区共 1452 像素；误差只在此区域计算，未用大片背景压低误差。交并比描述影的覆盖位置与范围，不是“绘画质量得分”，也没有事后设一个阈值把结果包装为通过。新版核心影色接近参考，但本次影带略窄，所以两个量测均略差；匿名评估认为这点不足以构成明显的保真退步，两版均通过本隔离样例的用途要求。

## 4. 能证明到哪里

这次证据说明：教程中的隐藏补全、部件独立控制和承影裁切要求，在新版提示词的实际执行中并没有整体消失；它同时暴露了嘴型校准和投影范围的单次输出差异。因此本次结论应分开：新版结构规划通过、投影达到同等用途要求；新版嘴部内部拆分通过，但默认嘴型保真未达到旧版本次产物的程度，尚不能宣布迁移后的全部效果等价。

一次新旧配对无法区分全部随机生成波动与提示词改动的因果影响，不能据此断言差异必然由删除教程导致；但这不影响对本次产物差异的如实记录。未测试的复杂虹膜、手指、多层发束、透明材料、多个投影叠加、带孔洞承影面、其余角色与节点，仍不在本轮结论内；没有进行动画绑定或角度动作验收。

本轮没有根据评估结果偷偷修候选或再抽到满意为止，也没有将样例覆盖正式角色文件。流程提示词的迁移说明仍见[教程融合报告](D:/Resources/workspace/AstraLayering/analysis/workflow-tutorial-migration-20260927/教程融合报告.md)。
