# 教程知识融合报告

## 1. 本轮解决的问题与范围

此前只删除教程输入及阅读指令，保留原提示词，不能证明教程中的细节已经迁入；之前的静态检查也不能证明绘制能力没有下降。本轮按教程原文逐节点补充实际制作规则，报告把“原本已有的规则”和“这次新增或澄清的规则”分开列出。

范围以此前删除记录为准：旧 `workflows` 中 23 个节点，新 `workflow_clothing` 中 4 个节点；另同步修改 7 份既有线稿审查提示词。这 7 份是已有的 review 文件，未新增 reviewer 或检查轮次。旧流程是本轮主要工作，衣装部分另列。

知识直接写在承担工作的节点提示词里。本报告及旁边的改动记录仅供维护者核查，没有作为 worker 的输入，没有新增一份要求所有 worker 通读的通用方法论文档；教程原文也没有重新挂回运行配置。

本轮没有启动绘制、生图或 A/B 试跑，没有改已有角色 SVG、预览、options 或运行记录，也没有提交推送。后文的逻辑核对不能替代模型实际作画验证，因此不宣称新旧成稿逐像素一致，也不宣称绘制质量已通过回归。

## 2. 融合方式

每条规则尽量写成“何时需要 → 具体画什么/怎么接 → 如何保持控制关系 → 不适用时怎么办”，放到真正承担它的阶段：

- **结构分析**决定哪些部分需要独立、哪些面要补、固定点和前后关系是什么；不给每个教程例子强造部件。
- **线稿**把判断落实为完整非退化实体、隐藏连接及自然轮廓；不能仅在计划、标签或说明里承诺。
- **着色/效果**落实完整底色、自身体积、材料变化、独立高光与投影，保留承影面与来源的区别。
- **已有线稿审查**同步具体缺件判据，复用原有对照；不新增最终组装或重复成稿审查。

拆分依据保留为相对变形、绘制顺序、显隐/浓淡、材质控制和裁切需求，而不是“名字不同就另建一层”。同一来源的完整几何、显示片段与后续运动身份分开表达；X/Y 需求落实为面宽、错位、遮挡、内侧及隐藏余量，当前不伪造动作测试。

> 阴影保留与裙摆/袖子/饰物实际投影范围相称的完整源形，再按衣料或素体表面裁切。根据承影材质选正片叠底、深色半透明或普通受影色面：前两种在拆片接口/同源跨衣层处会重复压暗，需要分配有效覆盖；普通受影色面须匹配局部渐变与图案，不能把衣料纹理抹平。真实多件投影的重叠按原图处理，与人工重复覆盖区别开。
> 金属扣、光泽布等独立反光若不应照亮外轮廓，放在底色与正式线条之间并裁到本体；透明底布和不透明绣纹按各自承影/反光范围处理，不把整个衣组一起提亮。当前SVG按原图匹配混合后的颜色；后续绑定更换混合实现时，半透明添加/变亮效果可能需再调，不假定不同渲染器数值等价。
